Recipe 18 — Sprite Rotation & Flip

Spin a sprite about its centre, orbit it around an off-centre pivot, and mirror it on either axis — all with one call, SDL_RenderTextureRotated.

What you'll learn

  • Rotating a texture with SDL_RenderTextureRotated and what each argument controls.
  • The angle convention: degrees, clockwise — not radians.
  • How the center pivot is measured relative to the destination rect, and how moving it turns spin into orbit.
  • Mirroring with SDL_FlipMode and combining flip with rotation.

Prerequisites

Recipe 05 — Loading Textures for creating and drawing a texture, and recipe 04 for the delta-time pattern that drives the animation.

Walkthrough

The rotated blit

Plain SDL_RenderTexture can only place an axis-aligned copy of a texture. To rotate or mirror it, reach for the longer form: 

bool SDL_RenderTextureRotated(
    SDL_Renderer  *renderer,
    SDL_Texture   *texture,
    const SDL_FRect *src,     // sub-rect of the texture, or nullptr for all
    const SDL_FRect *dst,     // where on screen (position + size)
    double          angle,    // DEGREES, clockwise
    const SDL_FPoint *center, // pivot, relative to dst's top-left; nullptr = centre
    SDL_FlipMode    flip);    // NONE | HORIZONTAL | VERTICAL

Two things trip people up. First, angle is in degrees, measured clockwise — the opposite handedness from the radians most trig code produces. If your physics works in radians, convert: deg = rad * 180.0 / SDL_PI_D. Second, the pivot is given in the destination rect's own coordinates, with (0,0) at the top-left of dst.

Spinning about the centre

Pass nullptr for center and SDL pivots around the middle of dst — the usual "spin in place". Drive the angle off accumulated time so the rate is frame-rate independent, exactly like the movement in recipe 04: 

st->spin += dt * 90.0;          // 90 degrees per second
SDL_FRect dst = { x - w/2, y - h/2, w, h };
SDL_RenderTextureRotated(r, tex, nullptr, &dst, st->spin, nullptr, SDL_FLIP_NONE);

Off-centre pivot — spin becomes orbit

Move the pivot away from the centre and the sprite swings around that point instead of turning on the spot. Because center is relative to the destination rect, a pivot at { w*0.5f, h + 90 } sits 90 pixels below the sprite — rotate and the sprite orbits that lower point like a pendulum bob: 

SDL_FPoint pivot = { w * 0.5f, h * 0.5f + orbit_radius };
SDL_RenderTextureRotated(r, tex, nullptr, &dst, st->spin, &pivot, SDL_FLIP_NONE);

Push the pivot far enough outside the sprite's own bounds and you get a wide orbit — handy for a moon circling a planet or a sword swung from the hand.

Flipping

SDL_FlipMode mirrors the texture before it's drawn. The three values are SDL_FLIP_NONE, SDL_FLIP_HORIZONTAL (mirror left/right) and SDL_FLIP_VERTICAL (mirror top/bottom). Flip is applied then rotation, so you can freely combine the two — a left-facing sprite flipped horizontally and rotated 30° still rotates about the same pivot: 

SDL_FlipMode flip = SDL_FLIP_NONE;
if (key == SDL_SCANCODE_1) flip = SDL_FLIP_NONE;
if (key == SDL_SCANCODE_2) flip = SDL_FLIP_HORIZONTAL;
if (key == SDL_SCANCODE_3) flip = SDL_FLIP_VERTICAL;
Degrees, and clockwise. A positive angle turns the sprite clockwise on screen because SDL's y-axis points down. If a rotation looks backwards, you're almost certainly feeding radians, or expecting the maths-class counter-clockwise convention.

Complete listing

A procedurally-built arrow texture spins under delta time. Keys 1/2/3 set the flip mode, and the pivot offset eases in and out so the arrow drifts between spinning in place and orbiting a point below it. 

/*
 * 18-sprite-transforms.cpp — SDL_RenderTextureRotated: spin, orbit, flip.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include "gfx.hpp"

struct AppState {
    SDL_Window   *window   = nullptr;
    SDL_Renderer *renderer = nullptr;
    SDL_Texture  *arrow    = nullptr;
    float  tw = 0, th = 0;
    double spin = 0.0;                 // degrees
    float  t    = 0.0f;                // seconds, drives the pivot ease
    SDL_FlipMode flip = SDL_FLIP_NONE;
    Uint64 last_ns = 0;
};

/* Build a 48x48 arrow pointing right, on a transparent background. */
static SDL_Texture *make_arrow(SDL_Renderer *r)
{
    const int W = 48, H = 48;
    SDL_Surface *s = SDL_CreateSurface(W, H, SDL_PIXELFORMAT_RGBA32);
    if (!s) return nullptr;
    const SDL_PixelFormatDetails *pfd = SDL_GetPixelFormatDetails(s->format);
    Uint32 *px = static_cast<Uint32 *>(s->pixels);
    int pitch = s->pitch / 4;

    for (int y = 0; y < H; ++y) {
        for (int x = 0; x < W; ++x) {
            // Shaft: a horizontal bar; head: a triangle on the right.
            bool shaft = (y >= 18 && y < 30 && x < 32);
            bool head  = (x >= 28 && x < 44 &&
                          SDL_abs(y - 24) <= (44 - x));
            Uint8 a = (shaft || head) ? 255 : 0;
            px[y * pitch + x] = SDL_MapRGBA(pfd, nullptr, 120, 210, 255, a);
        }
    }
    SDL_Texture *t = SDL_CreateTextureFromSurface(r, s);
    SDL_DestroySurface(s);
    return t;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Sprite Transforms", "1.0", "com.example.sdl3.transforms");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Sprite Transforms", 640, 480,
                                     SDL_WINDOW_RESIZABLE, &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);

    st->arrow = make_arrow(st->renderer);
    if (!st->arrow) { SDL_Log("arrow: %s", SDL_GetError()); delete st; return SDL_APP_FAILURE; }
    SDL_GetTextureSize(st->arrow, &st->tw, &st->th);

    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        switch (e->key.scancode) {
        case SDL_SCANCODE_ESCAPE: return SDL_APP_SUCCESS;
        case SDL_SCANCODE_1: st->flip = SDL_FLIP_NONE;       break;
        case SDL_SCANCODE_2: st->flip = SDL_FLIP_HORIZONTAL; break;
        case SDL_SCANCODE_3: st->flip = SDL_FLIP_VERTICAL;   break;
        default: break;
        }
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;

    st->spin += dt * 90.0;             // 90 deg/s, clockwise
    st->t    += dt;

    gfx::clear(st->renderer, 18, 20, 30);

    // Centre the sprite in the window.
    int w = 640, h = 480;
    SDL_GetRenderOutputSize(st->renderer, &w, &h);
    SDL_FRect dst = { w * 0.5f - st->tw * 0.5f, h * 0.5f - st->th * 0.5f,
                      st->tw, st->th };

    // Ease the pivot from the sprite centre out to 110px below and back.
    float ease = 0.5f - 0.5f * SDL_cosf(st->t * 0.8f);   // 0..1
    SDL_FPoint pivot = { st->tw * 0.5f, st->th * 0.5f + ease * 110.0f };

    SDL_RenderTextureRotated(st->renderer, st->arrow, nullptr, &dst,
                             st->spin, &pivot, st->flip);

    // Mark the pivot point so the orbit is visible.
    gfx::set_color(st->renderer, 255, 90, 90, 255);
    gfx::fill_rect(st->renderer, dst.x + pivot.x - 2, dst.y + pivot.y - 2, 4, 4);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        if (st->arrow) SDL_DestroyTexture(st->arrow);
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}

Try it yourself

  1. Make a wide orbit: fix the pivot far outside the sprite (say { tw*0.5f, th*0.5f + 200 }) and watch the arrow sweep a big circle instead of pendulum-swinging.
  2. Combine flip and rotation: hold a horizontal flip while spinning and confirm the mirror is applied before the rotation — the arrow still circles the same pivot.
  3. Draw from a sub-rect of a sprite sheet (recipe 06): pass a src rect picking one frame and rotate just that frame, so an animated sprite can also turn.
  4. Build a clock: two thin rectangle textures rotated about a shared centre at different rates — one a full turn per minute, one per hour.
