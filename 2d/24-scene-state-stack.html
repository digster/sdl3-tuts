Recipe 24 — Scene/State Stack

Give your game structure: a stack of Scene objects where only the top one runs but lower ones keep their state — so a pause menu can freeze and overlay the game beneath it, and a clean push/pop drives every screen transition.

What you'll learn

  • A polymorphic Scene interface: handle / update / draw.
  • Why a stack (not a single "current state") is the right shape — lower scenes survive.
  • Translucent scenes that draw the scene below them (the pause overlay).
  • Mutating the stack safely by deferring transitions as commands applied after the pass.

Prerequisites

Recipe 12 — Pong for a self-contained game loop and recipe 15 for immediate-mode UI. This recipe is the architectural frame those games slot into.

Walkthrough

The Scene interface

Every screen — menu, gameplay, pause — implements the same three verbs. A translucent() flag tells the renderer whether the scene below should still be drawn underneath this one. 

enum class Op { None, Push, Pop, PopToRoot, Quit };
struct Action { Op op = Op::None; Scene *(*make)() = nullptr; };  // a deferred command

struct Scene {
    virtual ~Scene() {}
    virtual Action handle(const SDL_Event &e) = 0;
    virtual Action update(float dt) { return {}; }
    virtual void   draw(SDL_Renderer *r) = 0;
    virtual bool   translucent() const { return false; }
};

Only the top scene runs

Events and updates go to stack.back() alone — the menu doesn't tick while you're playing, the game doesn't tick while paused. State on the lower scenes simply sits frozen, exactly where you left it. 

Action a = st->stack.back()->handle(e);   // top scene only
apply(st, a);                            // then mutate the stack

Draw from the deepest opaque scene up

Find the topmost scene that is not translucent and draw from there upward. With an opaque PlayScene under a translucent PauseScene, you get the game still on screen with the pause panel composited over it — for free. 

int base = (int)st->stack.size() - 1;
while (base > 0 && st->stack[base]->translucent()) --base;
for (int i = base; i < (int)st->stack.size(); ++i) st->stack[i]->draw(r);

Defer the mutation

A scene must never push_back or pop_back on the stack it's currently being iterated through. Instead it returns a command; the app applies it once the pass is done. Push allocates via the scene's factory; pop deletes the top; PopToRoot unwinds back to the menu. 

static void apply(AppState *st, const Action &a)
{
    switch (a.op) {
        case Op::Push:      st->stack.push_back(a.make());                 break;
        case Op::Pop:       delete st->stack.back(); st->stack.pop_back(); break;
        case Op::PopToRoot: while (st->stack.size() > 1) { delete st->stack.back(); st->stack.pop_back(); } break;
        case Op::Quit:      st->quitting = true;                          break;
        default: break;
    }
}
Stack, not switch. A single "current scene" variable forces you to rebuild gameplay state every time you leave and re-enter a screen. The stack keeps suspended scenes intact, which is precisely what pause menus, modal dialogs and inventory screens need.

Complete listing

Three scenes wired through one stack. The menu pushes the game; the game (move the square with the arrows to catch the gold dot) pushes a translucent pause panel that freezes and dims it. Resume with P, quit to the menu with Q. 

/*
 * 24-scene-state-stack.cpp — a polymorphic Scene stack with deferred transitions.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <vector>
#include "gfx.hpp"

static const int WIN_W = 720, WIN_H = 460;

struct Scene;                                   // forward declarations
enum class Op { None, Push, Pop, PopToRoot, Quit };
struct Action { Op op = Op::None; Scene *(*make)() = nullptr; };

struct Scene {
    virtual ~Scene() {}
    virtual Action handle(const SDL_Event &e) = 0;
    virtual Action update(float dt) { (void)dt; return {}; }
    virtual void   draw(SDL_Renderer *r) = 0;
    virtual bool   translucent() const { return false; }
};

static Scene *make_play();                      // factories, defined below
static Scene *make_pause();

/* ---- Menu ---- */
struct MenuScene : Scene {
    float t = 0.0f;
    Action handle(const SDL_Event &e) override {
        if (e.type == SDL_EVENT_KEY_DOWN) {
            if (e.key.scancode == SDL_SCANCODE_RETURN) return { Op::Push, make_play };
            if (e.key.scancode == SDL_SCANCODE_ESCAPE) return { Op::Quit, nullptr };
        }
        return {};
    }
    Action update(float dt) override { t += dt; return {}; }
    void draw(SDL_Renderer *r) override {
        gfx::clear(r, 20, 24, 40);
        gfx::set_color(r, 120, 200, 255, 255);
        gfx::fill_rect(r, WIN_W*0.5f - 120, 120, 240, 18);   // "title" bar
        gfx::set_color(r, 80, 100, 150, 255);
        gfx::fill_rect(r, WIN_W*0.5f - 80, 150, 160, 8);
        float pulse = 0.5f + 0.5f * SDL_sinf(t * 3.0f);      // blinking prompt
        gfx::set_color(r, 200, 220, 255, (Uint8)(80 + pulse * 175));
        gfx::fill_rect(r, WIN_W*0.5f - 60, 300, 120, 14);    // "Press Enter"
    }
};

/* ---- Play ---- */
struct PlayScene : Scene {
    float px = WIN_W*0.5f, py = WIN_H*0.5f;     // player
    float tx = 140, ty = 120, tvx = 180, tvy = 150;  // target dot
    int   score = 0;
    Action handle(const SDL_Event &e) override {
        if (e.type == SDL_EVENT_KEY_DOWN &&
            (e.key.scancode == SDL_SCANCODE_P || e.key.scancode == SDL_SCANCODE_ESCAPE))
            return { Op::Push, make_pause };
        return {};
    }
    Action update(float dt) override {
        const bool *k = SDL_GetKeyboardState(nullptr);
        float sp = 300.0f;
        if (k[SDL_SCANCODE_LEFT])  px -= sp * dt;
        if (k[SDL_SCANCODE_RIGHT]) px += sp * dt;
        if (k[SDL_SCANCODE_UP])    py -= sp * dt;
        if (k[SDL_SCANCODE_DOWN])  py += sp * dt;
        tx += tvx * dt; ty += tvy * dt;
        if (tx < 12 || tx > WIN_W - 12) tvx = -tvx;
        if (ty < 12 || ty > WIN_H - 12) tvy = -tvy;
        if (SDL_fabsf(px - tx) < 26 && SDL_fabsf(py - ty) < 26) {   // caught it
            ++score;
            tx = 40 + SDL_randf() * (WIN_W - 80);
            ty = 40 + SDL_randf() * (WIN_H - 80);
        }
        return {};
    }
    void draw(SDL_Renderer *r) override {
        gfx::clear(r, 14, 30, 26);
        gfx::set_color(r, 255, 210, 90, 255);
        gfx::fill_circle(r, tx, ty, 12);
        gfx::set_color(r, 120, 230, 160, 255);
        gfx::fill_rect(r, px - 16, py - 16, 32, 32);
        for (int i = 0; i < score; ++i) {                // score as a row of pips
            gfx::set_color(r, 255, 230, 120, 255);
            gfx::fill_rect(r, 16.0f + i * 16.0f, 16, 10, 10);
        }
    }
};

/* ---- Pause (translucent overlay) ---- */
struct PauseScene : Scene {
    bool translucent() const override { return true; }   // draw Play underneath
    Action handle(const SDL_Event &e) override {
        if (e.type == SDL_EVENT_KEY_DOWN) {
            if (e.key.scancode == SDL_SCANCODE_P || e.key.scancode == SDL_SCANCODE_ESCAPE)
                return { Op::Pop, nullptr };              // resume
            if (e.key.scancode == SDL_SCANCODE_Q) return { Op::PopToRoot, nullptr }; // to menu
        }
        return {};
    }
    void draw(SDL_Renderer *r) override {
        SDL_SetRenderDrawBlendMode(r, SDL_BLENDMODE_BLEND);
        gfx::set_color(r, 0, 0, 0, 150);                 // dim the frozen game
        gfx::fill_rect(r, 0, 0, (float)WIN_W, (float)WIN_H);
        gfx::set_color(r, 230, 235, 255, 255);
        gfx::fill_rect(r, WIN_W*0.5f - 90, WIN_H*0.5f - 12, 180, 24);  // "PAUSED" plate
        gfx::set_color(r, 90, 110, 160, 255);
        gfx::rect(r, WIN_W*0.5f - 110, WIN_H*0.5f - 40, 220, 80);
    }
};

static Scene *make_play()  { return new PlayScene(); }
static Scene *make_pause() { return new PauseScene(); }

struct AppState {
    SDL_Window   *window = nullptr;
    SDL_Renderer *renderer = nullptr;
    std::vector<Scene *> stack;
    bool   quitting = false;
    Uint64 last_ns = 0;
};

static void apply(AppState *st, const Action &a)
{
    switch (a.op) {
        case Op::Push:      st->stack.push_back(a.make());                          break;
        case Op::Pop:       delete st->stack.back(); st->stack.pop_back();           break;
        case Op::PopToRoot: while (st->stack.size() > 1) { delete st->stack.back(); st->stack.pop_back(); } break;
        case Op::Quit:      st->quitting = true;                                     break;
        default: break;
    }
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Scene Stack", "1.0", "com.example.sdl3.scenestack");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Scene Stack", WIN_W, WIN_H, 0,
                                     &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);
    st->stack.push_back(new MenuScene());        // start at the menu
    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (!st->stack.empty()) apply(st, st->stack.back()->handle(*e));   // top scene only
    return st->quitting ? SDL_APP_SUCCESS : SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;

    if (!st->stack.empty()) apply(st, st->stack.back()->update(dt));   // tick the top
    if (st->quitting) return SDL_APP_SUCCESS;

    gfx::clear(st->renderer, 0, 0, 0);
    int base = (int)st->stack.size() - 1;                            // deepest opaque scene
    while (base > 0 && st->stack[base]->translucent()) --base;
    for (int i = base; i < (int)st->stack.size(); ++i) st->stack[i]->draw(st->renderer);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        for (Scene *s : st->stack) delete s;     // unwind whatever's left
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}

Try it yourself

  1. Add a Replace op (pop then push in one command) for a game-over screen that swaps in without leaving the play scene on the stack.
  2. Give Scene an on_enter/on_exit pair and play a sound on each, so transitions get audio feedback.
  3. Make the pause panel a real menu: add Resume / Quit buttons reusing the immediate-mode UI from recipe 15, driven by the mouse.
  4. Add a transition scene that cross-fades between two scenes by drawing both at varying alpha — a translucent scene that owns its own timer.

And that's the 2D track. You went from a blank window to textures, audio, a full Pong, render targets, custom meshes, deterministic timing, 2D lighting, and now the camera, tweening and scene architecture that hold a real game together.
