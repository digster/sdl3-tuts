Recipe 21 — Clipping & Viewports

Carve the window into independent drawing regions with SDL_SetRenderViewport for split-screen, then mask a minimap to a neat border with SDL_SetRenderClipRect — two remaps that compose into HUDs, picture-in-picture and co-op cameras.

What you'll learn

  • How a viewport both moves the origin and bounds drawing to a sub-rectangle of the window.
  • How a clip rect is a pure scissor mask — it discards pixels but does not shift coordinates.
  • That clip coordinates are interpreted in the current viewport's space, so the two compose.
  • Building split-screen cameras and a clipped corner minimap from these two calls alone.

Prerequisites

Recipe 16 — Render Targets for the idea of a separate drawing surface, and recipe 04 for the delta-time loop. Unlike recipe 16, viewports and clip rects need no extra texture — they retarget the window itself.

Walkthrough

A viewport moves the origin

SDL_SetRenderViewport takes an SDL_Rect (integer pixels) and makes every subsequent draw call relative to that rect's top-left, clipped to its bounds. Drawing at (0, 0) now lands at the viewport corner, not the window corner — which is exactly what you want for split-screen: render the same world twice, each through a viewport that owns half the window. 

SDL_Rect left{ 0, 0, half_w, win_h };
SDL_SetRenderViewport(st->renderer, &left);   // origin + clip to the left half
// ...draw the world centred on player 1...
SDL_SetRenderViewport(st->renderer, nullptr); // back to the whole window

A camera offset per viewport

The viewport gives each player their own canvas; a per-view translation gives each their own camera. We place the followed object at the viewport centre by adding an offset to every world coordinate. Because the viewport already clips, anything off the edge simply doesn't draw — no manual culling required. 

float ox = vp.w * 0.5f - cam_x;     // world->viewport translation
float oy = vp.h * 0.5f - cam_y;
gfx::fill_circle(st->renderer, ox + ball.x, oy + ball.y, 16);

A clip rect masks, it doesn't move

For the minimap we want a small corner panel that shows the whole world scaled down — but with a clean inset border so the scaled markers never bleed to the panel's edge. Set a viewport for the panel, then a SDL_SetRenderClipRect a few pixels inside it. The clip rect is in viewport coordinates, so an inset of (4, 4) sits 4px from the panel corner. Pixels outside are discarded; coordinates are untouched. 

SDL_SetRenderViewport(st->renderer, &panel);            // corner panel
SDL_Rect inset{ 4, 4, panel.w - 8, panel.h - 8 };
SDL_SetRenderClipRect(st->renderer, &inset);            // scissor, in panel space
// ...draw the scaled world; the 4px frame stays clean...
SDL_SetRenderClipRect(st->renderer, nullptr);           // clear the scissor
Reset both when you're done. Viewport and clip state are sticky on the renderer. Always restore with nullptr before drawing window-wide UI (the divider line, a global flash) or the next frame inherits the last region you set.

Complete listing

Six balls bounce in a world larger than the window. The screen is split into two camera views — the left follows the cyan ball, the right follows the orange one — and a clipped minimap in the top-right corner shows the whole world with player markers. Press C to toggle the minimap's clip rect and watch the scaled world spill past its border. 

/*
 * 21-clipping-and-viewports.cpp — split-screen viewports + a scissor-clipped minimap.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include "gfx.hpp"

static const int   WIN_W = 880, WIN_H = 460;
static const float WORLD_W = 1200, WORLD_H = 700;
static const int   N = 6;

struct Ball { float x, y, vx, vy; Uint8 r, g, b; };

struct AppState {
    SDL_Window   *window = nullptr;
    SDL_Renderer *renderer = nullptr;
    Ball   balls[N];
    bool   clip_on = true;
    Uint64 last_ns = 0;
};

/* Draw the whole world into a viewport, translated so (cam_x, cam_y) is centred. */
static void draw_world(AppState *st, const SDL_Rect &vp, float cam_x, float cam_y)
{
    SDL_SetRenderViewport(st->renderer, &vp);          // origin + clip to vp
    float ox = vp.w * 0.5f - cam_x;
    float oy = vp.h * 0.5f - cam_y;

    gfx::set_color(st->renderer, 26, 30, 44, 255);     // view backdrop
    gfx::fill_rect(st->renderer, 0, 0, (float)vp.w, (float)vp.h);
    gfx::set_color(st->renderer, 64, 74, 104, 255);    // world bounds
    gfx::rect(st->renderer, ox, oy, WORLD_W, WORLD_H);

    for (int i = 0; i < N; ++i) {
        gfx::set_color(st->renderer, st->balls[i].r, st->balls[i].g, st->balls[i].b, 255);
        gfx::fill_circle(st->renderer, ox + st->balls[i].x, oy + st->balls[i].y, 16);
    }
    SDL_SetRenderViewport(st->renderer, nullptr);
}

/* A scaled-down map of the world in a corner panel, optionally clipped to an inset. */
static void draw_minimap(AppState *st, const SDL_Rect &panel)
{
    SDL_SetRenderViewport(st->renderer, &panel);
    if (st->clip_on) {
        SDL_Rect inset{ 4, 4, panel.w - 8, panel.h - 8 };
        SDL_SetRenderClipRect(st->renderer, &inset);   // scissor, in panel space
    }
    gfx::set_color(st->renderer, 12, 14, 22, 255);
    gfx::fill_rect(st->renderer, 0, 0, (float)panel.w, (float)panel.h);

    float sx = panel.w / WORLD_W, sy = panel.h / WORLD_H;
    for (int i = 0; i < N; ++i) {
        gfx::set_color(st->renderer, st->balls[i].r, st->balls[i].g, st->balls[i].b, 255);
        gfx::fill_circle(st->renderer, st->balls[i].x * sx, st->balls[i].y * sy, 5);
    }
    SDL_SetRenderClipRect(st->renderer, nullptr);       // always clear the scissor
    gfx::set_color(st->renderer, 180, 190, 220, 255);
    gfx::rect(st->renderer, 0, 0, (float)panel.w, (float)panel.h);
    SDL_SetRenderViewport(st->renderer, nullptr);
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Clipping and Viewports", "1.0", "com.example.sdl3.viewports");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Clipping and Viewports", WIN_W, WIN_H, 0,
                                     &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);

    const Uint8 cols[N][3] = {
        {120,200,255}, {255,180,90}, {120,230,150},
        {230,120,200}, {235,220,120}, {150,170,255}
    };
    for (int i = 0; i < N; ++i) {
        st->balls[i] = Ball{
            SDL_randf() * WORLD_W, SDL_randf() * WORLD_H,
            (SDL_randf() * 2 - 1) * 220.0f, (SDL_randf() * 2 - 1) * 220.0f,
            cols[i][0], cols[i][1], cols[i][2]
        };
    }
    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        if (e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
        if (e->key.scancode == SDL_SCANCODE_C) st->clip_on = !st->clip_on;
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;

    for (int i = 0; i < N; ++i) {
        Ball &b = st->balls[i];
        b.x += b.vx * dt; b.y += b.vy * dt;
        if (b.x < 16)          { b.x = 16;          b.vx = -b.vx; }
        if (b.x > WORLD_W - 16) { b.x = WORLD_W - 16; b.vx = -b.vx; }
        if (b.y < 16)          { b.y = 16;          b.vy = -b.vy; }
        if (b.y > WORLD_H - 16) { b.y = WORLD_H - 16; b.vy = -b.vy; }
    }

    gfx::clear(st->renderer, 0, 0, 0);                  // window-wide letterbox black

    int gutter = 2, half = (WIN_W - gutter) / 2;
    SDL_Rect left{ 0, 0, half, WIN_H };
    SDL_Rect right{ half + gutter, 0, WIN_W - half - gutter, WIN_H };
    draw_world(st, left,  st->balls[0].x, st->balls[0].y);   // P1 follows cyan
    draw_world(st, right, st->balls[1].x, st->balls[1].y);   // P2 follows orange

    SDL_Rect panel{ WIN_W - 224, 16, 208, 122 };            // top-right minimap
    draw_minimap(st, panel);

    gfx::set_color(st->renderer, 0, 0, 0, 255);             // split-screen divider
    gfx::fill_rect(st->renderer, (float)half, 0, (float)gutter, WIN_H);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}

Try it yourself

  1. Switch to a vertical split (stack the two viewports top/bottom). Only the rects change — the draw code is identical, which is the whole point of viewport-relative coordinates.
  2. Add a third small viewport for a spectator camera that frames both players (centre on the midpoint, zoom out by scaling the offset).
  3. Comment out the SDL_SetRenderViewport(..., nullptr) resets and watch every later draw inherit the last region — a vivid reminder that the state is sticky.
  4. Give the minimap a circular look: keep the rectangular clip but draw a filled dark circle first, so the corners read as a rounded porthole.
