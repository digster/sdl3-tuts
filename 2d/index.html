2D Track

Twenty-eight recipes that take you from opening a window to a controller-driven, audio-mixing game with an offscreen pixel-art pipeline, custom meshes, sprite transforms, a fixed-timestep loop, a 2D lighting pass, split-screen viewports, a follow camera, tweening, a scene stack, streaming pixel effects, A* pathfinding, spatial hashing and a vector-Asteroids capstone — all in C++ with SDL3's callback model and the high-level SDL_Renderer drawing API. Each one builds on the previous — work through them in order.

How to run the code

Every recipe's Complete listing is a drop-in replacement for examples/cpp/callbacks.cpp. Replace that file's contents, then build with make run-cpp from the repo root. The recipe will compile against the existing gfx.hpp / gfx.cpp in that folder.

New to the build setup? See the root README.
