Recipe 26 — A* Pathfinding

Find the shortest route across a tile grid. A* expands the frontier in best-first order using a binary-heap priority queue and a Manhattan heuristic, then an agent walks the path you click for it — around every wall in the way.

What you'll learn

  • The A* loop: f = g + h, the open set, the closed set, and how the heuristic steers it.
  • A compact binary heap as the open-set priority queue — no external containers.
  • Reconstructing the path by walking came_from back from the goal.
  • Turning grid waypoints into smooth agent movement, and re-planning on click.

Prerequisites

Recipe 10 — Tilemap Rendering for the grid and tile-to-pixel mapping, and recipe 04 for frame-rate-independent movement along the returned path.

Walkthrough

A* in one sentence

Dijkstra explores outward in every direction equally; A* biases the search toward the goal by adding a heuristic estimate of the remaining distance. Each cell gets g (known cost from the start) and h (estimated cost to the goal); the open set is always expanded lowest-f = g + h first. With an admissible heuristic (never an over-estimate) the first time the goal pops off the queue, its path is optimal. 

static int heuristic(int ax, int ay, int bx, int by) {
    return SDL_abs(ax - bx) + SDL_abs(ay - by);   // Manhattan: 4-connected grid
}

A binary heap for the open set

The open set must repeatedly yield its minimum-f node, so it's a min-heap keyed on f. A flat array with the standard sift-up on push and sift-down on pop gives O(log n) operations with no allocation churn. 

struct HeapItem { int f, idx; };
struct Heap { std::vector<HeapItem> a;
    void push(HeapItem v) {
        a.push_back(v);
        int i = (int)a.size() - 1;
        while (i > 0 && a[(i - 1) / 2].f > a[i].f) { std::swap(a[i], a[(i - 1) / 2]); i = (i - 1) / 2; }
    }
    HeapItem pop() {
        HeapItem top = a[0]; a[0] = a.back(); a.pop_back();
        int i = 0, n = (int)a.size();
        for (;;) {
            int l = 2*i+1, r = 2*i+2, m = i;
            if (l < n && a[l].f < a[m].f) m = l;
            if (r < n && a[r].f < a[m].f) m = r;
            if (m == i) break;
            std::swap(a[i], a[m]); i = m;
        }
        return top;
    }
    bool empty() const { return a.empty(); }
};

The search

Each cell stores its best-known g and the neighbour it came from. Popping a node, we relax its four orthogonal neighbours: if we can reach one more cheaply than before, record the new g, set came_from, and push it with an updated f. A stale duplicate may sit in the heap, but the closed check skips it when it pops. 

while (!open.empty()) {
    int cur = open.pop().idx;
    if (cur == goal) break;                 // optimal path found
    if (closed[cur]) continue;              // a stale heap entry
    closed[cur] = true;
    int cx = cur % COLS, cy = cur / COLS;
    const int dx[4] = { 1,-1,0,0 }, dy[4] = { 0,0,1,-1 };
    for (int d = 0; d < 4; ++d) {
        int nx = cx + dx[d], ny = cy + dy[d];
        if (nx < 0 || nx >= COLS || ny < 0 || ny >= ROWS) continue;
        int ni = ny * COLS + nx;
        if (wall[ni] || closed[ni]) continue;
        int ng = g[cur] + 1;                // uniform step cost
        if (ng < g[ni]) {
            g[ni] = ng; came_from[ni] = cur;
            open.push({ ng + heuristic(nx, ny, gx, gy), ni });
        }
    }
}
The heuristic must match the moves. On a 4-connected grid Manhattan distance is admissible and fast. Allow diagonal moves and you'd switch to the octile (Chebyshev-with-√2) distance — a Manhattan estimate would over-count and could return a non-shortest path.

Complete listing

A grid of walls with a green agent. Left-click a floor tile to send it there — A* plans around the walls, the path is drawn in amber, and the agent walks it. Right-click toggles a wall and re-plans live. 

/*
 * 26-astar-pathfinding.cpp — A* over a tile grid with a binary-heap open set;
 * click to set the goal, the agent walks the returned path.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <vector>
#include <algorithm>
#include "gfx.hpp"

static const int COLS = 24, ROWS = 16, TILE = 32;
static const int WIN_W = COLS * TILE, WIN_H = ROWS * TILE;

struct HeapItem { int f, idx; };
struct Heap {
    std::vector<HeapItem> a;
    void push(HeapItem v) {
        a.push_back(v);
        int i = (int)a.size() - 1;
        while (i > 0 && a[(i - 1) / 2].f > a[i].f) { std::swap(a[i], a[(i - 1) / 2]); i = (i - 1) / 2; }
    }
    HeapItem pop() {
        HeapItem top = a[0]; a[0] = a.back(); a.pop_back();
        int i = 0, n = (int)a.size();
        for (;;) {
            int l = 2*i+1, r = 2*i+2, m = i;
            if (l < n && a[l].f < a[m].f) m = l;
            if (r < n && a[r].f < a[m].f) m = r;
            if (m == i) break;
            std::swap(a[i], a[m]); i = m;
        }
        return top;
    }
    bool empty() const { return a.empty(); }
    void clear() { a.clear(); }
};

static int heuristic(int ax, int ay, int bx, int by) { return SDL_abs(ax - bx) + SDL_abs(ay - by); }

struct AppState {
    SDL_Window   *window = nullptr;
    SDL_Renderer *renderer = nullptr;
    std::vector<Uint8> wall;                 // COLS*ROWS: 1 = blocked
    std::vector<int>   path;                 // cell indices, start .. goal
    int   start = 0;
    float ax, ay;                           // agent pixel position
    int   step = 0;                         // index into path the agent walks toward
    Uint64 last_ns = 0;
};

// Run A*; fill st->path (empty if unreachable). start/goal are cell indices.
static void plan(AppState *st, int start, int goal)
{
    const int N = COLS * ROWS;
    std::vector<int>  g(N, 1 << 30), came(N, -1);
    std::vector<Uint8> closed(N, 0);
    Heap open;
    g[start] = 0;
    int gx = goal % COLS, gy = goal / COLS;
    open.push({ heuristic(start % COLS, start / COLS, gx, gy), start });

    while (!open.empty()) {
        int cur = open.pop().idx;
        if (cur == goal) break;
        if (closed[cur]) continue;
        closed[cur] = 1;
        int cx = cur % COLS, cy = cur / COLS;
        const int dx[4] = { 1,-1,0,0 }, dy[4] = { 0,0,1,-1 };
        for (int d = 0; d < 4; ++d) {
            int nx = cx + dx[d], ny = cy + dy[d];
            if (nx < 0 || nx >= COLS || ny < 0 || ny >= ROWS) continue;
            int ni = ny * COLS + nx;
            if (st->wall[ni] || closed[ni]) continue;
            int ng = g[cur] + 1;
            if (ng < g[ni]) { g[ni] = ng; came[ni] = cur; open.push({ ng + heuristic(nx, ny, gx, gy), ni }); }
        }
    }

    st->path.clear();
    if (came[goal] == -1 && goal != start) return;     // unreachable
    for (int c = goal; c != -1; c = came[c]) st->path.push_back(c);
    std::reverse(st->path.begin(), st->path.end());
    st->step = 1;                                       // 0 is the tile we're on
}

static void cell_center(int idx, float *px, float *py)
{
    *px = (idx % COLS) * TILE + TILE * 0.5f;
    *py = (idx / COLS) * TILE + TILE * 0.5f;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("A* Pathfinding", "1.0", "com.example.sdl3.astar");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("A* Pathfinding", WIN_W, WIN_H, 0, &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);

    st->wall.assign(COLS * ROWS, 0);
    for (int y = 2; y < 12; ++y) st->wall[y * COLS + 8]  = 1;   // two barriers with gaps
    for (int y = 4; y < 14; ++y) st->wall[y * COLS + 15] = 1;
    st->wall[6 * COLS + 8]  = 0;                                // a doorway in each
    st->wall[9 * COLS + 15] = 0;

    st->start = 1 * COLS + 1;
    cell_center(st->start, &st->ax, &st->ay);
    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_MOUSE_BUTTON_DOWN) {
        int cx = (int)(e->button.x / TILE), cy = (int)(e->button.y / TILE);
        if (cx < 0 || cx >= COLS || cy < 0 || cy >= ROWS) return SDL_APP_CONTINUE;
        int idx = cy * COLS + cx;
        if (e->button.button == SDL_BUTTON_RIGHT) {           // toggle a wall, re-plan
            st->wall[idx] = !st->wall[idx];
            if (!st->path.empty()) plan(st, st->start, st->path.back());
        } else if (!st->wall[idx]) {                          // set a new goal
            // Re-root the search at the tile the agent currently stands on.
            st->start = ((int)(st->ay / TILE)) * COLS + (int)(st->ax / TILE);
            plan(st, st->start, idx);
        }
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;

    // Walk toward the next waypoint at a constant speed.
    if (!st->path.empty() && st->step < (int)st->path.size()) {
        float tx, ty; cell_center(st->path[st->step], &tx, &ty);
        float dx = tx - st->ax, dy = ty - st->ay, dist = SDL_sqrtf(dx*dx + dy*dy);
        float speed = 160.0f, move = speed * dt;
        if (dist <= move) { st->ax = tx; st->ay = ty; ++st->step; }   // reached, advance
        else { st->ax += dx / dist * move; st->ay += dy / dist * move; }
    }

    gfx::clear(st->renderer, 18, 20, 28);
    // Tiles: walls dark, floor faint, a thin grid.
    for (int y = 0; y < ROWS; ++y)
        for (int x = 0; x < COLS; ++x) {
            if (st->wall[y * COLS + x]) gfx::set_color(st->renderer, 60, 66, 84, 255);
            else                       gfx::set_color(st->renderer, 30, 34, 46, 255);
            gfx::fill_rect(st->renderer, x*TILE+1, y*TILE+1, TILE-2, TILE-2);
        }
    // Path as amber pips.
    gfx::set_color(st->renderer, 240, 190, 90, 255);
    for (int i = st->step; i < (int)st->path.size(); ++i) {
        float px, py; cell_center(st->path[i], &px, &py);
        gfx::fill_rect(st->renderer, px - 4, py - 4, 8, 8);
    }
    // Goal marker + agent.
    if (!st->path.empty()) {
        float gx, gy; cell_center(st->path.back(), &gx, &gy);
        gfx::set_color(st->renderer, 230, 110, 110, 255);
        gfx::rect(st->renderer, gx - 10, gy - 10, 20, 20);
    }
    gfx::set_color(st->renderer, 120, 230, 150, 255);
    gfx::fill_circle(st->renderer, st->ax, st->ay, 10);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}

Try it yourself

  1. Weighted terrain: give tiles a movement cost (mud = 3, road = 1) and add it instead of the flat +1. A* now prefers cheap ground.
  2. Allow diagonal moves (8 neighbours) and switch the heuristic to octile distance — watch paths cut corners.
  3. Draw the search itself: shade every closed cell to see how the heuristic focuses the frontier toward the goal versus a plain Dijkstra flood.
  4. Smooth the route: run a line-of-sight test between waypoints and drop any that a straight line already clears (string-pulling).
