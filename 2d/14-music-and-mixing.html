Recipe 14 — Music & Mixing

Recipe 08 played one beep at a time. Now: a looping music bed and sound effects layered on top, each on its own stream with its own volume — SDL mixes them for you.

What you'll learn

  • Why multiple audio streams bound to one device gives you a mixer for free.
  • Keeping a music bed topped up so it loops seamlessly, without a callback.
  • Per-stream volume with SDL_SetAudioStreamGain.
  • Firing one-shot SFX on a separate stream so they overlap the music instead of cutting it off.

Prerequisites

Recipe 08 — Audio Basics. We reuse its synth-a-buffer trick and the audio-stream model wholesale; this recipe is about running more than one of them at once.

Walkthrough

One device, many streams

In recipe 08 we opened a single stream and queued beeps into it — they played back-to-back because they shared one queue. The trick to a real soundscape is to open several streams against the same playback device. Each stream has its own queue; SDL sums their output every time the device pulls samples. That summation is mixing. 

SDL_AudioSpec want{};
want.freq = 48000; want.format = SDL_AUDIO_F32; want.channels = 1;

st->music = SDL_OpenAudioDeviceStream(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, &want, nullptr, nullptr);
st->sfx   = SDL_OpenAudioDeviceStream(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, &want, nullptr, nullptr);
SDL_ResumeAudioStreamDevice(st->music);
SDL_ResumeAudioStreamDevice(st->sfx);

A bed that loops

Background music is just a buffer you never stop feeding. We synthesise a couple of seconds of a looping arpeggio once, then in SDL_AppIterate we check how much audio is still queued and top it up before it runs dry. Because we always re-queue the whole loop, the seam is sample-exact — no click, no gap. 

// Keep at least ~0.25s queued so the device never starves.
const int low_water = 48000 * sizeof(float) / 4;
if (SDL_GetAudioStreamAvailable(st->music) < low_water)
    SDL_PutAudioStreamData(st->music, st->loop.data(),
                           (int)(st->loop.size() * sizeof(float)));

SDL_GetAudioStreamAvailable returns bytes still waiting to be played. When that dips below our "low water" mark we push another copy of the loop. Simple, and it never blocks.

Independent volumes

Each stream carries a gain multiplier you set with SDL_SetAudioStreamGain — 1.0 is unity, 0.0 is silence, and you can go above 1 if you've got headroom. We duck the music a little and keep effects loud: 

SDL_SetAudioStreamGain(st->music, 0.5f);   // bed sits underneath
SDL_SetAudioStreamGain(st->sfx,   0.9f);   // hits cut through

One-shot effects on their own stream

Because the SFX stream is separate from the music, queueing a blip there layers it over the bed instead of interrupting it. Spam the key and the blips still queue head-to-tail on that one stream — for true overlap (a chord of simultaneous hits) you'd open a small pool of SFX streams and round-robin them.

Format must match to skip conversion. Open every stream with the same SDL_AudioSpec you synthesise in (here F32, mono, 48 kHz). Mismatch is legal — SDL converts — but you pay for it on every Put.

Complete listing

A two-second arpeggio loops forever under your fingers; Space fires a blip and the arrow keys nudge the music volume. Watch the corner bar track the music gain. 

/*
 * 14-music-and-mixing.cpp — a looping music bed plus layered one-shot SFX,
 * each on its own audio stream, mixed by the device.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include "gfx.hpp"

#include <vector>

struct AppState {
    SDL_Window   *window = nullptr;
    SDL_Renderer *renderer = nullptr;
    SDL_AudioStream *music = nullptr;
    SDL_AudioStream *sfx   = nullptr;
    std::vector<float> loop;       // the pre-rendered music bed
    float music_gain = 0.5f;
    int   blink = 0;
};

static const int RATE = 48000;

// Render `secs` of a simple 4-note arpeggio into a float buffer.
static std::vector<float> make_loop(float secs)
{
    const float notes[4] = { 261.63f, 329.63f, 392.00f, 523.25f }; // C E G C
    int total = (int)(RATE * secs);
    std::vector<float> buf(total, 0.0f);
    int per = total / 8;                       // eight steps over the loop
    for (int step = 0; step < 8; ++step) {
        float f = notes[step % 4];
        for (int i = 0; i < per; ++i) {
            int idx = step * per + i;
            if (idx >= total) break;
            float t = (float)i / RATE;
            float env = 1.0f - (float)i / per;        // pluck-like decay
            buf[idx] = 0.20f * env * SDL_sinf(2.0f * SDL_PI_F * f * t);
        }
    }
    return buf;
}

static void play_blip(SDL_AudioStream *s)
{
    const float secs = 0.10f, freq = 880.0f;
    int n = (int)(RATE * secs);
    std::vector<float> buf(n);
    int env = 4 * RATE / 1000;
    for (int i = 0; i < n; ++i) {
        float t = (float)i / RATE, a = 1.0f;
        if (i < env)         a = (float)i / env;
        if (i > n - env)     a = (float)(n - i) / env;
        buf[i] = a * 0.30f * SDL_sinf(2.0f * SDL_PI_F * freq * t);
    }
    SDL_PutAudioStreamData(s, buf.data(), (int)(buf.size() * sizeof(float)));
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Music and Mixing", "1.0", "com.example.sdl3.mixing");
    if (!SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Music & Mixing", 640, 400,
                                     SDL_WINDOW_RESIZABLE, &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);

    SDL_AudioSpec want{};
    want.freq = RATE; want.format = SDL_AUDIO_F32; want.channels = 1;
    st->music = SDL_OpenAudioDeviceStream(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, &want, nullptr, nullptr);
    st->sfx   = SDL_OpenAudioDeviceStream(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, &want, nullptr, nullptr);
    if (!st->music || !st->sfx) { SDL_Log("audio: %s", SDL_GetError()); delete st; return SDL_APP_FAILURE; }

    SDL_SetAudioStreamGain(st->music, st->music_gain);
    SDL_SetAudioStreamGain(st->sfx,   0.9f);
    SDL_ResumeAudioStreamDevice(st->music);
    SDL_ResumeAudioStreamDevice(st->sfx);

    st->loop = make_loop(2.0f);

    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        switch (e->key.scancode) {
        case SDL_SCANCODE_ESCAPE: return SDL_APP_SUCCESS;
        case SDL_SCANCODE_SPACE:  play_blip(st->sfx); st->blink = 8; break;
        case SDL_SCANCODE_UP:     st->music_gain = SDL_min(1.0f, st->music_gain + 0.1f);
                                  SDL_SetAudioStreamGain(st->music, st->music_gain); break;
        case SDL_SCANCODE_DOWN:   st->music_gain = SDL_max(0.0f, st->music_gain - 0.1f);
                                  SDL_SetAudioStreamGain(st->music, st->music_gain); break;
        default: break;
        }
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);

    // Top the music bed up before it drains, so it loops seamlessly.
    const int low_water = RATE * (int)sizeof(float) / 4;   // ~0.25s
    if (SDL_GetAudioStreamAvailable(st->music) < low_water)
        SDL_PutAudioStreamData(st->music, st->loop.data(),
                               (int)(st->loop.size() * sizeof(float)));

    Uint8 bg = st->blink > 0 ? 70 : 18;
    if (st->blink > 0) --st->blink;
    gfx::clear(st->renderer, bg, bg, bg + 12);

    // A volume meter for the music gain.
    gfx::set_color(st->renderer, 60, 70, 90, 255);
    gfx::fill_rect(st->renderer, 60, 200, 520, 24);
    gfx::set_color(st->renderer, 120, 200, 255, 255);
    gfx::fill_rect(st->renderer, 60, 200, 520 * st->music_gain, 24);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        if (st->music) SDL_DestroyAudioStream(st->music);
        if (st->sfx)   SDL_DestroyAudioStream(st->sfx);
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}

Try it yourself

  1. Open a pool of four SFX streams and round-robin play_blip across them. Now rapid presses overlap into a chord instead of queueing.
  2. Swap the synthesised loop for a real track: SDL_LoadWAV a music file (recipe 08) into st->loop and feed it the same way.
  3. Crossfade two beds. Open a second music stream, ramp one gain down while the other comes up over a second.
  4. Add a master mute on M that pauses both streams with SDL_PauseAudioStreamDevice and toggles back.
