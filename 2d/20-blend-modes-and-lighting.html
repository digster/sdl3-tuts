Recipe 20 — Blend Modes & 2D Lighting

Learn the four built-in blend modes, then put the multiply mode to work: build a light map on an offscreen target and composite it over the scene for moody, coloured 2D lighting.

What you'll learn

  • The four built-in blend modes — BLEND, ADD, MOD, MUL — and what each one does visually.
  • Setting them per-texture (SDL_SetTextureBlendMode) and per-primitive (SDL_SetRenderDrawBlendMode).
  • Building custom factors with SDL_ComposeCustomBlendMode when the built-ins aren't enough.
  • The classic 2D lighting trick: an additive light map composited over the scene with multiply.

Prerequisites

Recipe 16 — Render Targets & Screen Effects, which this builds on directly — the light map is just another offscreen target. Recipe 11 is handy if you want to feed the lights from a particle source later.

Walkthrough

The four blend modes

A blend mode decides how a source pixel you're drawing combines with the destination pixel already there. SDL ships four:

  • SDL_BLENDMODE_BLEND — standard alpha compositing. The source's alpha decides how much it covers the destination. This is the default and what every translucent sprite uses.
  • SDL_BLENDMODE_ADD — source is added to the destination, so colours only ever get brighter. Perfect for glows, fire, lasers and lights.
  • SDL_BLENDMODE_MOD — destination is multiplied by the source. White leaves it untouched, black crushes it to black — exactly what a light map needs to darken unlit areas.
  • SDL_BLENDMODE_MUL — multiply that also folds in the source alpha, a softer modulate useful for tinted shadow passes.

Set the mode on whatever you're about to draw. For a texture: 

SDL_SetTextureBlendMode(light_tex, SDL_BLENDMODE_ADD);   // lights accumulate
// ...for plain rects, lines, fills:
SDL_SetRenderDrawBlendMode(renderer, SDL_BLENDMODE_BLEND);

A radial light sprite

A light is just a texture whose alpha falls off with distance from the centre — bright in the middle, fading to nothing at the rim. Build it once in code: for each pixel, compute the normalised radius and set alpha from a smooth falloff: 

for (int y = 0; y < D; ++y) {
    for (int x = 0; x < D; ++x) {
        float dx = (x - D * 0.5f) / (D * 0.5f);
        float dy = (y - D * 0.5f) / (D * 0.5f);
        float d  = SDL_sqrtf(dx * dx + dy * dy);     // 0 at centre, 1 at edge
        float a  = SDL_max(0.0f, 1.0f - d);          // linear falloff
        a = a * a;                                   // square it for a soft core
        px[y * D + x] = pack_rgba(255, 255, 255, (Uint8)(a * 255));
    }
}

Keep it white — we'll colour each light when we draw it with SDL_SetTextureColorMod, so one sprite serves every light.

The light map on an offscreen target

Make a second target the size of the scene (recipe 16). Bind it, clear it to a dim ambient colour — that's how dark unlit areas will be — then draw each light sprite onto it with additive blending so overlapping lights brighten and bleed into one another: 

SDL_SetRenderTarget(r, st->lightmap);
gfx::clear(r, 30, 30, 45);                        // ambient: nothing is pure black

SDL_SetTextureBlendMode(st->light, SDL_BLENDMODE_ADD);
for (Light &L : st->lights) {
    SDL_SetTextureColorMod(st->light, L.r, L.g, L.b);   // tint this light
    SDL_FRect d = { L.x - L.rad, L.y - L.rad, L.rad * 2, L.rad * 2 };
    SDL_RenderTexture(r, st->light, nullptr, &d);
}

Composite with multiply

Now draw the scene to the window normally, then lay the light map over it with SDL_BLENDMODE_MOD. Multiply means bright spots in the map keep the scene's colour while dim ambient areas darken it — instant pools of light against shadow: 

SDL_SetRenderTarget(r, nullptr);
draw_scene(r);                                    // shapes, sprites, whatever

SDL_SetTextureBlendMode(st->lightmap, SDL_BLENDMODE_MOD);
SDL_RenderTexture(r, st->lightmap, nullptr, nullptr);  // nullptr dst = fill window

Because each light was colour-modded, the multiply also tints the scene — a red lamp washes everything under it red, a cool blue one chills it.

When the built-ins aren't enough. SDL_ComposeCustomBlendMode(srcColorFactor, dstColorFactor, colorOp, srcAlphaFactor, dstAlphaFactor, alphaOp) returns a custom SDL_BlendMode you can hand to the same setter functions. It lets you spell out the exact factors and operation — for example a pre-multiplied-alpha composite, or an additive blend that ignores source alpha.

Complete listing

A handful of shapes form the scene; three coloured lights drift across it. The light map is built additively on an offscreen target each frame and composited over the scene with multiply, so the world is dark except where the lights reach — and tinted by whichever light is nearest. 

/*
 * 20-blend-modes-and-lighting.cpp — additive light map, MOD composite.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include "gfx.hpp"

static const int W = 800, H = 500;
static const int LIGHT_D = 256;        // light sprite diameter

struct Light { float x, y, rad, phase; Uint8 r, g, b; };

struct AppState {
    SDL_Window   *window   = nullptr;
    SDL_Renderer *renderer = nullptr;
    SDL_Texture  *lightmap = nullptr;  // offscreen, TEXTUREACCESS_TARGET
    SDL_Texture  *light    = nullptr;  // the radial sprite
    Light  lights[3];
    float  t = 0.0f;
    Uint64 last_ns = 0;
};

/* A white radial-falloff sprite: bright centre, transparent rim. */
static SDL_Texture *make_light(SDL_Renderer *r)
{
    SDL_Texture *t = SDL_CreateTexture(r, SDL_PIXELFORMAT_RGBA8888,
                                       SDL_TEXTUREACCESS_STATIC, LIGHT_D, LIGHT_D);
    if (!t) return nullptr;
    SDL_SetTextureScaleMode(t, SDL_SCALEMODE_LINEAR);

    // 256×256×4 = 256 KB — too big for the stack, so allocate on the heap.
    Uint32 *px = (Uint32 *)SDL_malloc(LIGHT_D * LIGHT_D * sizeof(Uint32));
    if (!px) { SDL_DestroyTexture(t); return nullptr; }
    for (int y = 0; y < LIGHT_D; ++y) {
        for (int x = 0; x < LIGHT_D; ++x) {
            float dx = (x - LIGHT_D * 0.5f) / (LIGHT_D * 0.5f);
            float dy = (y - LIGHT_D * 0.5f) / (LIGHT_D * 0.5f);
            float d  = SDL_sqrtf(dx * dx + dy * dy);
            float a  = SDL_max(0.0f, 1.0f - d);
            a = a * a;                                  // soft core
            Uint8 av = (Uint8)(a * 255.0f);
            // RGBA8888: 0xRRGGBBAA
            px[y * LIGHT_D + x] = 0xFFFFFF00u | av;
        }
    }
    SDL_UpdateTexture(t, nullptr, px, LIGHT_D * sizeof(Uint32));
    SDL_free(px);
    return t;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Blend & Lighting", "1.0", "com.example.sdl3.lighting");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }

    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Blend Modes & 2D Lighting", W, H,
                                     SDL_WINDOW_RESIZABLE, &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);

    st->lightmap = SDL_CreateTexture(st->renderer, SDL_PIXELFORMAT_RGBA8888,
                                     SDL_TEXTUREACCESS_TARGET, W, H);
    st->light = make_light(st->renderer);
    if (!st->lightmap || !st->light) { SDL_Log("tex: %s", SDL_GetError()); delete st; return SDL_APP_FAILURE; }

    st->lights[0] = { 0, 0, 170, 0.0f, 255, 90,  70  };   // warm red
    st->lights[1] = { 0, 0, 200, 2.1f, 90,  140, 255 };   // cool blue
    st->lights[2] = { 0, 0, 150, 4.2f, 120, 255, 130 };   // green

    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *, SDL_Event *e)
{
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE)
        return SDL_APP_SUCCESS;
    return SDL_APP_CONTINUE;
}

/* Draw the plain scene: a few coloured shapes on a flat floor. */
static void draw_scene(SDL_Renderer *r)
{
    gfx::clear(r, 40, 42, 52);
    gfx::set_color(r, 70, 110, 90, 255);
    gfx::fill_rect(r, 0, H - 120, W, 120);              // floor
    gfx::set_color(r, 180, 160, 120, 255);
    gfx::fill_rect(r, 140, H - 220, 90, 100);           // a crate
    gfx::fill_rect(r, 520, H - 260, 110, 140);          // a pillar
    gfx::set_color(r, 150, 150, 170, 255);
    gfx::fill_circle(r, 380, 200, 46);                  // a sphere
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;
    st->t += dt;

    // Drift the lights along lazy Lissajous paths.
    for (int i = 0; i < 3; ++i) {
        float p = st->lights[i].phase;
        st->lights[i].x = W * (0.5f + 0.38f * SDL_cosf(st->t * 0.5f + p));
        st->lights[i].y = H * (0.5f + 0.32f * SDL_sinf(st->t * 0.7f + p * 1.3f));
    }

    // --- pass A: build the light map on the offscreen target ---
    SDL_SetRenderTarget(st->renderer, st->lightmap);
    gfx::clear(st->renderer, 26, 26, 38);               // dim ambient
    SDL_SetTextureBlendMode(st->light, SDL_BLENDMODE_ADD);
    for (int i = 0; i < 3; ++i) {
        Light &L = st->lights[i];
        SDL_SetTextureColorMod(st->light, L.r, L.g, L.b);
        SDL_FRect d = { L.x - L.rad, L.y - L.rad, L.rad * 2, L.rad * 2 };
        SDL_RenderTexture(st->renderer, st->light, nullptr, &d);
    }

    // --- pass B: scene to the window, then composite the light map (MOD) ---
    SDL_SetRenderTarget(st->renderer, nullptr);
    draw_scene(st->renderer);

    SDL_SetTextureBlendMode(st->lightmap, SDL_BLENDMODE_MOD);
    SDL_RenderTexture(st->renderer, st->lightmap, nullptr, nullptr);

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        if (st->light)    SDL_DestroyTexture(st->light);
        if (st->lightmap) SDL_DestroyTexture(st->lightmap);
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}
A note on the MOD composite size. The light map here is a fixed W×H target while the window is resizable, so on resize the nullptr destination stretches the map to fit. For a production build, recreate the light map at the new output size (as recipe 16 discusses) or render through a fixed-resolution target so the two always match.

Try it yourself

  1. Push the light colours further — a saturated red lamp and a deep blue one — and watch the multiply tint the same crate two different colours as the lights pass over it.
  2. Add an SDL_BLENDMODE_ADD glow pass on top of the composite: draw the brightest light sprites once more straight to the window for a bloom-ish flare around the cores.
  3. Animate a day/night cycle by easing the ambient clear colour of the light map up and down — bright ambient washes the lights out, dark ambient makes them pop.
  4. Replace SDL_BLENDMODE_MOD with a custom mode from SDL_ComposeCustomBlendMode and dial the factors yourself — try a half-strength multiply so shadows never go fully black.
