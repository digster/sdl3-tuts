Recipe 28 — Mini Game: Asteroids

The 2D track's second capstone. A vector-graphics Asteroids that pulls together the whole track: a wrap-around world, thrust-and-inertia flight, splitting rocks, a particle burst on every hit, screen shake for impact, and a fixed-timestep core keeping it deterministic.

What you'll learn

  • Wrap-around ("toroidal") space and drawing polygons with SDL_RenderLines.
  • Newtonian ship control: thrust adds to velocity, nothing removes it but drag.
  • A pooled bullet + asteroid + particle system with spawn / update / cull.
  • Feel: rocks that split, a particle burst and screen shake on each impact, and a simple play / game-over state flip.

Prerequisites

This is where the track converges. Recipe 11 is the debris, recipe 19 the deterministic loop, recipe 16 the screen shake, and recipe 24 the play / game-over states — folded into one small game.

Walkthrough

A wrap-around world

Everything — ship, bullets, rocks — lives on a torus: leave the right edge and reappear on the left. One helper wraps any position after integration, so no object is ever "off screen". 

static void wrap(float &x, float &y) {
    if (x < 0) x += WIN_W;  else if (x >= WIN_W) x -= WIN_W;
    if (y < 0) y += WIN_H;  else if (y >= WIN_H) y -= WIN_H;
}

Thrust and inertia

The ship has a heading angle and a velocity vector. Rotation only changes the angle; thrust adds a small push along the heading to the velocity. With just a little drag, releasing thrust lets you coast — the essence of the game's feel. 

if (k[SDL_SCANCODE_LEFT])  ship.a -= 3.2f * dt;
if (k[SDL_SCANCODE_RIGHT]) ship.a += 3.2f * dt;
if (k[SDL_SCANCODE_UP]) {                       // accelerate along the nose
    ship.vx += SDL_cosf(ship.a) * 260.0f * dt;
    ship.vy += SDL_sinf(ship.a) * 260.0f * dt;
}
ship.vx *= 0.995f; ship.vy *= 0.995f;           // gentle drag
ship.x += ship.vx * dt; ship.y += ship.vy * dt; wrap(ship.x, ship.y);

Rocks that split

Each asteroid carries a size tier. A bullet hit spawns a debris burst, adds score, and — unless it was already the smallest tier — pushes two smaller, faster children into next frame's rock list. Clearing them all respawns a fresh wave. 

// Children go into `out`, not st->rocks — never mutate the list we're iterating.
static void split(AppState *st, const Asteroid &a, std::vector<Asteroid> &out) {
    burst(st, a.x, a.y);                         // recipe-11 particles
    st->shake = 0.35f;                            // recipe-16 screen shake
    if (a.tier <= 0) return;                      // smallest tier: just vanishes
    for (int i = 0; i < 2; ++i) {
        float dir = SDL_randf() * 6.2831853f, sp = 40 + a.tier * 30 + SDL_randf() * 40;
        out.push_back({ a.x, a.y, SDL_cosf(dir)*sp, SDL_sinf(dir)*sp,
                        (SDL_randf()-0.5f)*3.0f, SDL_randf()*6.2831853f, a.tier - 1, a.seed*7 + i });
    }
}
Deterministic core, juicy surface. The simulation runs on the recipe-19 fixed-timestep accumulator, so physics is frame-rate independent. The "juice" — particle bursts, a decaying screen-shake offset applied to every draw — is layered on top and never touches the simulation step, so it can't desync the game.

Complete listing

←/→ rotate, ↑ thrusts, Space fires. Shoot the rocks; getting hit ends the run — Enter restarts. A fixed-timestep accumulator drives the physics; particles and screen shake add the impact. 

/*
 * 28-mini-game-asteroids.cpp — vector Asteroids: wrap-around flight, splitting
 * rocks, particle bursts and screen shake, on a fixed-timestep core.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <vector>
#include "gfx.hpp"

static const int WIN_W = 900, WIN_H = 660;
static const float DT = 1.0f / 120.0f;          // fixed physics step (recipe 19)

static void wrap(float &x, float &y) {
    if (x < 0) x += WIN_W;  else if (x >= WIN_W) x -= WIN_W;
    if (y < 0) y += WIN_H;  else if (y >= WIN_H) y -= WIN_H;
}

struct Ship     { float x, y, vx, vy, a; };
struct Bullet   { float x, y, vx, vy, life; };
struct Asteroid { float x, y, vx, vy, spin, ang; int tier, seed; };
struct Particle { float x, y, vx, vy, life; };

struct AppState {
    SDL_Window   *window = nullptr;
    SDL_Renderer *renderer = nullptr;
    Ship   ship{};
    std::vector<Bullet>   bullets;
    std::vector<Asteroid> rocks;
    std::vector<Particle> parts;
    int    score = 0;
    bool   alive = true;
    float  shake = 0.0f;                        // decaying screen-shake amount
    float  accum = 0.0f;                        // fixed-timestep accumulator
    Uint64 last_ns = 0;
    Uint32 rng = 0x1234;
};

// Emit a small debris burst at (x,y) — the recipe-11 particle pattern.
static void burst(AppState *st, float x, float y) {
    for (int i = 0; i < 14; ++i) {
        float a = SDL_randf() * 6.2831853f, s = 40 + SDL_randf() * 160;
        st->parts.push_back({ x, y, SDL_cosf(a)*s, SDL_sinf(a)*s, 0.4f + SDL_randf()*0.4f });
    }
}

// Children go into `out`, never into the list step() is iterating.
static void split(AppState *st, const Asteroid &a, std::vector<Asteroid> &out) {
    burst(st, a.x, a.y);
    st->shake = 0.35f;
    if (a.tier <= 0) return;
    for (int i = 0; i < 2; ++i) {
        float dir = SDL_randf() * 6.2831853f, sp = 40 + a.tier * 30 + SDL_randf() * 40;
        out.push_back({ a.x, a.y, SDL_cosf(dir)*sp, SDL_sinf(dir)*sp,
                        (SDL_randf()-0.5f)*3.0f, SDL_randf()*6.2831853f, a.tier - 1, a.seed*7 + i });
    }
}

// Spawn a wave of big rocks at the edges, away from the ship.
static void new_wave(AppState *st, int n) {
    for (int i = 0; i < n; ++i) {
        float dir = SDL_randf() * 6.2831853f, sp = 30 + SDL_randf() * 50;
        st->rocks.push_back({ SDL_randf()*WIN_W, SDL_randf()*40.0f,
                              SDL_cosf(dir)*sp, SDL_sinf(dir)*sp,
                              (SDL_randf()-0.5f)*2.0f, 0, 2, (int)(SDL_randf()*1000) });
    }
}

static float rock_radius(int tier) { return 12.0f + tier * 12.0f; }

// Draw an n-sided rough polygon (asteroid) using a seeded per-vertex jitter.
static void draw_rock(SDL_Renderer *r, const Asteroid &a) {
    const int N = 9;
    SDL_FPoint pts[N + 1];
    float rad = rock_radius(a.tier);
    for (int i = 0; i <= N; ++i) {
        float ang = a.ang + (i % N) / (float)N * 6.2831853f;
        float jit = 0.75f + 0.25f * SDL_sinf((float)((a.seed + i) * 53 % 100));
        pts[i] = { a.x + SDL_cosf(ang) * rad * jit, a.y + SDL_sinf(ang) * rad * jit };
    }
    SDL_RenderLines(r, pts, N + 1);
}

static void reset(AppState *st) {
    st->ship = { WIN_W*0.5f, WIN_H*0.5f, 0, 0, -SDL_PI_F/2 };
    st->bullets.clear(); st->rocks.clear(); st->parts.clear();
    st->score = 0; st->alive = true; st->shake = 0;
    new_wave(st, 5);
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Asteroids", "1.0", "com.example.sdl3.asteroids");
    if (!SDL_Init(SDL_INIT_VIDEO)) { SDL_Log("%s", SDL_GetError()); return SDL_APP_FAILURE; }
    AppState *st = new AppState();
    if (!SDL_CreateWindowAndRenderer("Asteroids", WIN_W, WIN_H, 0, &st->window, &st->renderer)) {
        SDL_Log("%s", SDL_GetError()); delete st; return SDL_APP_FAILURE;
    }
    SDL_SetRenderVSync(st->renderer, 1);
    reset(st);
    st->last_ns = SDL_GetTicksNS();
    *appstate = st;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        if (e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
        if (e->key.scancode == SDL_SCANCODE_RETURN && !st->alive) reset(st);
        if (e->key.scancode == SDL_SCANCODE_SPACE && st->alive) {   // fire along the nose
            st->bullets.push_back({ st->ship.x, st->ship.y,
                                    st->ship.vx + SDL_cosf(st->ship.a)*520.0f,
                                    st->ship.vy + SDL_sinf(st->ship.a)*520.0f, 0.9f });
        }
    }
    return SDL_APP_CONTINUE;
}

// One fixed physics step.
static void step(AppState *st) {
    const bool *k = SDL_GetKeyboardState(nullptr);
    if (st->alive) {
        if (k[SDL_SCANCODE_LEFT])  st->ship.a -= 3.2f * DT;
        if (k[SDL_SCANCODE_RIGHT]) st->ship.a += 3.2f * DT;
        if (k[SDL_SCANCODE_UP]) {
            st->ship.vx += SDL_cosf(st->ship.a) * 260.0f * DT;
            st->ship.vy += SDL_sinf(st->ship.a) * 260.0f * DT;
            if (SDL_randf() < 0.5f) {              // engine sparks out the back
                float ba = st->ship.a + SDL_PI_F;
                st->parts.push_back({ st->ship.x + SDL_cosf(ba)*12, st->ship.y + SDL_sinf(ba)*12,
                                      SDL_cosf(ba)*80, SDL_sinf(ba)*80, 0.25f });
            }
        }
        st->ship.vx *= 0.995f; st->ship.vy *= 0.995f;
        st->ship.x += st->ship.vx * DT; st->ship.y += st->ship.vy * DT; wrap(st->ship.x, st->ship.y);
    }

    for (auto &b : st->bullets) { b.x += b.vx*DT; b.y += b.vy*DT; wrap(b.x, b.y); b.life -= DT; }
    for (auto &a : st->rocks)   { a.x += a.vx*DT; a.y += a.vy*DT; wrap(a.x, a.y); a.ang += a.spin*DT; }
    for (auto &p : st->parts)   { p.x += p.vx*DT; p.y += p.vy*DT; p.life -= DT; }

    // Bullet vs rock: rebuild the rock list from survivors + any split children.
    std::vector<Asteroid> next;
    for (auto &a : st->rocks) {
        bool hit = false;
        for (auto &b : st->bullets) {
            if (b.life <= 0) continue;
            float dx = b.x - a.x, dy = b.y - a.y, rr = rock_radius(a.tier);
            if (dx*dx + dy*dy < rr*rr) { b.life = 0; hit = true; st->score += (a.tier + 1) * 10; break; }
        }
        if (hit) split(st, a, next);               // burst + push children into `next`
        else     next.push_back(a);                // survivor carries over
    }
    st->rocks.swap(next);

    // Ship vs rock.
    if (st->alive)
        for (auto &a : st->rocks) {
            float dx = st->ship.x - a.x, dy = st->ship.y - a.y, rr = rock_radius(a.tier) + 8;
            if (dx*dx + dy*dy < rr*rr) { st->alive = false; burst(st, st->ship.x, st->ship.y); st->shake = 0.8f; }
        }

    // Cull dead bullets / particles; respawn a wave when the field is clear.
    for (size_t i = st->bullets.size(); i-- > 0; ) if (st->bullets[i].life <= 0) { st->bullets[i] = st->bullets.back(); st->bullets.pop_back(); }
    for (size_t i = st->parts.size();   i-- > 0; ) if (st->parts[i].life   <= 0) { st->parts[i]   = st->parts.back();   st->parts.pop_back();   }
    if (st->alive && st->rocks.empty()) new_wave(st, 6);

    if (st->shake > 0) st->shake = SDL_max(0.0f, st->shake - DT * 2.0f);
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float frame = (now - st->last_ns) / 1.0e9f;
    st->last_ns = now;
    if (frame > 0.1f) frame = 0.1f;              // clamp after a stall

    st->accum += frame;                          // fixed-timestep accumulator (recipe 19)
    while (st->accum >= DT) { step(st); st->accum -= DT; }

    // Screen shake: offset every draw by a decaying random vector.
    float ox = 0, oy = 0;
    if (st->shake > 0) { ox = (SDL_randf()*2-1) * st->shake * 14; oy = (SDL_randf()*2-1) * st->shake * 14; }

    gfx::clear(st->renderer, 8, 9, 16);

    gfx::set_color(st->renderer, 255, 240, 180, 255);       // particles
    for (const auto &p : st->parts) gfx::fill_rect(st->renderer, p.x + ox - 1, p.y + oy - 1, 2, 2);

    gfx::set_color(st->renderer, 180, 200, 255, 255);       // rocks
    for (auto &a : st->rocks) { Asteroid d = a; d.x += ox; d.y += oy; draw_rock(st->renderer, d); }

    gfx::set_color(st->renderer, 120, 255, 180, 255);       // bullets
    for (const auto &b : st->bullets) gfx::fill_rect(st->renderer, b.x + ox - 1.5f, b.y + oy - 1.5f, 3, 3);

    if (st->alive) {                                        // the ship: a triangle along its heading
        float a = st->ship.a;
        SDL_FPoint nose = { st->ship.x + SDL_cosf(a)*14 + ox,           st->ship.y + SDL_sinf(a)*14 + oy };
        SDL_FPoint l    = { st->ship.x + SDL_cosf(a+2.6f)*11 + ox,      st->ship.y + SDL_sinf(a+2.6f)*11 + oy };
        SDL_FPoint r    = { st->ship.x + SDL_cosf(a-2.6f)*11 + ox,      st->ship.y + SDL_sinf(a-2.6f)*11 + oy };
        SDL_FPoint ship[4] = { nose, l, r, nose };
        gfx::set_color(st->renderer, 230, 240, 255, 255);
        SDL_RenderLines(st->renderer, ship, 4);
    }

    // Score as a row of pips; a bar across the screen on game over.
    gfx::set_color(st->renderer, 240, 220, 120, 255);
    for (int i = 0; i < st->score / 10 && i < 60; ++i) gfx::fill_rect(st->renderer, 12.0f + i*12, 12, 8, 8);
    if (!st->alive) {
        SDL_SetRenderDrawBlendMode(st->renderer, SDL_BLENDMODE_BLEND);
        gfx::set_color(st->renderer, 20, 10, 10, 150);
        gfx::fill_rect(st->renderer, 0, WIN_H*0.5f - 30, (float)WIN_W, 60);
        gfx::set_color(st->renderer, 255, 120, 120, 255);
        gfx::fill_rect(st->renderer, WIN_W*0.5f - 100, WIN_H*0.5f - 6, 200, 12);   // "GAME OVER" plate
    }

    SDL_RenderPresent(st->renderer);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (st) {
        SDL_DestroyRenderer(st->renderer);
        SDL_DestroyWindow(st->window);
        delete st;
    }
}
One scratch list per step. The collision pass reads st->rocks but writes survivors and split children into a separate next vector, swapped in at the end. That's the same deferred-mutation discipline as the recipe-24 scene stack: never resize the container you're currently iterating, and there's a single obvious source of truth each frame.

Try it yourself

  1. Give the ship lives and a brief invulnerability blink on respawn instead of an instant game over.
  2. Add a UFO that crosses the field and shoots back — its own tiny wrap-around AI.
  3. Wire in audio from recipe 14: a thrust rumble, a fire blip, an explosion per split.
  4. Draw a real score and "GAME OVER" with the recipe-09 bitmap font in place of the pip/plate placeholders.
