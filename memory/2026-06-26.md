## Key technical notes (verified against SDL3 / bgfx docs + existing recipes)
- **`float4`-pack uniform arrays.** Every new multi-element uniform block (light
  arrays in 3D/22, 3D/25, bgfx/24) packs each vec as `float4` so the C++ and MSL/`.sc`
  layouts are byte-identical — sidesteps the `float3`-is-16-bytes alignment trap.
- **3D/22 lights:** one forward pass, `Light{ pos_range, color_int, dir_cone }`;
  `dir_cone.w < -0.5` ⇒ point light, else spotlight via `smoothstep(cone, cone+0.05,
  dot(-L, dir))`. `CULLMODE_NONE` (existing cube winding was authored for no-cull).
- **3D/23 tone mapping:** scene → `R16G16B16A16_FLOAT` HDR target, fullscreen pass
  (reuses recipe 19's `kPostVS`) applies exposure → clamp/Reinhard/ACES → `pow(c,
  1/2.2)`. Order: tone-map + gamma **last, once**.
- **3D/24 reflections:** procedural `TEXTURETYPE_CUBE`; `reflect(I, N)` samples the
  same cubemap drawn as the sky; added a column-major `mat4_look_at` (camera position
  known directly so reflections are correct); sky view = orientation-only via
  `look_at(origin, -camPos)`, `pos.xyww` far-plane trick.
- **3D/25 deferred:** MRT geometry pass — 3 `SDL_GPUColorTargetDescription`
  (RGBA8 albedo, RGBA16F normal, RGBA16F position) + matching
  `SDL_GPUColorTargetInfo[3]`; MSL fragment returns a struct with `[[color(0..2)]]`.
  Lighting fullscreen pass loops 16 lights over the G-buffer; background guarded by
  `dot(N,N) < 0.5` (normal target cleared to 0).
- **bgfx/21 PBR:** Cook-Torrance (GGX `D`, Smith `G`, Schlick `F`) on a UV-sphere
  grid; cheap IBL = `textureCube(env, N)` diffuse + `mix(textureCube(env, R),
  irradiance, rough)` specular (no prefiltered mip chain — flagged in a note).
- **bgfx/22 particles:** keeps recipe 16's mechanism (dynamic vertex buffer,
  `dispatch` view 0 → draw view 1, bgfx auto-barriers); new content = sine-based
  flow field + linear mouse attractor (no `normalize`, no singularity) + additive
  `BGFX_STATE_BLEND_ADD`.
- **bgfx/23 stencil:** planar mirror — `setViewMode(Sequential)` for submit order;
  mark floor (`OP_PASS_Z_REPLACE` ref 1, no colour/depth write) → reflected cubes
  (`STENCIL_TEST_EQUAL`, `CULL_CCW` for flipped winding) → translucent floor →
  upright cubes. Note flags winding/`homogeneousDepth` as backend-tunable (like the
  shadow recipe).
- **bgfx/24 deferred:** `createFrameBuffer(4, att, true)` from RGBA8 + 2×RGBA16F +
  D24S8; `gl_FragData[0..2]`; lighting reads `bgfx::getTexture(fb, i)`; transient
  fullscreen triangle (recipe 15's `screenTri`, V-flip on `!originBottomLeft`).

## Key technical notes (verified vs SDL_GPU docs + existing recipes)
- **SSAO** (26): geometry VS outputs `(view·model)·pos` / view-space normal so the
  SSAO pass re-projects samples with just the projection matrix. Hemisphere **kernel**
  = 24 `float4`s generated CPU-side (clustered near origin via `0.1 + 0.9·s²`); 4×4
  **noise** texture of `*0.5+0.5`-encoded RGBA8 rotation vectors, tiled with a REPEAT
  sampler (G-buffer uses a CLAMP sampler — two sampler objects). Depth compare
  `sampleDepth >= samplePos.z + bias` (right-handed view space) flagged as
  backend-tunable like the shadow recipe; projected UV uses `uv.y = 1 - uv.y` to match
  `kPostVS`. Reused `make_shader`/`create_color_target`/`create_depth` and a local
  `make_post` (≡ recipe 19's `make_post_pipeline`).
- **GPU particles** (27): storage buffer flagged
  `VERTEX | COMPUTE_STORAGE_READ | COMPUTE_STORAGE_WRITE`; compute pipeline
  `num_readwrite_storage_buffers=1`, `[[buffer(0)]]` uniforms then `[[buffer(1)]]`
  storage (per recipe 17); `Params{ float4 p0, float4 attractor }` float4-packed.
  Additive `SDL_GPUColorTargetBlendState` (ONE/ONE, ADD) on the color target;
  `PRIMITIVETYPE_POINTLIST` + `[[point_size]]`; `mat4_look_at` orbit camera.
