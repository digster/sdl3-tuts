## Key technical notes (verified against SDL3 / bgfx docs)
- **3D/21 Mipmaps & MSAA (least-certain batch, all confirmed on the SDL wiki):**
  `SDL_GenerateMipmapsForGPUTexture(cmd_buffer, texture)` takes a *command
  buffer* and runs outside any render pass; the texture needs `COLOR_TARGET`
  (plus `SAMPLER`) usage for mip generation. Sampler `mipmap_mode`,
  `enable_anisotropy`, `max_anisotropy`, `min_lod`/`max_lod` confirmed.
  MSAA via `SDL_GPUMultisampleState::sample_count` (`_1/_2/_4/_8`) + resolve with
  `SDL_GPU_STOREOP_RESOLVE` / `RESOLVE_AND_STORE` and
  `SDL_GPUColorTargetInfo::resolve_texture` / `resolve_mip_level` /
  `resolve_layer`.
- **3D/18 instancing:** second vertex buffer bound at slot 1 with
  `input_rate = SDL_GPU_VERTEXINPUTRATE_INSTANCE` (per-instance offset attr 2,
  colour attr 3); one `SDL_DrawGPUIndexedPrimitives(..., NUM_INSTANCES, ...)`.
- **3D/19 bloom:** HDR scene target (`R16G16B16A16_FLOAT`) so emissive > 1.0
  survives the bright-pass; separable Gaussian H/V ping-pong at half-res reusing
  recipe 12's fullscreen-triangle VS; additive composite.
- **3D/20 transparency:** transparent pipeline keeps depth *test* on, depth
  *write* off, drawn back-to-front (`std::sort` by view-space Z) after the opaque
  pass; `SDL_GPUColorTargetBlendState` SRC_ALPHA / ONE_MINUS_SRC_ALPHA.
- **bgfx/17 skybox:** procedural 6-face `createTextureCube` (face order
  +X,-X,+Y,-Y,+Z,-Z, face-major memory); cube positions double as sample
  directions; `SAMPLERCUBE`/`textureCube`; translation-stripped view; `pos.xyww`
  far-plane trick; `DEPTH_TEST_LEQUAL`, no Z-write.
- **bgfx/19 shadow mapping:** `D16` depth texture with
  `BGFX_TEXTURE_RT | BGFX_SAMPLER_COMPARE_LEQUAL` → `createFrameBuffer`; crop/bias
  matrix branches on `homogeneousDepth`/`originBottomLeft`; `SAMPLER2DSHADOW` +
  `shadow2DProj`; gated on `BGFX_CAPS_TEXTURE_COMPARE_LEQUAL`.
- **bgfx/20 buffers:** transient (`getAvailTransientVertexBuffer` guard →
  `allocTransientVertexBuffer`, one-frame) vs dynamic
  (`createDynamicVertexBuffer` + `update`) vs the static buffers used so far.
