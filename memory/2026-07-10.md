## Key technical notes (verified vs SDL3 / SDL_GPU / bgfx docs + existing recipes)
- **2D/25 streaming:** `SDL_CreateTexture(..., STREAMING, ...)` at a small internal size,
  `SDL_LockTexture` → write per-pixel honouring **pitch (bytes, not texels)** →
  `SDL_UnlockTexture`; `SCALEMODE_NEAREST` scaled to the window. Doom-style rolling fire
  (heat field) + a sum-of-sines plasma.
- **2D/26 A*:** flat-array binary-heap open set (sift-up/down), Manhattan heuristic,
  `came_from` reconstruction, click-to-plan; agent walks waypoints with recipe-04 dt.
- **2D/27 spatial hash:** uniform grid, self + E/SW/S/SE neighbour offsets to test each
  unordered pair once; brute-force vs grid toggled, timed with `SDL_GetPerformanceCounter`.
- **2D/28 Asteroids:** wrap-around world, `SDL_RenderLines` polygons, thrust+inertia,
  fixed-timestep accumulator (recipe 19), particle bursts (11), decaying screen shake
  (16). **Fix during review:** the split-collision loop was mutating `st->rocks` while
  range-iterating it — rewrote to the double-buffer pattern (`split()` writes children
  into a `next` scratch vector, swapped in once per step).
- **3D/28 terrain:** 4-octave value-noise fBm as a pure `terrain_h(x,z)`;
  central-difference normals; altitude colour bands; `exp(-density*dist)` fog with fog
  colour == clear colour (doubles as a far-plane hide). `FRONTFACE_CCW` + back-cull with
  `a,c,b / b,c,d` winding.
- **3D/29 culling:** Gribb–Hartmann plane extraction from the column-major VP
  (`row_i = (m[i], m[4+i], m[8+i], m[12+i])`; near = `row2` alone for the **zero-to-one**
  depth this repo's `mat4_perspective` uses); positive-vertex AABB test; per-frame
  visible list re-uploaded to a dynamic instance buffer with **cycle=true**; culled from
  a narrow rotating frustum but viewed from a pulled-back camera; count in the window
  title.
- **3D/30 CSM:** three cascades fitted to view-frustum slices (corners from the camera
  basis → centroid + bounding radius → light ortho); **three separate D32 depth textures**
  + samplers (deliberately not a depth array, to keep the plumbing visible); per-fragment
  cascade pick by view depth (passed as `-(view*world).z`); per-cascade bias; debug tint
  toggle. `float4x4 lightVP[3]` float4-aligned in the FS uniform.
- **3D/31 water (terminator):** reflection = scene rendered with
  `proj * view * scale(1,-1,1)` into an offscreen colour target (recipe 12); water plane
  samples it **projectively** (interpolate clip coords, divide in FS) + sine-wave UV
  distortion + Schlick–Fresnel from `V.y`. `CULLMODE_NONE` because the mirror flips winding.
- **bgfx/25 HDR:** `RGBA16F` + `D24S8` framebuffer; over-bright cube; fullscreen
  `screenTri` (recipe 15) tone-map (clamp/Reinhard/ACES) + gamma; `vec3_splat`.
- **bgfx/26 SSAO:** view-space G-buffer via built-in `u_modelView`; `u_kernel[24]` uniform
  array + 4×4 REPEAT+POINT noise texture (`bgfx::alloc`); custom `u_projMat` (avoids the
  reserved `u_proj`); `mtxFromCols` TBN; four views geometry→SSAO→blur→composite.
- **bgfx/27 occlusion queries:** `createOcclusionQuery`, `submit(view, prog, query)`,
  `getResult` (Visible/Invisible/NoResult) tallied to `dbgTextPrintf`, `setCondition`
  gating a marker draw; `setViewMode(Sequential)` so the occluder draws first; gated on
  `BGFX_CAPS_OCCLUSION_QUERY`. **API verified via context7.**
- **bgfx/28 GPU-driven (terminator):** `cs_cull` atomic-append (`atomicFetchAndAdd`) into a
  compute-write dynamic vertex buffer; `cs_genargs` writes `drawIndexedIndirect` into
  `createIndirectBuffer(1)` then **zeroes the counter for next frame** (keeps it to two
  dispatches, no CPU readback); `submit(1, prog, indirect, 0, 1)` with instance count
  decided on-GPU; `setInstanceDataBuffer(dynHandle, 0, MAX)`; gated on
  `BGFX_CAPS_COMPUTE | BGFX_CAPS_DRAW_INDIRECT`. **API verified via context7.**

# 2026-07-10 (follow-up) — Bake three tuning caveats into robust defaults

## Goal
Turn three of batch-4's "tune-this-yourself" caveats into baked-in defaults (confirmed
all three via `AskUserQuestion`): CSM shimmer, SSAO V-orientation, water reflection leak.

## What changed
- **`3d/30-cascaded-shadow-maps.html` — CSM texel-snap.** In `fit_cascade`, after building
  the light view/ortho, round the light-space origin to whole shadow-map texels and fold
  the sub-texel remainder into the ortho's x/y offset (`lp.m[12]/[13] += (round(o)-o)/half`,
  `half = SHADOW/2`). Standard MJP round-in-clip-space method — works because ortho keeps
  `w = 1`, so the clip origin is the VP's last column; no matrix inverse. Added a
  "Snap the box to texels" walkthrough subsection, swapped try-it #1 (now done) for a PCF
  suggestion, and softened the warn box (shimmer handled; bias/splits still tunable).
- **`bgfx/26-ssao.html` — SSAO V-flip.** New `u_flipY` uniform set from
  `bgfx::getCaps()->originBottomLeft`; `fs_ssao` flips the *projected* sample UV
  (`if (u_flipY.x > 0.5) uv.y = 1.0 - uv.y;`) so it matches how `screenTri` orients the
  G-buffer sampling. Fixes AO haloing/inversion on non-GL (D3D/Metal/Vulkan) backends.
  Note rewritten; one-line cross-reference added to the MSL-only (already consistent)
  `3d/26-ssao.html`.
- **`3d/31-water-planar-reflections.html` — below-water clip.** Scene VS now outputs world
  position; scene FS discards `wpos.y < 0` when a new `clipBelow` uniform is set. The
  reflection `draw_objects` call passes `1.0f`, the main call `0.0f`. Lowered `obj_model`'s
  Y (base 1.6→0.9, amp 0.6→1.1 ⇒ range ≈ [-0.2, 2.0]) so cubes bob through the surface and
  the clip visibly matters — opaque water hides the submerged parts in the main view, the
  clip removes them from the mirror. Walkthrough + try-it #1 updated.
