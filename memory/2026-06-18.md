## Key technical notes (verified against SDL3 / bgfx docs)
- **SDL_GPU compute (3D/17):** confirmed via the SDL wiki that hand-written MSL
  compute binds `[[buffer(n)]]` as **uniforms first, then read-only storage,
  then read-write storage** — so the params UBO is `buffer(0)` and the
  read-write particle buffer is `buffer(1)`. Particle buffer carries
  `VERTEX | COMPUTE_STORAGE_READ | COMPUTE_STORAGE_WRITE` so one buffer is both
  simulated and drawn; SDL inserts the compute→vertex barrier.
- **bgfx is column-major (bgfx/14 picking):** `mtx[12..14]` being the
  translation (recipe 11) confirms `M·v` column-vector math, so the unproject
  reads `Σ m[c*4+r]·v[c]` and `viewProj = mtxMul(proj, view)`; `nearZ` chosen
  from `getCaps()->homogeneousDepth`.
- **Post-chain V-flip (bgfx/15):** the fullscreen triangle flips V when
  `!getCaps()->originBottomLeft` (Metal/D3D) so the composite isn't upside-down
  — same fix the 3D RTT recipe (12) applies in-shader.
- **Skybox / shadow pipelines (3D/14, 3D/16):** set `CULLMODE_NONE` to match the
  existing recipes (which never cull) rather than introduce a winding
  dependency; the skybox uses `LESS_OR_EQUAL` + no depth write + `position.xyww`.
- Kept the working Prism setup (`prism.min.js` + `prism-c.min.js` +
  `prism-cpp.min.js`, in that order) on every new page.
