Recipe 23 — Stencil Reflections & Outlines

Put the stencil buffer to work. Mark a floor's pixels, then draw the scene mirrored only there for a planar reflection — and learn the same mask trick that produces selection outlines.

What you'll learn

  • What the stencil buffer is and how bgfx::setStencil reads and writes it.
  • Marking a region (the floor) with a stencil reference value.
  • Drawing reflected geometry gated by STENCIL_TEST_EQUAL so it stays inside the mirror.
  • Why a mirror flips winding — and the same masking idea behind outlines.

Prerequisites

Recipe 08 — Depth & Render State for bgfx::setState and depth, and recipe 07 for the cube. The stencil buffer rides alongside depth in the same D24S8 attachment.

Walkthrough

The stencil buffer

Alongside depth, each pixel carries a small integer stencil value. You can write it during one draw and test against it during another, masking where later geometry is allowed to land. It's the classic tool for mirrors, portals, decals and outlines.

Order matters — make the view sequential

A stencil mirror is a strict sequence: mark, reflect, composite. bgfx sorts draw calls within a view by default, so we switch the view to Sequential to guarantee submission order. 

bgfx::setViewMode(0, bgfx::ViewMode::Sequential);
bgfx::setViewClear(0, BGFX_CLEAR_COLOR | BGFX_CLEAR_DEPTH | BGFX_CLEAR_STENCIL, 0x0a0c14ff, 1.0f, 0);

Step 1 — mark the floor into stencil

Draw the floor with colour and depth writes off, replacing the stencil with 1 wherever the floor passes the depth test. Now the floor's visible pixels carry a 1; everything else stays 0. 

bgfx::setStencil(BGFX_STENCIL_TEST_ALWAYS
               | BGFX_STENCIL_FUNC_REF(1) | BGFX_STENCIL_FUNC_RMASK(0xff)
               | BGFX_STENCIL_OP_FAIL_S_KEEP | BGFX_STENCIL_OP_FAIL_Z_KEEP
               | BGFX_STENCIL_OP_PASS_Z_REPLACE);
bgfx::setState(BGFX_STATE_DEPTH_TEST_LESS);     // no colour, no depth write

Step 2 — draw the reflected scene where stencil == 1

Mirror each object about the floor plane (negate Y around it, scale Y by −1) and draw it testing STENCIL_TEST_EQUAL against 1 — so the reflection can only appear inside the floor. Mirroring flips triangle winding, so cull the opposite face. 

bgfx::setStencil(BGFX_STENCIL_TEST_EQUAL | BGFX_STENCIL_FUNC_REF(1) | BGFX_STENCIL_FUNC_RMASK(0xff));
bgfx::setState(BGFX_STATE_WRITE_RGB | BGFX_STATE_WRITE_A | BGFX_STATE_WRITE_Z
             | BGFX_STATE_DEPTH_TEST_LESS | BGFX_STATE_CULL_CCW);   // flipped winding

Step 3 — composite the floor, then the real scene

Draw the floor again, this time translucent, so the reflection shows through it tinted. Finally draw the upright scene normally. The result: a glossy floor mirroring the cubes above it.

Backend conventions vary. Like shadow mapping, the exact winding to cull and the sign of the mirror depend on homogeneousDepth / clip-space handedness across D3D, Metal, Vulkan and GL. If the reflection culls away or shows inside-out, flip CULL_CCW ↔ CULL_CW — the logic is unchanged.

Complete listing

Three cubes hover over a mirror floor that reflects them via the stencil buffer. Native-handle / loadProgram helpers identical to recipe 03 (elided). Shaders: vs_solid / fs_solid. 

/*
 * bgfx/23-stencil-reflections.cpp — planar reflection via the stencil buffer.
 * Native-handle + loadProgram helpers identical to recipe 03 (elided).
 * Shaders: vs_solid / fs_solid.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <bgfx/bgfx.h>
#include <bgfx/platform.h>
#include <bx/math.h>
#include <cstdint>

static void *nativeWindowHandle(SDL_Window *);
static void *nativeDisplayHandle(SDL_Window *);
static bgfx::ProgramHandle loadProgram(const char *vs, const char *fs);

static const float FLOOR_Y = -1.5f;

struct PNVertex { float px, py, pz; float nx, ny, nz; };
static const PNVertex kCube[24] = {
    {  0.5f,-0.5f,-0.5f, 1,0,0 },{  0.5f, 0.5f,-0.5f, 1,0,0 },{  0.5f, 0.5f, 0.5f, 1,0,0 },{  0.5f,-0.5f, 0.5f, 1,0,0 },
    { -0.5f,-0.5f, 0.5f,-1,0,0 },{ -0.5f, 0.5f, 0.5f,-1,0,0 },{ -0.5f, 0.5f,-0.5f,-1,0,0 },{ -0.5f,-0.5f,-0.5f,-1,0,0 },
    { -0.5f, 0.5f,-0.5f, 0,1,0 },{ -0.5f, 0.5f, 0.5f, 0,1,0 },{  0.5f, 0.5f, 0.5f, 0,1,0 },{  0.5f, 0.5f,-0.5f, 0,1,0 },
    { -0.5f,-0.5f, 0.5f, 0,-1,0 },{ -0.5f,-0.5f,-0.5f, 0,-1,0 },{  0.5f,-0.5f,-0.5f, 0,-1,0 },{  0.5f,-0.5f, 0.5f, 0,-1,0 },
    { -0.5f,-0.5f, 0.5f, 0,0,1 },{  0.5f,-0.5f, 0.5f, 0,0,1 },{  0.5f, 0.5f, 0.5f, 0,0,1 },{ -0.5f, 0.5f, 0.5f, 0,0,1 },
    {  0.5f,-0.5f,-0.5f, 0,0,-1 },{ -0.5f,-0.5f,-0.5f, 0,0,-1 },{ -0.5f, 0.5f,-0.5f, 0,0,-1 },{  0.5f, 0.5f,-0.5f, 0,0,-1 },
};
static const uint16_t kIdx[36] = {
    0,1,2, 0,2,3, 4,5,6, 4,6,7, 8,9,10, 8,10,11,
    12,13,14, 12,14,15, 16,17,18, 16,18,19, 20,21,22, 20,22,23,
};
// A floor quad on the y = FLOOR_Y plane, normal +Y.
static const PNVertex kFloor[4] = {
    { -6, FLOOR_Y, -6, 0,1,0 }, {  6, FLOOR_Y, -6, 0,1,0 },
    {  6, FLOOR_Y,  6, 0,1,0 }, { -6, FLOOR_Y,  6, 0,1,0 },
};
static const uint16_t kFloorIdx[6] = { 0, 1, 2, 0, 2, 3 };

struct AppState {
    SDL_Window *window = nullptr; int width = 1280, height = 720;
    bgfx::VertexLayout layout;
    bgfx::VertexBufferHandle cubeVbh = BGFX_INVALID_HANDLE, floorVbh = BGFX_INVALID_HANDLE;
    bgfx::IndexBufferHandle  cubeIbh = BGFX_INVALID_HANDLE, floorIbh = BGFX_INVALID_HANDLE;
    bgfx::ProgramHandle program = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle u_color = BGFX_INVALID_HANDLE;
    Uint64 startNs = 0;
};

static SDL_AppResult fail(const char *what) { SDL_Log("%s: %s", what, SDL_GetError()); return SDL_APP_FAILURE; }

// Per-cube colours and angular offsets for the three hovering cubes.
static const float kCol[3][3] = { {0.95f,0.5f,0.4f}, {0.45f,0.8f,0.95f}, {0.7f,0.95f,0.5f} };

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("bgfx Stencil Reflections", "1.0", "com.example.sdl3.bgfx.stencil");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("SDL_Init");
    AppState *st = new AppState(); *appstate = st;
    st->window = SDL_CreateWindow("bgfx — Stencil Reflections", st->width, st->height,
                                  SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY);
    if (!st->window) return fail("SDL_CreateWindow");
    SDL_GetWindowSizeInPixels(st->window, &st->width, &st->height);

    bgfx::renderFrame();
    bgfx::Init init;
    init.type = bgfx::RendererType::Count;
    init.platformData.nwh = nativeWindowHandle(st->window);
    init.platformData.ndt = nativeDisplayHandle(st->window);
    init.resolution.width = (uint32_t)st->width; init.resolution.height = (uint32_t)st->height;
    init.resolution.reset = BGFX_RESET_VSYNC;
    if (!bgfx::init(init)) return fail("bgfx::init");

    bgfx::setViewMode(0, bgfx::ViewMode::Sequential);                 // honour submit order
    bgfx::setViewClear(0, BGFX_CLEAR_COLOR | BGFX_CLEAR_DEPTH | BGFX_CLEAR_STENCIL, 0x0a0c14ff, 1.0f, 0);

    st->layout.begin()
        .add(bgfx::Attrib::Position, 3, bgfx::AttribType::Float)
        .add(bgfx::Attrib::Normal,   3, bgfx::AttribType::Float).end();
    st->cubeVbh  = bgfx::createVertexBuffer(bgfx::makeRef(kCube, sizeof(kCube)), st->layout);
    st->cubeIbh  = bgfx::createIndexBuffer (bgfx::makeRef(kIdx, sizeof(kIdx)));
    st->floorVbh = bgfx::createVertexBuffer(bgfx::makeRef(kFloor, sizeof(kFloor)), st->layout);
    st->floorIbh = bgfx::createIndexBuffer (bgfx::makeRef(kFloorIdx, sizeof(kFloorIdx)));
    st->program  = loadProgram("vs_solid", "fs_solid");
    st->u_color  = bgfx::createUniform("u_color", bgfx::UniformType::Vec4);
    if (!bgfx::isValid(st->program)) return fail("loadProgram");

    st->startNs = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_WINDOW_PIXEL_SIZE_CHANGED) {
        st->width = e->window.data1; st->height = e->window.data2;
        bgfx::reset((uint32_t)st->width, (uint32_t)st->height, BGFX_RESET_VSYNC);
    }
    return SDL_APP_CONTINUE;
}

// Submit one cube with an upright or mirrored model matrix.
static void submitCube(AppState *st, int i, float t, bool reflected, uint64_t state, uint32_t stencil)
{
    float x = 2.4f * bx::cos(t * 0.5f + i * 2.094f);
    float y = 0.4f + 0.6f * bx::sin(t + i);
    float z = 2.4f * bx::sin(t * 0.5f + i * 2.094f);
    float ang = t + i;

    float rot[16]; bx::mtxRotateY(rot, ang);
    float model[16];
    if (!reflected) {
        float trn[16]; bx::mtxTranslate(trn, x, y, z);
        bx::mtxMul(model, rot, trn);
    } else {
        float scl[16], tmp[16], trn[16];
        bx::mtxScale(scl, 1.0f, -1.0f, 1.0f);                 // mirror about the plane
        bx::mtxMul(tmp, rot, scl);
        bx::mtxTranslate(trn, x, 2.0f * FLOOR_Y - y, z);      // reflected height
        bx::mtxMul(model, tmp, trn);
    }
    float col[4] = { kCol[i][0], kCol[i][1], kCol[i][2], 1.0f };
    bgfx::setUniform(st->u_color, col);
    bgfx::setTransform(model);
    bgfx::setVertexBuffer(0, st->cubeVbh);
    bgfx::setIndexBuffer(st->cubeIbh);
    if (stencil) bgfx::setStencil(stencil);
    bgfx::setState(state);
    bgfx::submit(0, st->program);
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (float)(SDL_GetTicksNS() - st->startNs) / 1.0e9f;

    bgfx::setViewRect(0, 0, 0, (uint16_t)st->width, (uint16_t)st->height);
    const bx::Vec3 at = { 0, -0.3f, 0 }, eye = { 0, 2.2f, -7.5f };
    float view[16], proj[16];
    bx::mtxLookAt(view, eye, at);
    bx::mtxProj(proj, 55.0f, float(st->width)/float(st->height), 0.1f, 100.0f, bgfx::getCaps()->homogeneousDepth);
    bgfx::setViewTransform(0, view, proj);

    float identity[16]; bx::mtxIdentity(identity);
    float floorCol[4] = { 0.15f, 0.17f, 0.22f, 1.0f };

    // --- Step 1: mark the floor into the stencil buffer (no colour / depth write) ---
    bgfx::setUniform(st->u_color, floorCol);
    bgfx::setTransform(identity);
    bgfx::setVertexBuffer(0, st->floorVbh);
    bgfx::setIndexBuffer(st->floorIbh);
    bgfx::setStencil(BGFX_STENCIL_TEST_ALWAYS
                   | BGFX_STENCIL_FUNC_REF(1) | BGFX_STENCIL_FUNC_RMASK(0xff)
                   | BGFX_STENCIL_OP_FAIL_S_KEEP | BGFX_STENCIL_OP_FAIL_Z_KEEP
                   | BGFX_STENCIL_OP_PASS_Z_REPLACE);
    bgfx::setState(BGFX_STATE_DEPTH_TEST_LESS);
    bgfx::submit(0, st->program);

    // --- Step 2: reflected cubes, only where stencil == 1, flipped winding ---
    uint64_t reflState = BGFX_STATE_WRITE_RGB | BGFX_STATE_WRITE_A | BGFX_STATE_WRITE_Z
                       | BGFX_STATE_DEPTH_TEST_LESS | BGFX_STATE_CULL_CCW;
    uint32_t reflStencil = BGFX_STENCIL_TEST_EQUAL | BGFX_STENCIL_FUNC_REF(1) | BGFX_STENCIL_FUNC_RMASK(0xff)
                         | BGFX_STENCIL_OP_FAIL_S_KEEP | BGFX_STENCIL_OP_FAIL_Z_KEEP | BGFX_STENCIL_OP_PASS_Z_KEEP;
    for (int i = 0; i < 3; ++i) submitCube(st, i, t, /*reflected=*/true, reflState, reflStencil);

    // --- Step 3: translucent floor over the reflection (no depth write so it blends in place) ---
    float floorTint[4] = { 0.15f, 0.17f, 0.22f, 0.55f };
    bgfx::setUniform(st->u_color, floorTint);
    bgfx::setTransform(identity);
    bgfx::setVertexBuffer(0, st->floorVbh);
    bgfx::setIndexBuffer(st->floorIbh);
    bgfx::setState(BGFX_STATE_WRITE_RGB | BGFX_STATE_WRITE_A | BGFX_STATE_DEPTH_TEST_LESS | BGFX_STATE_BLEND_ALPHA);
    bgfx::submit(0, st->program);

    // --- Step 4: the upright cubes, normal state ---
    for (int i = 0; i < 3; ++i) submitCube(st, i, t, /*reflected=*/false, BGFX_STATE_DEFAULT, 0);

    bgfx::frame();
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (bgfx::isValid(st->u_color))  bgfx::destroy(st->u_color);
    if (bgfx::isValid(st->floorIbh)) bgfx::destroy(st->floorIbh);
    if (bgfx::isValid(st->floorVbh)) bgfx::destroy(st->floorVbh);
    if (bgfx::isValid(st->cubeIbh))  bgfx::destroy(st->cubeIbh);
    if (bgfx::isValid(st->cubeVbh))  bgfx::destroy(st->cubeVbh);
    if (bgfx::isValid(st->program))  bgfx::destroy(st->program);
    bgfx::shutdown();
    SDL_DestroyWindow(st->window);
    delete st;
}

# vs_solid.sc / fs_solid.sc — flat material colour with one directional light
# (vs)
$input  a_position, a_normal
$output v_normal
#include "bgfx_shader.sh"
void main() {
    vec4 wpos   = mul(u_model[0], vec4(a_position, 1.0));
    v_normal    = normalize(mul(u_model[0], vec4(a_normal, 0.0)).xyz);
    gl_Position = mul(u_viewProj, wpos);
}
# (fs)
$input v_normal
#include "bgfx_shader.sh"
uniform vec4 u_color;
void main() {
    vec3  L = normalize(vec3(0.4, 1.0, -0.3));
    float d = max(dot(normalize(v_normal), L), 0.0);
    gl_FragColor = vec4(u_color.xyz * (0.25 + 0.75 * d), u_color.w);
}

Try it yourself

  1. Selection outline with the same buffer: draw an object writing stencil = 1, then draw a slightly scaled-up copy with STENCIL_TEST_NOTEQUAL 1 in a flat colour and depth test off — a clean silhouette halo.
  2. Fade the reflection with distance: in fs_solid darken by world height so the mirror image dims as it recedes under the floor.
  3. Tilt the mirror: reflect about an arbitrary plane by building a true reflection matrix instead of the axis-aligned scale(1,-1,1).
  4. Clip below the floor explicitly: add a user clip plane (or discard v_wpos.y > FLOOR_Y in the reflected pass) so nothing pokes above the mirror.
