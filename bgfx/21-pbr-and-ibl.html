Recipe 21 — PBR & Image-Based Lighting

Trade ad-hoc Phong for physically-based shading. A Cook-Torrance BRDF with metallic and roughness inputs, lit by analytic point lights and a cubemap environment, across a grid of spheres that sweeps the whole material space.

What you'll learn

  • The metallic/roughness PBR inputs and what each one physically means.
  • The Cook-Torrance specular BRDF: the D, G and F terms.
  • Energy conservation — splitting light into diffuse and specular so nothing is created.
  • Cheap image-based lighting from a cubemap for ambient diffuse + specular.

Prerequisites

Recipe 17 — Skybox & Cubemaps for the environment cubemap and recipe 18 for per-fragment world-space normals. PBR replaces the Blinn-Phong of the earlier recipes with an energy-conserving model.

Walkthrough

Metallic and roughness

PBR describes a surface with two scalars. Metallic says whether the surface is a dielectric (plastic, 0) or a conductor (metal, 1) — metals have no diffuse and tint their reflections by the base colour. Roughness says how polished it is: 0 is a mirror, 1 is chalk. Those two knobs cover an enormous range of real materials.

The Cook-Torrance BRDF

Specular reflection is the product of three terms: D, the normal distribution (how many microfacets point at the half-vector — GGX here); G, geometry/self-shadowing of those microfacets; and F, Fresnel (reflectance rising at grazing angles). 

# fs_pbr.sc — Cook-Torrance terms (excerpt)
float distributionGGX(vec3 N, vec3 H, float rough) {
    float a = rough*rough, a2 = a*a;
    float ndh = max(dot(N, H), 0.0);
    float d = ndh*ndh*(a2 - 1.0) + 1.0;
    return a2 / (PI * d * d);
}
float geometrySmith(vec3 N, vec3 V, vec3 L, float rough) {
    float k = (rough + 1.0)*(rough + 1.0) / 8.0;
    float gv = max(dot(N,V),0.0) / (max(dot(N,V),0.0)*(1.0-k)+k);
    float gl = max(dot(N,L),0.0) / (max(dot(N,L),0.0)*(1.0-k)+k);
    return gv * gl;
}
vec3 fresnelSchlick(float ct, vec3 F0) { return F0 + (1.0 - F0)*pow(1.0 - ct, 5.0); }

Energy conservation

Whatever fraction F reflects specularly can't also diffuse, so the diffuse weight is (1 - F), further killed by metallic (metals have no diffuse). The reflectance at normal incidence F0 is 0.04 for dielectrics and the base colour for metals. 

# per analytic light
vec3 F0 = mix(vec3_splat(0.04), albedo, metallic);
vec3 F  = fresnelSchlick(max(dot(H, V), 0.0), F0);
vec3 spec = (D * G * F) / (4.0 * max(dot(N,V),0.0) * max(dot(N,L),0.0) + 0.001);
vec3 kd   = (vec3_splat(1.0) - F) * (1.0 - metallic);       // energy left for diffuse
Lo += (kd * albedo / PI + spec) * radiance * max(dot(N, L), 0.0);

Image-based lighting from the cubemap

Analytic lights alone leave shadows pitch black. Real surfaces are also lit by their surroundings. A cheap approximation samples the environment cubemap along the normal for ambient diffuse and along the reflection for specular, blending toward the diffuse as roughness rises (standing in for a proper prefiltered mip chain). 

vec3 irradiance = textureCube(s_env, N).xyz;                 // ambient diffuse
vec3 prefilter  = mix(textureCube(s_env, reflect(-V, N)).xyz, irradiance, rough);
vec3 ambient    = (1.0 - metallic) * irradiance * albedo + prefilter * F;
This is a teaching-grade IBL. Production IBL precomputes an irradiance map and a roughness-prefiltered specular mip chain plus a BRDF lookup table. The mix-to-diffuse shortcut here keeps the recipe self-contained while still showing the split-sum idea.

Complete listing

A 5×5 grid of spheres: metallic rises down the rows, roughness rises across the columns, all lit by two point lights and a synthesised cubemap environment. Native-handle / loadProgram helpers are identical to recipe 03 (elided). Shaders: vs_pbr / fs_pbr. 

/*
 * bgfx/21-pbr-and-ibl.cpp — Cook-Torrance PBR + cubemap IBL on a material grid.
 * Native-handle + loadProgram helpers identical to recipe 03 (elided).
 * Shaders: vs_pbr / fs_pbr.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <bgfx/bgfx.h>
#include <bgfx/platform.h>
#include <bx/math.h>
#include <cstdint>
#include <vector>

static void *nativeWindowHandle(SDL_Window *);
static void *nativeDisplayHandle(SDL_Window *);
static bgfx::ProgramHandle loadProgram(const char *vs, const char *fs);

struct PNVertex { float px, py, pz; float nx, ny, nz; };

// A UV sphere: positions double as normals (unit sphere centred at origin).
static void makeSphere(std::vector<PNVertex> &v, std::vector<uint16_t> &idx, int seg, int rings)
{
    for (int r = 0; r <= rings; ++r) {
        float phi = (float)r / rings * 3.14159265f;          // 0..PI
        for (int s = 0; s <= seg; ++s) {
            float theta = (float)s / seg * 6.2831853f;        // 0..2PI
            float x = SDL_sinf(phi) * SDL_cosf(theta);
            float y = SDL_cosf(phi);
            float z = SDL_sinf(phi) * SDL_sinf(theta);
            v.push_back({ x, y, z, x, y, z });
        }
    }
    int stride = seg + 1;
    for (int r = 0; r < rings; ++r)
        for (int s = 0; s < seg; ++s) {
            uint16_t a = (uint16_t)(r * stride + s);
            uint16_t b = (uint16_t)((r + 1) * stride + s);
            idx.push_back(a); idx.push_back(b); idx.push_back(a + 1);
            idx.push_back(a + 1); idx.push_back(b); idx.push_back(b + 1);
        }
}

// Synthesise a 6-face environment cubemap (+X -X +Y -Y +Z -Z), RGBA8 (0xAABBGGRR).
static bgfx::TextureHandle makeEnvCube()
{
    const uint32_t F = 64;
    const uint8_t base[6][3] = {
        {120,90,70}, {70,90,120}, {150,170,210}, {40,35,32}, {110,120,90}, {90,80,110}
    };
    uint32_t *px = (uint32_t *)SDL_malloc(F * F * 4 * 6);
    for (int f = 0; f < 6; ++f)
        for (uint32_t y = 0; y < F; ++y)
            for (uint32_t x = 0; x < F; ++x) {
                float v = (float)y / (F - 1);
                float k = 0.6f + 0.5f * (1.0f - v);          // brighter toward the top
                uint8_t r = (uint8_t)SDL_min(255.0f, base[f][0] * k);
                uint8_t g = (uint8_t)SDL_min(255.0f, base[f][1] * k);
                uint8_t b = (uint8_t)SDL_min(255.0f, base[f][2] * k);
                px[f*F*F + y*F + x] = 0xff000000u | (uint32_t(b)<<16) | (uint32_t(g)<<8) | uint32_t(r);
            }
    const bgfx::Memory *mem = bgfx::copy(px, F * F * 4 * 6);
    SDL_free(px);
    return bgfx::createTextureCube((uint16_t)F, false, 1, bgfx::TextureFormat::RGBA8, 0, mem);
}

struct AppState {
    SDL_Window *window = nullptr; int width = 1280, height = 720;
    bgfx::VertexLayout layout;
    bgfx::VertexBufferHandle vbh = BGFX_INVALID_HANDLE;
    bgfx::IndexBufferHandle  ibh = BGFX_INVALID_HANDLE;
    bgfx::ProgramHandle program = BGFX_INVALID_HANDLE;
    bgfx::TextureHandle env = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle s_env = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle u_eyePos = BGFX_INVALID_HANDLE, u_material = BGFX_INVALID_HANDLE, u_baseColor = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle u_lightPos = BGFX_INVALID_HANDLE, u_lightCol = BGFX_INVALID_HANDLE;
    uint32_t numIndices = 0; Uint64 startNs = 0;
};

static SDL_AppResult fail(const char *what) { SDL_Log("%s: %s", what, SDL_GetError()); return SDL_APP_FAILURE; }

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("bgfx PBR", "1.0", "com.example.sdl3.bgfx.pbr");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("SDL_Init");
    AppState *st = new AppState(); *appstate = st;
    st->window = SDL_CreateWindow("bgfx — PBR & IBL", st->width, st->height,
                                  SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY);
    if (!st->window) return fail("SDL_CreateWindow");
    SDL_GetWindowSizeInPixels(st->window, &st->width, &st->height);

    bgfx::renderFrame();
    bgfx::Init init;
    init.type = bgfx::RendererType::Count;
    init.platformData.nwh = nativeWindowHandle(st->window);
    init.platformData.ndt = nativeDisplayHandle(st->window);
    init.resolution.width = (uint32_t)st->width; init.resolution.height = (uint32_t)st->height;
    init.resolution.reset = BGFX_RESET_VSYNC;
    if (!bgfx::init(init)) return fail("bgfx::init");
    bgfx::setViewClear(0, BGFX_CLEAR_COLOR | BGFX_CLEAR_DEPTH, 0x0a0c14ff, 1.0f, 0);

    st->layout.begin()
        .add(bgfx::Attrib::Position, 3, bgfx::AttribType::Float)
        .add(bgfx::Attrib::Normal,   3, bgfx::AttribType::Float).end();
    std::vector<PNVertex> verts; std::vector<uint16_t> idx;
    makeSphere(verts, idx, 32, 20);
    st->numIndices = (uint32_t)idx.size();
    st->vbh = bgfx::createVertexBuffer(bgfx::copy(verts.data(), uint32_t(verts.size()*sizeof(PNVertex))), st->layout);
    st->ibh = bgfx::createIndexBuffer (bgfx::copy(idx.data(),   uint32_t(idx.size()*sizeof(uint16_t))));
    st->program = loadProgram("vs_pbr", "fs_pbr");
    st->env = makeEnvCube();
    st->s_env      = bgfx::createUniform("s_env",      bgfx::UniformType::Sampler);
    st->u_eyePos   = bgfx::createUniform("u_eyePos",   bgfx::UniformType::Vec4);
    st->u_material = bgfx::createUniform("u_material", bgfx::UniformType::Vec4);
    st->u_baseColor= bgfx::createUniform("u_baseColor",bgfx::UniformType::Vec4);
    st->u_lightPos = bgfx::createUniform("u_lightPos", bgfx::UniformType::Vec4, 2);
    st->u_lightCol = bgfx::createUniform("u_lightCol", bgfx::UniformType::Vec4, 2);
    if (!bgfx::isValid(st->program)) return fail("loadProgram");

    st->startNs = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_WINDOW_PIXEL_SIZE_CHANGED) {
        st->width = e->window.data1; st->height = e->window.data2;
        bgfx::reset((uint32_t)st->width, (uint32_t)st->height, BGFX_RESET_VSYNC);
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (float)(SDL_GetTicksNS() - st->startNs) / 1.0e9f;

    bgfx::setViewRect(0, 0, 0, (uint16_t)st->width, (uint16_t)st->height);
    const bx::Vec3 at = { 0, 0, 0 }, eye = { 0, 0, -13.0f };
    float view[16], proj[16];
    bx::mtxLookAt(view, eye, at);
    bx::mtxProj(proj, 50.0f, float(st->width)/float(st->height), 0.1f, 100.0f, bgfx::getCaps()->homogeneousDepth);
    bgfx::setViewTransform(0, view, proj);

    float eyev[4] = { eye.x, eye.y, eye.z, 0 };
    bgfx::setUniform(st->u_eyePos, eyev);
    float lpos[2][4] = { { 6*bx::cos(t), 6.0f, -6.0f, 0 }, { -6*bx::cos(t), -6.0f, -6.0f, 0 } };
    float lcol[2][4] = { { 1.0f, 0.9f, 0.8f, 60.0f }, { 0.6f, 0.7f, 1.0f, 60.0f } };  // .w = intensity
    bgfx::setUniform(st->u_lightPos, lpos, 2);
    bgfx::setUniform(st->u_lightCol, lcol, 2);
    float albedo[4] = { 0.95f, 0.64f, 0.54f, 1.0f };           // a copper-ish base
    bgfx::setUniform(st->u_baseColor, albedo);

    const int ROWS = 5, COLS = 5;
    for (int r = 0; r < ROWS; ++r)
        for (int c = 0; c < COLS; ++c) {
            float metallic  = (float)r / (ROWS - 1);
            float roughness = SDL_clamp((float)c / (COLS - 1), 0.05f, 1.0f);
            float mat[4] = { metallic, roughness, 0, 0 };
            bgfx::setUniform(st->u_material, mat);

            float model[16];
            bx::mtxTranslate(model, (c - 2) * 2.5f, (r - 2) * 2.5f, 0.0f);
            bgfx::setTransform(model);
            bgfx::setVertexBuffer(0, st->vbh);
            bgfx::setIndexBuffer(st->ibh);
            bgfx::setTexture(0, st->s_env, st->env);
            bgfx::setState(BGFX_STATE_DEFAULT);
            bgfx::submit(0, st->program);
        }

    bgfx::frame();
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    bgfx::UniformHandle us[] = { st->u_lightCol, st->u_lightPos, st->u_baseColor, st->u_material, st->u_eyePos, st->s_env };
    for (bgfx::UniformHandle u : us) if (bgfx::isValid(u)) bgfx::destroy(u);
    if (bgfx::isValid(st->env))     bgfx::destroy(st->env);
    if (bgfx::isValid(st->ibh))     bgfx::destroy(st->ibh);
    if (bgfx::isValid(st->vbh))     bgfx::destroy(st->vbh);
    if (bgfx::isValid(st->program)) bgfx::destroy(st->program);
    bgfx::shutdown();
    SDL_DestroyWindow(st->window);
    delete st;
}

# fs_pbr.sc — Cook-Torrance + cubemap IBL
$input v_wpos, v_normal
#include "bgfx_shader.sh"
SAMPLERCUBE(s_env, 0);
uniform vec4 u_eyePos;
uniform vec4 u_material;        // x = metallic, y = roughness
uniform vec4 u_baseColor;
uniform vec4 u_lightPos[2];
uniform vec4 u_lightCol[2];     // .w = intensity
#define PI 3.14159265

float distributionGGX(vec3 N, vec3 H, float rough) {
    float a = rough*rough, a2 = a*a;
    float ndh = max(dot(N, H), 0.0);
    float d = ndh*ndh*(a2 - 1.0) + 1.0;
    return a2 / (PI * d * d);
}
float geometrySmith(vec3 N, vec3 V, vec3 L, float rough) {
    float k = (rough + 1.0)*(rough + 1.0) / 8.0;
    float nv = max(dot(N, V), 0.0), nl = max(dot(N, L), 0.0);
    return (nv / (nv*(1.0 - k) + k)) * (nl / (nl*(1.0 - k) + k));
}
vec3 fresnelSchlick(float ct, vec3 F0) { return F0 + (1.0 - F0) * pow(1.0 - ct, 5.0); }

void main() {
    vec3 N = normalize(v_normal);
    vec3 V = normalize(u_eyePos.xyz - v_wpos);
    vec3 albedo = u_baseColor.xyz;
    float metallic = u_material.x, rough = u_material.y;
    vec3 F0 = mix(vec3_splat(0.04), albedo, metallic);

    vec3 Lo = vec3_splat(0.0);
    for (int i = 0; i < 2; ++i) {
        vec3 L = normalize(u_lightPos[i].xyz - v_wpos);
        vec3 H = normalize(V + L);
        float dist = length(u_lightPos[i].xyz - v_wpos);
        vec3 radiance = u_lightCol[i].xyz * (u_lightCol[i].w / (dist*dist));
        float D = distributionGGX(N, H, rough);
        float G = geometrySmith(N, V, L, rough);
        vec3  F = fresnelSchlick(max(dot(H, V), 0.0), F0);
        vec3 spec = (D * G * F) / (4.0 * max(dot(N,V),0.0) * max(dot(N,L),0.0) + 0.001);
        vec3 kd = (vec3_splat(1.0) - F) * (1.0 - metallic);
        Lo += (kd * albedo / PI + spec) * radiance * max(dot(N, L), 0.0);
    }

    vec3 F = fresnelSchlick(max(dot(N, V), 0.0), F0);
    vec3 irradiance = textureCube(s_env, N).xyz;
    vec3 prefilter  = mix(textureCube(s_env, reflect(-V, N)).xyz, irradiance, rough);
    vec3 ambient = (vec3_splat(1.0) - F) * (1.0 - metallic) * irradiance * albedo + prefilter * F;

    vec3 color = ambient + Lo;
    color = color / (color + vec3_splat(1.0));      // tone map
    color = pow(color, vec3_splat(1.0 / 2.2));       // gamma
    gl_FragColor = vec4(color, 1.0);
}

Try it yourself

  1. Draw the skybox behind the grid (recipe 17) so the IBL visibly matches the environment the spheres reflect.
  2. Add a third coloured rim light and watch metals pick up its tint while dielectrics stay mostly their base colour — the metallic split in action.
  3. Feed albedo, metallic and roughness from textures instead of uniforms for per-texel materials (a true PBR material set).
  4. Replace the mix-to-diffuse IBL with a real prefiltered cubemap: generate mips and sample textureCubeLod(s_env, R, rough * maxMip).
