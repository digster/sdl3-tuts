Recipe 18 — Normal Mapping

Fake the bumps. A flat quad gains brick-like relief by perturbing its per-pixel normal from a texture — tangent space, a TBN matrix, and Blinn-Phong doing the rest.

What you'll learn

  • Why surface detail lives in tangent space, and what the per-vertex tangent buys you.
  • Adding bgfx::Attrib::Normal and bgfx::Attrib::Tangent to the layout and to varying.def.sc.
  • Generating a procedural normal map in RGBA8 — and getting the ABGR packing of an encoded normal right.
  • Building a TBN matrix from normal + tangent + computed bitangent.
  • Decoding a texel into a normal (n = texel.xyz * 2 - 1) and lighting it with Blinn-Phong.

Prerequisites

Textures and sampler uniforms from recipe 09, and the diffuse lighting introduced in the capstone (recipe 12). New shader pair: vs_normalmap / fs_normalmap. This mirrors 3D recipe 15.

Walkthrough

Why tangent space

A normal map stores a perturbed surface normal per texel. But stored in what frame? If we baked world-space normals into the texture, the map would only be valid for one fixed orientation of the surface. Instead we store normals in tangent space: a local frame that follows the surface, with the texture's U axis as the tangent, V as the bitangent, and the geometric normal as Z. A flat map (mostly pointing "out", i.e. +Z) then works on any triangle, however it's oriented — we just need the per-fragment transform back into world space.

The extra attributes

Lighting already needed a normal (recipe 12). Tangent-space lighting adds one more per-vertex vector: the tangent, pointing along the texture's U direction across the surface. The bitangent is the cross product of the two, so we don't store it. 

struct PNTUVertex {                 // position, normal, tangent, uv
    float px, py, pz;
    float nx, ny, nz;
    float tx, ty, tz;
    float u, v;
};

A normal map, built procedurally

A normal map is an ordinary RGBA8 texture whose RGB encodes a unit normal: each channel maps [-1,1] onto [0,255] via byte = (component * 0.5 + 0.5) * 255. A perfectly flat normal (0,0,1) therefore encodes to R=128, G=128, B=255 — the familiar lavender-blue of every normal map. We synthesise a brick relief: tilt the normal left/right near the mortar lines so the grooves catch the light. 

static uint32_t encodeNormal(float nx, float ny, float nz) {
    float len = SDL_sqrtf(nx*nx + ny*ny + nz*nz);
    nx /= len; ny /= len; nz /= len;
    uint8_t r = (uint8_t)((nx * 0.5f + 0.5f) * 255.0f);
    uint8_t g = (uint8_t)((ny * 0.5f + 0.5f) * 255.0f);
    uint8_t b = (uint8_t)((nz * 0.5f + 0.5f) * 255.0f);
    // RGBA8 little-endian packs as 0xAABBGGRR.
    return 0xff000000u | (uint32_t(b) << 16) | (uint32_t(g) << 8) | uint32_t(r);
}

static bgfx::TextureHandle makeBrickNormalMap() {
    const uint32_t kSize = 256;
    uint32_t *px = (uint32_t *)SDL_malloc(kSize * kSize * 4);
    for (uint32_t y = 0; y < kSize; ++y)
        for (uint32_t x = 0; x < kSize; ++x) {
            // Brick lattice with half-offset rows; mortar gaps tilt the normal.
            uint32_t row = y / 32;
            uint32_t sx  = (x + (row & 1) * 32) % 64;
            uint32_t sy  = y % 32;
            float nx = 0.0f, ny = 0.0f, nz = 1.0f;
            if (sx < 4)        nx = -0.6f;   // left mortar edge tilts -X
            else if (sx > 59)  nx =  0.6f;   // right edge tilts +X
            if (sy < 4)        ny = -0.6f;
            else if (sy > 27)  ny =  0.6f;
            px[y * kSize + x] = encodeNormal(nx, ny, nz);
        }
    const bgfx::Memory *mem = bgfx::copy(px, kSize * kSize * 4);
    SDL_free(px);
    return bgfx::createTexture2D((uint16_t)kSize, (uint16_t)kSize, false, 1,
                                 bgfx::TextureFormat::RGBA8, 0, mem);
}

TBN in the vertex shader, lighting in the fragment

The vertex shader rotates normal, tangent and bitangent into world space — those three vectors are the columns of the TBN basis. The fragment shader samples the map, decodes the texel to a tangent-space normal, transforms it into world space with TBN, and runs Blinn-Phong. 

# vs_normalmap.sc
$input  a_position, a_normal, a_tangent, a_texcoord0
$output v_wpos, v_texcoord0, v_tangent, v_bitangent, v_normal
#include "bgfx_shader.sh"
void main() {
    vec4 wpos    = mul(u_model[0], vec4(a_position, 1.0));
    v_wpos       = wpos.xyz;
    gl_Position  = mul(u_viewProj, wpos);

    // Rotate the frame into world space (w = 0: direction, no translation).
    v_normal     = normalize(mul(u_model[0], vec4(a_normal,  0.0)).xyz);
    v_tangent    = normalize(mul(u_model[0], vec4(a_tangent, 0.0)).xyz);
    v_bitangent  = cross(v_normal, v_tangent);
    v_texcoord0  = a_texcoord0;
}

# fs_normalmap.sc
$input v_wpos, v_texcoord0, v_tangent, v_bitangent, v_normal
#include "bgfx_shader.sh"
SAMPLER2D(s_normal, 0);
uniform vec4 u_lightPos;        // .xyz = world-space light position
uniform vec4 u_eyePos;          // .xyz = camera position
void main() {
    // Decode the tangent-space normal from the map.
    vec3 texel = texture2D(s_normal, v_texcoord0).xyz;
    vec3 nTS   = normalize(texel * 2.0 - 1.0);

    // TBN: columns tangent, bitangent, normal — transforms TS -> world.
    mat3 tbn = mtxFromCols(normalize(v_tangent),
                           normalize(v_bitangent),
                           normalize(v_normal));
    vec3 N = normalize(mul(tbn, nTS));

    vec3  L    = normalize(u_lightPos.xyz - v_wpos);
    vec3  V    = normalize(u_eyePos.xyz   - v_wpos);
    vec3  H    = normalize(L + V);
    float diff = max(dot(N, L), 0.0);
    float spec = pow(max(dot(N, H), 0.0), 48.0);

    vec3 base = vec3(0.80, 0.35, 0.25);     // brick red
    vec3 col  = base * (0.15 + 0.85 * diff) + vec3_splat(spec) * 0.6;
    gl_FragColor = vec4(col, 1.0);
}
About mtxFromCols for a mat3. bgfx's bgfx_shader.sh provides mtxFromCols for building matrices from column vectors; the vec3 form yields a mat3 whose columns are the arguments, exactly the tangent/bitangent/normal basis we want. If your bgfx version predates the mat3 overload, assemble it by hand: mat3 tbn = mat3(T.x,B.x,N.x, T.y,B.y,N.y, T.z,B.z,N.z); (note the row-wise constructor order) and the rest is unchanged.

Complete listing

The native-handle / loadProgram helpers are unchanged from recipe 03 (elided). We draw a single tilted quad so the relief is easy to read; the same shaders work on any mesh that carries tangents. 

/*
 * bgfx/18-normal-mapping.cpp — tangent-space normal mapping on a lit quad.
 * Native-handle + loadProgram helpers identical to recipe 03 (elided).
 * Shaders: vs_normalmap / fs_normalmap.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <bgfx/bgfx.h>
#include <bgfx/platform.h>
#include <bx/math.h>
#include <cstdint>

static void *nativeWindowHandle(SDL_Window *);
static void *nativeDisplayHandle(SDL_Window *);
static bgfx::ProgramHandle loadProgram(const char *vs, const char *fs);

struct PNTUVertex { float px,py,pz; float nx,ny,nz; float tx,ty,tz; float u,v; };

// A quad in the XY plane: normal +Z, tangent +X, bitangent +Y.
static const PNTUVertex kQuad[4] = {
    { -2.0f, -2.0f, 0.0f,  0,0,1,  1,0,0,  0.0f, 1.0f },
    {  2.0f, -2.0f, 0.0f,  0,0,1,  1,0,0,  1.0f, 1.0f },
    {  2.0f,  2.0f, 0.0f,  0,0,1,  1,0,0,  1.0f, 0.0f },
    { -2.0f,  2.0f, 0.0f,  0,0,1,  1,0,0,  0.0f, 0.0f },
};
static const uint16_t kIdx[6] = { 0, 1, 2,  0, 2, 3 };

struct AppState {
    SDL_Window              *window = nullptr;
    int                      width = 1280, height = 720;
    bgfx::VertexLayout       layout;
    bgfx::VertexBufferHandle vbh = BGFX_INVALID_HANDLE;
    bgfx::IndexBufferHandle  ibh = BGFX_INVALID_HANDLE;
    bgfx::ProgramHandle      program  = BGFX_INVALID_HANDLE;
    bgfx::TextureHandle      normal   = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle      s_normal = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle      u_lightPos = BGFX_INVALID_HANDLE;
    bgfx::UniformHandle      u_eyePos   = BGFX_INVALID_HANDLE;
    Uint64                   startNs = 0;
};

static SDL_AppResult fail(const char *what) { SDL_Log("%s: %s", what, SDL_GetError()); return SDL_APP_FAILURE; }

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("bgfx Normal Mapping", "1.0", "com.example.sdl3.bgfx.nmap");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("SDL_Init");

    AppState *st = new AppState(); *appstate = st;
    st->window = SDL_CreateWindow("bgfx — Normal Mapping", st->width, st->height,
                                  SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY);
    if (!st->window) return fail("SDL_CreateWindow");
    SDL_GetWindowSizeInPixels(st->window, &st->width, &st->height);

    bgfx::renderFrame();
    bgfx::Init init;
    init.type              = bgfx::RendererType::Count;
    init.platformData.nwh  = nativeWindowHandle(st->window);
    init.platformData.ndt  = nativeDisplayHandle(st->window);
    init.resolution.width  = (uint32_t)st->width;
    init.resolution.height = (uint32_t)st->height;
    init.resolution.reset  = BGFX_RESET_VSYNC;
    if (!bgfx::init(init)) return fail("bgfx::init");

    bgfx::setViewClear(0, BGFX_CLEAR_COLOR | BGFX_CLEAR_DEPTH, 0x0d1226ff, 1.0f, 0);

    st->layout.begin()
        .add(bgfx::Attrib::Position,  3, bgfx::AttribType::Float)
        .add(bgfx::Attrib::Normal,    3, bgfx::AttribType::Float)
        .add(bgfx::Attrib::Tangent,   3, bgfx::AttribType::Float)
        .add(bgfx::Attrib::TexCoord0, 2, bgfx::AttribType::Float).end();
    st->vbh        = bgfx::createVertexBuffer(bgfx::makeRef(kQuad, sizeof(kQuad)), st->layout);
    st->ibh        = bgfx::createIndexBuffer (bgfx::makeRef(kIdx, sizeof(kIdx)));
    st->program    = loadProgram("vs_normalmap", "fs_normalmap");
    st->normal     = makeBrickNormalMap();
    st->s_normal   = bgfx::createUniform("s_normal",   bgfx::UniformType::Sampler);
    st->u_lightPos = bgfx::createUniform("u_lightPos", bgfx::UniformType::Vec4);
    st->u_eyePos   = bgfx::createUniform("u_eyePos",   bgfx::UniformType::Vec4);
    if (!bgfx::isValid(st->program)) return fail("loadProgram");

    st->startNs = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_WINDOW_PIXEL_SIZE_CHANGED) {
        st->width = e->window.data1; st->height = e->window.data2;
        bgfx::reset((uint32_t)st->width, (uint32_t)st->height, BGFX_RESET_VSYNC);
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (float)(SDL_GetTicksNS() - st->startNs) / 1.0e9f;

    bgfx::setViewRect(0, 0, 0, (uint16_t)st->width, (uint16_t)st->height);

    const bx::Vec3 at  = { 0.0f, 0.0f,  0.0f };
    const bx::Vec3 eye = { 0.0f, 0.0f, -6.0f };
    float view[16], proj[16];
    bx::mtxLookAt(view, eye, at);
    bx::mtxProj(proj, 60.0f, float(st->width)/float(st->height), 0.1f, 100.0f,
                bgfx::getCaps()->homogeneousDepth);
    bgfx::setViewTransform(0, view, proj);

    // The light orbits the quad in the XY plane; the eye position is fixed.
    float lp[4] = { 4.0f * bx::cos(t), 4.0f * bx::sin(t), -3.0f, 0.0f };
    float ep[4] = { eye.x, eye.y, eye.z, 0.0f };
    bgfx::setUniform(st->u_lightPos, lp);
    bgfx::setUniform(st->u_eyePos,   ep);

    float model[16];
    bx::mtxRotateY(model, 0.3f);                 // tilt so grazing light pops
    bgfx::setTransform(model);

    bgfx::setVertexBuffer(0, st->vbh);
    bgfx::setIndexBuffer(st->ibh);
    bgfx::setTexture(0, st->s_normal, st->normal);
    bgfx::setState(BGFX_STATE_DEFAULT);
    bgfx::submit(0, st->program);

    bgfx::frame();
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (bgfx::isValid(st->u_eyePos))   bgfx::destroy(st->u_eyePos);
    if (bgfx::isValid(st->u_lightPos)) bgfx::destroy(st->u_lightPos);
    if (bgfx::isValid(st->s_normal))   bgfx::destroy(st->s_normal);
    if (bgfx::isValid(st->normal))     bgfx::destroy(st->normal);
    if (bgfx::isValid(st->ibh))        bgfx::destroy(st->ibh);
    if (bgfx::isValid(st->vbh))        bgfx::destroy(st->vbh);
    if (bgfx::isValid(st->program))    bgfx::destroy(st->program);
    bgfx::shutdown();
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Toggle the map off to compare: branch the fragment shader on a u_params.x flag between the decoded N and the raw geometric v_normal. With the map off the quad is dead flat — proof the relief is entirely in the texture.
  2. Scale the bump strength: after decoding, do nTS.xy *= u_params.y; nTS = normalize(nTS);. Values above 1 exaggerate the grooves; below 1 flattens them.
  3. Push the specular: raise the exponent from 48 toward 256 for a tighter, glossier highlight, and watch it skate across the mortar lines as the light orbits.
  4. Rotate the light by hand with the arrow keys instead of the automatic orbit, and confirm the highlights track it correctly from every angle — the real test that your TBN basis is right.
