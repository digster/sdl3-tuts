Recipe 28 — Procedural Terrain & Fog

Build an outdoor world from code. Sum a few octaves of value noise into a heightmap, triangulate it into a grid mesh with per-vertex normals, tint it by altitude, and let exponential distance fog dissolve the far hills into the sky — the scene the rest of this track's finale builds on.

What you'll learn

  • Generating a heightmap from layered value noise (fractal Brownian motion).
  • Turning a height grid into a vertex/index mesh with central-difference normals.
  • Height-based colour banding — water, grass, rock, snow — in the fragment shader.
  • Exponential distance fog, and why it doubles as a cheap far-plane hide.

Prerequisites

Recipe 09 — Phong Lighting for the normal-and-light-dir diffuse term, and recipe 11 for the fly camera used to roam the landscape. This recipe just feeds them a much bigger, procedurally generated mesh.

Walkthrough

Value noise, stacked into fBm

A single lattice of smoothly-interpolated random values (value noise) is too uniform to look like terrain. Summing several octaves — each at double the frequency and half the amplitude — gives fractal Brownian motion: big rolling hills with finer detail layered on. It's all a pure function of (x, z), so the same coordinate always returns the same height. 

static float lerpf(float a, float b, float t) { return a + (b - a) * t; }
static float hash2(int x, int z) {                       // deterministic 0..1 per cell
    int h = x * 374761393 + z * 668265263;
    h = (h ^ (h >> 13)) * 1274126177;
    return ((h ^ (h >> 16)) & 0xFFFF) / 65535.0f;
}
static float vnoise(float x, float z) {                  // smooth bilinear value noise
    int xi = (int)SDL_floorf(x), zi = (int)SDL_floorf(z);
    float xf = x - xi, zf = z - zi;
    float u = xf*xf*(3 - 2*xf), v = zf*zf*(3 - 2*zf);    // smoothstep weights
    float a = hash2(xi, zi),   b = hash2(xi+1, zi);
    float c = hash2(xi, zi+1), d = hash2(xi+1, zi+1);
    return lerpf(lerpf(a, b, u), lerpf(c, d, u), v);
}
static float terrain_h(float x, float z) {               // 4-octave fBm, scaled
    float h = 0, amp = 1, freq = 0.08f, sum = 0;
    for (int o = 0; o < 4; ++o) { h += vnoise(x*freq, z*freq) * amp; sum += amp; amp *= 0.5f; freq *= 2.0f; }
    return (h / sum) * 7.0f - 2.5f;
}

Normals without a mesh to differentiate

Because the height is a function you can call anywhere, the normal at a vertex comes from sampling the slope in x and z — a central difference — rather than averaging triangle faces. Cheaper, and exact at the sample point. 

float e = 0.5f;                                          // sample step
float hl = terrain_h(x - e, z), hr = terrain_h(x + e, z);
float hd = terrain_h(x, z - e), hu = terrain_h(x, z + e);
// gradient of the surface (x,h,z); the normal is perpendicular to it.
Vec3 n = normalize({ hl - hr, 2.0f * e, hd - hu });

Colour by altitude, fog by distance

The fragment shader bands the terrain by world height — deep blue, sand, grass, rock, snow — then applies a directional diffuse term. Finally it mixes toward the fog colour by exp(−density·dist): near geometry is untouched, distant geometry fades to the sky, and the harsh far clip plane vanishes into haze. 

# fragment (excerpt)
float fog = exp(-u.fogDensity * dist);                  // 1 near, 0 far
float3 col = mix(u.fogColor.rgb, lit, clamp(fog, 0.0, 1.0));
Fog is a far-plane trick too. Setting the fog colour equal to the clear/sky colour means anything approaching the far plane blends seamlessly into the background — so you can use a modest far distance without popping. Match the two colours and the seam disappears.

Complete listing

A 128×128 heightfield mesh under a low sun, tinted by altitude and drowned in distance fog, with the camera flying a slow circular path over it. The mesh is generated once at start-up; only the camera moves. 

/*
 * 28-terrain-and-fog.cpp — a procedural fBm heightmap triangulated into a grid
 * mesh with central-difference normals, altitude colour and exponential fog.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <cstring>
#include <cstddef>
#include <vector>

static const int G = 128;                 // vertices per side
static const float CELL = 0.6f;           // world spacing between vertices

struct Vertex { float x, y, z, nx, ny, nz; };

static float lerpf(float a, float b, float t) { return a + (b - a) * t; }
static float hash2(int x, int z) {
    int h = x * 374761393 + z * 668265263;
    h = (h ^ (h >> 13)) * 1274126177;
    return ((h ^ (h >> 16)) & 0xFFFF) / 65535.0f;
}
static float vnoise(float x, float z) {
    int xi = (int)SDL_floorf(x), zi = (int)SDL_floorf(z);
    float xf = x - xi, zf = z - zi;
    float u = xf*xf*(3 - 2*xf), v = zf*zf*(3 - 2*zf);
    float a = hash2(xi, zi),   b = hash2(xi+1, zi);
    float c = hash2(xi, zi+1), d = hash2(xi+1, zi+1);
    return lerpf(lerpf(a, b, u), lerpf(c, d, u), v);
}
static float terrain_h(float x, float z) {
    float h = 0, amp = 1, freq = 0.08f, sum = 0;
    for (int o = 0; o < 4; ++o) { h += vnoise(x*freq, z*freq) * amp; sum += amp; amp *= 0.5f; freq *= 2.0f; }
    return (h / sum) * 7.0f - 2.5f;
}

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}
static Mat4 mat4_look_at(float ex,float ey,float ez, float cx,float cy,float cz, float ux,float uy,float uz){
    float fx=cx-ex, fy=cy-ey, fz=cz-ez; float fl=SDL_sqrtf(fx*fx+fy*fy+fz*fz); fx/=fl; fy/=fl; fz/=fl;
    float sx=fy*uz-fz*uy, sy=fz*ux-fx*uz, sz=fx*uy-fy*ux; float sl=SDL_sqrtf(sx*sx+sy*sy+sz*sz); sx/=sl; sy/=sl; sz/=sl;
    float ux2=sy*fz-sz*fy, uy2=sz*fx-sx*fz, uz2=sx*fy-sy*fx;
    Mat4 r=mat4_identity();
    r.m[0]=sx; r.m[4]=sy; r.m[8]=sz;  r.m[1]=ux2; r.m[5]=uy2; r.m[9]=uz2;
    r.m[2]=-fx; r.m[6]=-fy; r.m[10]=-fz;
    r.m[12]=-(sx*ex+sy*ey+sz*ez); r.m[13]=-(ux2*ex+uy2*ey+uz2*ez); r.m[14]=(fx*ex+fy*ey+fz*ez);
    return r;
}

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos [[attribute(0)]]; float3 nrm [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float3 wpos; float3 wn; };
struct UBO   { float4x4 mvp; };
vertex VSOut vs(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o;
    o.position = u.mvp * float4(in.pos, 1.0);
    o.wpos = in.pos;                       // terrain is authored in world space
    o.wn   = in.nrm;
    return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float3 wpos; float3 wn; };
struct FUBO  { float4 eye; float4 lightDir; float4 fogColor; float fogDensity; float p0,p1,p2; };
// Altitude colour ramp: water -> sand -> grass -> rock -> snow.
static float3 band(float h) {
    if (h < -1.5) return float3(0.13, 0.28, 0.45);
    if (h < -0.8) return float3(0.76, 0.70, 0.48);
    if (h <  1.5) return float3(0.28, 0.50, 0.24);
    if (h <  3.2) return float3(0.42, 0.38, 0.34);
    return float3(0.92, 0.94, 0.98);
}
fragment float4 fs(VSOut in [[stage_in]], constant FUBO &u [[buffer(0)]]) {
    float3 N = normalize(in.wn);
    float diff = max(dot(N, normalize(-u.lightDir.xyz)), 0.0);
    float3 base = band(in.wpos.y);
    float3 lit  = base * (0.25 + 0.85 * diff);
    float dist = length(in.wpos - u.eye.xyz);
    float fog  = clamp(exp(-u.fogDensity * dist), 0.0, 1.0);
    float3 col = mix(u.fogColor.rgb, lit, fog);
    return float4(col, 1.0);
}
)msl";

struct FUBO { float eye[4]; float lightDir[4]; float fogColor[4]; float fogDensity, p0, p1, p2; };

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUGraphicsPipeline *pipeline=nullptr;
    SDL_GPUBuffer *vbuf=nullptr, *ibuf=nullptr;
    SDL_GPUTexture *depth=nullptr;
    Uint32 idx_count=0, fb_w=0, fb_h=0; Uint64 start_ns=0;
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e, Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s; i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d,&i);
}
static void upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev); SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb; SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false); SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb);
}
static SDL_GPUBuffer *make_buf(SDL_GPUDevice *d, SDL_GPUBufferUsageFlags u, const void *src, Uint32 size){
    SDL_GPUBufferCreateInfo bi{}; bi.usage=u; bi.size=size; SDL_GPUBuffer *b=SDL_CreateGPUBuffer(d,&bi);
    upload_buffer(d,b,src,size); return b;
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Terrain and Fog", "1.0", "com.example.sdl3.terrain");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Procedural Terrain & Fog", 900, 640, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    // --- generate the grid mesh once (positions + central-difference normals) ---
    std::vector<Vertex> verts(G * G);
    float half = (G - 1) * CELL * 0.5f;
    for (int z = 0; z < G; ++z)
        for (int x = 0; x < G; ++x) {
            float wx = x * CELL - half, wz = z * CELL - half;
            float wy = terrain_h(wx, wz);
            float e = 0.5f;
            float hl = terrain_h(wx-e, wz), hr = terrain_h(wx+e, wz);
            float hd = terrain_h(wx, wz-e), hu = terrain_h(wx, wz+e);
            float nx = hl - hr, ny = 2.0f * e, nz = hd - hu;
            float nl = SDL_sqrtf(nx*nx + ny*ny + nz*nz);
            verts[z*G + x] = { wx, wy, wz, nx/nl, ny/nl, nz/nl };
        }
    std::vector<Uint32> idx;
    idx.reserve((G-1)*(G-1)*6);
    for (int z = 0; z < G-1; ++z)
        for (int x = 0; x < G-1; ++x) {
            Uint32 a = z*G + x, b = a + 1, c = a + G, d = c + 1;
            idx.push_back(a); idx.push_back(c); idx.push_back(b);
            idx.push_back(b); idx.push_back(c); idx.push_back(d);
        }
    st->idx_count = (Uint32)idx.size();
    st->vbuf = make_buf(st->device, SDL_GPU_BUFFERUSAGE_VERTEX, verts.data(), (Uint32)(verts.size()*sizeof(Vertex)));
    st->ibuf = make_buf(st->device, SDL_GPU_BUFFERUSAGE_INDEX,  idx.data(),   (Uint32)(idx.size()*sizeof(Uint32)));

    SDL_GPUShader *vs=make_shader(st->device,kVS,SDL_GPU_SHADERSTAGE_VERTEX,  "vs",1,0);
    SDL_GPUShader *fs=make_shader(st->device,kFS,SDL_GPU_SHADERSTAGE_FRAGMENT,"fs",1,0);
    SDL_GPUVertexBufferDescription vb{}; vb.slot=0; vb.pitch=sizeof(Vertex); vb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute a[2]{};
    a[0]={0,0,SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3, offsetof(Vertex,x)};
    a[1]={1,0,SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3, offsetof(Vertex,nx)};
    SDL_GPUVertexInputState vi{}; vi.vertex_buffer_descriptions=&vb; vi.num_vertex_buffers=1; vi.vertex_attributes=a; vi.num_vertex_attributes=2;
    SDL_GPUColorTargetDescription ct{}; ct.format=SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    SDL_GPUGraphicsPipelineCreateInfo pc{};
    pc.vertex_shader=vs; pc.fragment_shader=fs; pc.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST; pc.vertex_input_state=vi;
    pc.target_info.color_target_descriptions=&ct; pc.target_info.num_color_targets=1;
    pc.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; pc.target_info.has_depth_stencil_target=true;
    pc.depth_stencil_state.enable_depth_test=true; pc.depth_stencil_state.enable_depth_write=true; pc.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;
    pc.rasterizer_state.cull_mode=SDL_GPU_CULLMODE_BACK; pc.rasterizer_state.front_face=SDL_GPU_FRONTFACE_COUNTER_CLOCKWISE;
    st->pipeline=SDL_CreateGPUGraphicsPipeline(st->device,&pc);
    SDL_ReleaseGPUShader(st->device,vs); SDL_ReleaseGPUShader(st->device,fs);
    if(!st->pipeline) return fail("pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *, SDL_Event *e)
{
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->fb_w || sh != st->fb_h) {
            if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
            st->depth = create_depth(st->device, sw, sh); st->fb_w=sw; st->fb_h=sh;
        }
        float aspect = sh > 0 ? (float)sw/(float)sh : 1.0f;

        // Fly a slow circle over the terrain, looking a little ahead and down.
        float r = 22.0f;
        float ex = SDL_cosf(t*0.15f) * r, ez = SDL_sinf(t*0.15f) * r;
        float ey = 9.0f + terrain_h(ex, ez);
        float ax = SDL_cosf(t*0.15f + 0.4f) * (r - 10), az = SDL_sinf(t*0.15f + 0.4f) * (r - 10);
        Mat4 view = mat4_look_at(ex, ey, ez, ax, terrain_h(ax, az) + 1.0f, az, 0, 1, 0);
        Mat4 proj = mat4_perspective(60.0f*SDL_PI_F/180.0f, aspect, 0.1f, 120.0f);
        Mat4 mvp  = mat4_mul(proj, view);

        FUBO fu{};
        fu.eye[0]=ex; fu.eye[1]=ey; fu.eye[2]=ez;
        fu.lightDir[0]=-0.5f; fu.lightDir[1]=-0.75f; fu.lightDir[2]=-0.4f;
        fu.fogColor[0]=0.62f; fu.fogColor[1]=0.70f; fu.fogColor[2]=0.80f;   // matches the clear colour
        fu.fogDensity = 0.020f;

        SDL_GPUColorTargetInfo c{}; c.texture=swap; c.clear_color=SDL_FColor{0.62f,0.70f,0.80f,1};
        c.load_op=SDL_GPU_LOADOP_CLEAR; c.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo d{}; d.texture=st->depth; d.clear_depth=1.0f;
        d.load_op=SDL_GPU_LOADOP_CLEAR; d.store_op=SDL_GPU_STOREOP_DONT_CARE;
        SDL_GPURenderPass *p = SDL_BeginGPURenderPass(cmd, &c, 1, &d);
        SDL_BindGPUGraphicsPipeline(p, st->pipeline);
        SDL_GPUBufferBinding vb{}; vb.buffer=st->vbuf; SDL_BindGPUVertexBuffers(p,0,&vb,1);
        SDL_GPUBufferBinding ib{}; ib.buffer=st->ibuf; SDL_BindGPUIndexBuffer(p,&ib, SDL_GPU_INDEXELEMENTSIZE_32BIT);
        SDL_PushGPUVertexUniformData(cmd, 0, &mvp, sizeof(mvp));
        SDL_PushGPUFragmentUniformData(cmd, 0, &fu, sizeof(fu));
        SDL_DrawGPUIndexedPrimitives(p, st->idx_count, 1, 0, 0, 0);
        SDL_EndGPURenderPass(p);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
        if (st->ibuf)  SDL_ReleaseGPUBuffer(st->device, st->ibuf);
        if (st->vbuf)  SDL_ReleaseGPUBuffer(st->device, st->vbuf);
        if (st->pipeline) SDL_ReleaseGPUGraphicsPipeline(st->device, st->pipeline);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}
Note on the winding. The index order above (a, c, b / b, c, d) is counter-clockwise when the grid is viewed from above, matching FRONTFACE_COUNTER_CLOCKWISE with back-face culling. Flip a triangle's winding — or set CULLMODE_NONE — if your terrain renders inside-out.

Try it yourself

  1. Give the camera real control with the recipe-11 WASD + mouse rig and walk the hills yourself.
  2. Animate a water plane at y = -1.5 (a flat quad with alpha from recipe 20) so the blue band reads as an actual lake.
  3. Swap value noise for gradient (Perlin/simplex) noise — smoother ridges — or add a ridged octave (1 - abs(2·n - 1)) for sharp mountain crests.
  4. Scatter instanced rocks or trees (recipe 18) by sampling terrain_h at each instance's position for its Y.
