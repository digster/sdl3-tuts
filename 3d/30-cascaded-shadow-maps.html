Recipe 30 — Cascaded Shadow Maps

One shadow map can't cover a whole outdoor scene without going blocky up close. Cascaded shadow maps split the view distance into slices and give each its own tightly-fitted map — crisp shadows near the camera, coverage all the way to the horizon.

What you'll learn

  • Why a single directional shadow map trades resolution for range.
  • Splitting the camera frustum into cascades and fitting an ortho box to each slice.
  • Rendering N depth maps, then picking the right cascade per fragment by view depth.
  • A debug tint that colours each cascade so you can see the bands.

Prerequisites

Recipe 16 — Shadow Mapping is the whole foundation: depth-from-the-light, the light-space re-projection and the bias. This recipe runs that machinery three times over nested frustum slices. Recipe 28 gives the kind of wide scene where cascades earn their keep.

Walkthrough

Why one map isn't enough

A directional light's shadow map is an orthographic depth render. Stretch that ortho box to cover everything from your feet to the horizon and each texel spans metres — shadows near the camera turn into staircases. Cascaded shadow maps fix this by covering near geometry with a small, dense box and far geometry with a larger, coarser one, so texel density tracks how close (and how important) the shadow is.

Fit an ortho box to each slice

Split the view range into a few sub-frusta (here [near,10], [10,26], [26,far]). For each, compute its eight world-space corners from the camera basis, take their centroid and bounding radius, and build a light-space ortho box of exactly that size. Tight box = maximum resolution for that slice. 

// Corners of the sub-frustum [zn, zf] from the camera basis.
Vec3 corners[8]; int n = 0;
for (float z : { zn, zf }) {
    float hh = tanH * z, hw = hh * aspect;
    Vec3 c = add(eye, scale(fwd, z));
    corners[n++] = add(add(c, scale(right,  hw)), scale(up,  hh));
    corners[n++] = add(add(c, scale(right, -hw)), scale(up,  hh));
    corners[n++] = add(add(c, scale(right,  hw)), scale(up, -hh));
    corners[n++] = add(add(c, scale(right, -hw)), scale(up, -hh));
}
Vec3 centre = {0,0,0};
for (auto &p : corners) centre = add(centre, scale(p, 1.0f / 8));
float radius = 0;
for (auto &p : corners) radius = SDL_max(radius, len(sub(p, centre)));

Vec3 L = normalize(lightDir);
Mat4 lv = mat4_look_at_v(sub(centre, scale(L, radius)), centre, {0,1,0});
Mat4 lp = mat4_ortho(-radius, radius, -radius, radius, 0.0f, 2.0f * radius);
cascade[i].vp = mat4_mul(lp, lv);

Snap the box to texels (kill the shimmer)

Left there, the ortho box slides continuously as the camera moves, so every shadow texel lands on a slightly different world position each frame — the edges crawl and sparkle. The fix is to quantise the box origin to whole shadow-map texels. Project the origin into the map, round it to the texel grid, and fold the sub-texel remainder back into the ortho's x/y offset (an orthographic matrix keeps w = 1, so the clip origin is just the last column of the view-projection — no inverse needed). 

Mat4 vp = mat4_mul(lp, lv);
float half = SHADOW * 0.5f;
float ox = vp.m[12] * half, oy = vp.m[13] * half;   // clip origin -> texel units
lp.m[12] += (SDL_roundf(ox) - ox) / half;           // shift by the sub-texel remainder
lp.m[13] += (SDL_roundf(oy) - oy) / half;
cascade[i].vp = mat4_mul(lp, lv);                   // now stable frame-to-frame

Pick the cascade per fragment

The main shader receives all three light matrices and the split distances. Each fragment carries its view-space depth; it selects the first cascade whose far distance it falls within, projects into that map, and does the recipe-16 depth compare. A debug mode tints the three bands red / green / blue so the boundaries are visible. 

# main fragment (excerpt)
int c = (in.viewDepth < u.splits.x) ? 0 : (in.viewDepth < u.splits.y) ? 1 : 2;
float4 lc = u.lightVP[c] * float4(in.wpos, 1.0);         // into that cascade's clip space
float3 pr = lc.xyz / lc.w;
float2 uv = pr.xy * 0.5 + 0.5; uv.y = 1.0 - uv.y;
float closest = shadow[c].sample(smp, uv);              // 3 depth2d samplers
float lit = (pr.z - bias > closest) ? 0.35 : 1.0;
Three textures, not a texture array. To keep the moving parts obvious, each cascade is a separate D32 depth texture bound to its own sampler. Production engines pack the cascades into one depth array and index the layer, but that adds array-target plumbing that would bury the idea. Same algorithm, denser storage.

Complete listing

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_translate(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[12]=x;r.m[13]=y;r.m[14]=z; return r;}
static Mat4 mat4_scale(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[0]=x;r.m[5]=y;r.m[10]=z; return r;}
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_ortho(float l,float r,float b,float t,float n,float f){ Mat4 m{}; m.m[0]=2/(r-l); m.m[5]=2/(t-b); m.m[10]=1/(n-f); m.m[12]=-(r+l)/(r-l); m.m[13]=-(t+b)/(t-b); m.m[14]=n/(n-f); m.m[15]=1; return m; }
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}
static Mat4 mat4_look_at_v(Vec3 e, Vec3 c, Vec3 up){
    Vec3 f = normalize(sub(c, e)), s = normalize(cross(f, up)), u = cross(s, f);
    Mat4 r = mat4_identity();
    r.m[0]=s.x; r.m[4]=s.y; r.m[8]=s.z;  r.m[1]=u.x; r.m[5]=u.y; r.m[9]=u.z;
    r.m[2]=-f.x; r.m[6]=-f.y; r.m[10]=-f.z;
    r.m[12]=-(s.x*e.x+s.y*e.y+s.z*e.z); r.m[13]=-(u.x*e.x+u.y*e.y+u.z*e.z); r.m[14]=(f.x*e.x+f.y*e.y+f.z*e.z);
    return r;
}

// Fit a light-space ortho box to the camera sub-frustum [zn, zf].
static Mat4 fit_cascade(Vec3 eye, Vec3 fwd, Vec3 right, Vec3 up, float fovy, float aspect,
                        float zn, float zf, Vec3 lightDir)
{
    float tanH = SDL_tanf(fovy * 0.5f);
    Vec3 corners[8]; int n = 0;
    float zs[2] = { zn, zf };
    for (int fi = 0; fi < 2; ++fi) {
        float z = zs[fi], hh = tanH * z, hw = hh * aspect;
        Vec3 c = add(eye, scale(fwd, z));
        corners[n++] = add(add(c, scale(right,  hw)), scale(up,  hh));
        corners[n++] = add(add(c, scale(right, -hw)), scale(up,  hh));
        corners[n++] = add(add(c, scale(right,  hw)), scale(up, -hh));
        corners[n++] = add(add(c, scale(right, -hw)), scale(up, -hh));
    }
    Vec3 centre = {0,0,0};
    for (int i = 0; i < 8; ++i) centre = add(centre, scale(corners[i], 1.0f / 8));
    float radius = 0;
    for (int i = 0; i < 8; ++i) radius = SDL_max(radius, len(sub(corners[i], centre)));
    radius = SDL_ceilf(radius);                          // stabilise a little

    Vec3 L = normalize(lightDir);
    Mat4 lv = mat4_look_at_v(sub(centre, scale(L, radius)), centre, {0,1,0});
    Mat4 lp = mat4_ortho(-radius, radius, -radius, radius, 0.0f, 2.0f * radius);

    // Texel-snap: round the light-space origin to whole shadow-map texels so the
    // cascade doesn't crawl (shimmer) as the camera moves. Fold the sub-texel
    // remainder back into the ortho's x/y offset (ortho keeps w = 1, so the clip
    // origin is just the VP's last column). No matrix inverse needed.
    Mat4 vp = mat4_mul(lp, lv);
    float half = SHADOW * 0.5f;
    float ox = vp.m[12] * half, oy = vp.m[13] * half;    // clip origin -> texel units
    lp.m[12] += (SDL_roundf(ox) - ox) / half;            // shift by the sub-texel remainder
    lp.m[13] += (SDL_roundf(oy) - oy) / half;
    return mat4_mul(lp, lv);
}

static const char *kShadowVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn { float3 pos [[attribute(0)]]; float3 nrm [[attribute(1)]]; };
struct UBO  { float4x4 lightVP; float4x4 model; };
vertex float4 shadowVS(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    return u.lightVP * (u.model * float4(in.pos, 1.0));
}
)msl";

#include <metal_stdlib>
using namespace metal;
fragment void shadowFS() {}
)msl";

static const char *kMainVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos [[attribute(0)]]; float3 nrm [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float3 wpos; float3 wn; float viewDepth; };
struct UBO   { float4x4 mvp; float4x4 model; float4x4 view; };
vertex VSOut mainVS(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o;
    float4 world = u.model * float4(in.pos, 1.0);
    o.position   = u.mvp * float4(in.pos, 1.0);
    o.wpos       = world.xyz;
    o.wn         = (u.model * float4(in.nrm, 0.0)).xyz;
    o.viewDepth  = -(u.view * world).z;              // distance in front of the camera
    return o;
}
)msl";
static const char *kMainFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float3 wpos; float3 wn; float viewDepth; };
struct FBO   { float4x4 lightVP[3]; float4 splits; float4 lightDir; float4 baseColor; float debug; float p0,p1,p2; };
fragment float4 mainFS(VSOut in [[stage_in]], constant FBO &u [[buffer(0)]],
                       depth2d<float> sm0 [[texture(0)]], sampler s0 [[sampler(0)]],
                       depth2d<float> sm1 [[texture(1)]], sampler s1 [[sampler(1)]],
                       depth2d<float> sm2 [[texture(2)]], sampler s2 [[sampler(2)]]) {
    int c = (in.viewDepth < u.splits.x) ? 0 : (in.viewDepth < u.splits.y) ? 1 : 2;
    float4 lc = u.lightVP[c] * float4(in.wpos, 1.0);
    float3 pr = lc.xyz / lc.w;
    float2 uv = pr.xy * 0.5 + 0.5; uv.y = 1.0 - uv.y;
    float closest = (c == 0) ? sm0.sample(s0, uv) : (c == 1) ? sm1.sample(s1, uv) : sm2.sample(s2, uv);
    float bias = 0.0015 + 0.0015 * float(c);          // looser bias for coarser cascades
    float lit  = (pr.z - bias > closest) ? 0.35 : 1.0;
    if (uv.x < 0 || uv.x > 1 || uv.y < 0 || uv.y > 1) lit = 1.0;

    float3 N = normalize(in.wn);
    float diff = max(dot(N, normalize(-u.lightDir.xyz)), 0.0);
    float3 col = u.baseColor.rgb * (0.15 + 0.85 * diff * lit);
    if (u.debug > 0.5) {                               // tint each cascade band
        float3 tint = (c == 0) ? float3(1.0,0.6,0.6) : (c == 1) ? float3(0.6,1.0,0.6) : float3(0.6,0.6,1.0);
        col *= tint;
    }
    return float4(col, 1.0);
}
)msl";

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e, Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s; i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d,&i);
}
static void upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev); SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb; SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false); SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb);
}
static SDL_GPUBuffer *make_buf(SDL_GPUDevice *d, SDL_GPUBufferUsageFlags u, const void *src, Uint32 size){
    SDL_GPUBufferCreateInfo bi{}; bi.usage=u; bi.size=size; SDL_GPUBuffer *b=SDL_CreateGPUBuffer(d,&bi);
    upload_buffer(d,b,src,size); return b;
}
static SDL_GPUTexture *create_shadow(SDL_GPUDevice *d){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D; ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET | SDL_GPU_TEXTUREUSAGE_SAMPLER;
    ti.width=SHADOW; ti.height=SHADOW; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(d,&ti);
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}

// Depth-only (shadow) or lit (main) pipeline, matching recipe 16's build_pipeline.
static SDL_GPUGraphicsPipeline *build_pipeline(AppState *st, bool depthOnly, SDL_GPUTextureFormat swap)
{
    SDL_GPUShader *vs=make_shader(st->device, depthOnly?kShadowVS:kMainVS, SDL_GPU_SHADERSTAGE_VERTEX,
                                  depthOnly?"shadowVS":"mainVS", 1, 0);
    SDL_GPUShader *fs=make_shader(st->device, depthOnly?kShadowFS:kMainFS, SDL_GPU_SHADERSTAGE_FRAGMENT,
                                  depthOnly?"shadowFS":"mainFS", depthOnly?0u:1u, depthOnly?0u:3u);
    SDL_GPUVertexBufferDescription vb{}; vb.slot=0; vb.pitch=sizeof(Vertex); vb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute a[2]{};
    a[0]={0,0,SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3, offsetof(Vertex,px)};
    a[1]={1,0,SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3, offsetof(Vertex,nx)};
    SDL_GPUVertexInputState vi{}; vi.vertex_buffer_descriptions=&vb; vi.num_vertex_buffers=1; vi.vertex_attributes=a; vi.num_vertex_attributes=2;
    SDL_GPUGraphicsPipelineCreateInfo pc{};
    pc.vertex_shader=vs; pc.fragment_shader=fs; pc.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST; pc.vertex_input_state=vi;
    SDL_GPUColorTargetDescription ct{}; ct.format=swap;
    if (!depthOnly) { pc.target_info.color_target_descriptions=&ct; pc.target_info.num_color_targets=1; }
    pc.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; pc.target_info.has_depth_stencil_target=true;
    pc.depth_stencil_state.enable_depth_test=true; pc.depth_stencil_state.enable_depth_write=true; pc.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;
    pc.rasterizer_state.cull_mode=SDL_GPU_CULLMODE_NONE;
    SDL_GPUGraphicsPipeline *p=SDL_CreateGPUGraphicsPipeline(st->device,&pc);
    SDL_ReleaseGPUShader(st->device,vs); SDL_ReleaseGPUShader(st->device,fs);
    return p;
}

// A handful of pillars + the ground, reused by both passes.
static const int NUM_PILLARS = 12;
static Mat4 pillar_model(int i) {
    float a = i / (float)NUM_PILLARS * 6.2831853f, r = 6.0f + (i % 3) * 6.0f;
    return mat4_mul(mat4_translate(SDL_cosf(a)*r, 0.5f, SDL_sinf(a)*r), mat4_scale(1.0f, 3.0f, 1.0f));
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Cascaded Shadow Maps", "1.0", "com.example.sdl3.csm");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Cascaded Shadow Maps", 900, 640, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    st->cv = make_buf(st->device, SDL_GPU_BUFFERUSAGE_VERTEX, kCube,   sizeof(kCube));
    st->ci = make_buf(st->device, SDL_GPU_BUFFERUSAGE_INDEX,  kIdx,    sizeof(kIdx));
    st->gv = make_buf(st->device, SDL_GPU_BUFFERUSAGE_VERTEX, kGround, sizeof(kGround));
    st->gi = make_buf(st->device, SDL_GPU_BUFFERUSAGE_INDEX,  kGroundIdx, sizeof(kGroundIdx));
    for (int i = 0; i < NUM_CASCADES; ++i) st->shadow[i] = create_shadow(st->device);

    SDL_GPUSamplerCreateInfo si{}; si.min_filter=SDL_GPU_FILTER_NEAREST; si.mag_filter=SDL_GPU_FILTER_NEAREST;
    si.address_mode_u=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE; si.address_mode_v=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE;
    st->sampler = SDL_CreateGPUSampler(st->device, &si);

    SDL_GPUTextureFormat swap = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    st->shadowPipe = build_pipeline(st, true,  swap);  if(!st->shadowPipe) return fail("shadow pipeline");
    st->mainPipe   = build_pipeline(st, false, swap);  if(!st->mainPipe)   return fail("main pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        if (e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
        if (e->key.scancode == SDL_SCANCODE_SPACE)  st->debug = !st->debug;
    }
    return SDL_APP_CONTINUE;
}

// vs_ubo is the vertex uniform whose `model` field we overwrite per object.
template <typename UBO>
static void draw_scene(SDL_GPUCommandBuffer *cmd, SDL_GPURenderPass *pass, AppState *st, UBO &ubo,
                       void (*set_model)(UBO&, const Mat4&))
{
    SDL_GPUBufferBinding cvb{}; cvb.buffer=st->cv; SDL_GPUBufferBinding cib{}; cib.buffer=st->ci;
    SDL_GPUBufferBinding gvb{}; gvb.buffer=st->gv; SDL_GPUBufferBinding gib{}; gib.buffer=st->gi;
    for (int i = 0; i < NUM_PILLARS; ++i) {
        set_model(ubo, pillar_model(i));
        SDL_BindGPUVertexBuffers(pass,0,&cvb,1); SDL_BindGPUIndexBuffer(pass,&cib,SDL_GPU_INDEXELEMENTSIZE_16BIT);
        SDL_PushGPUVertexUniformData(cmd,0,&ubo,sizeof(ubo));
        SDL_DrawGPUIndexedPrimitives(pass,36,1,0,0,0);
    }
    set_model(ubo, mat4_identity());
    SDL_BindGPUVertexBuffers(pass,0,&gvb,1); SDL_BindGPUIndexBuffer(pass,&gib,SDL_GPU_INDEXELEMENTSIZE_16BIT);
    SDL_PushGPUVertexUniformData(cmd,0,&ubo,sizeof(ubo));
    SDL_DrawGPUIndexedPrimitives(pass,6,1,0,0,0);
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->fb_w || sh != st->fb_h) {
            if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
            st->depth = create_depth(st->device, sw, sh); st->fb_w=sw; st->fb_h=sh;
        }
        float aspect = sh > 0 ? (float)sw/(float)sh : 1.0f, fovy = 55.0f*SDL_PI_F/180.0f;

        // Orbiting camera; derive its basis for the cascade fit.
        Vec3 eye = { SDL_cosf(t*0.15f)*18.0f, 7.0f, SDL_sinf(t*0.15f)*18.0f };
        Vec3 target = { 0, 1.0f, 0 };
        Vec3 fwd = normalize(sub(target, eye));
        Vec3 right = normalize(cross(fwd, {0,1,0}));
        Vec3 up = cross(right, fwd);
        Vec3 lightDir = normalize({ -0.5f, -1.0f, -0.35f });   // sun direction

        Mat4 view = mat4_look_at_v(eye, target, {0,1,0});
        Mat4 proj = mat4_perspective(fovy, aspect, 0.1f, SPLITS[2]);

        Mat4 cascadeVP[3];
        float zn = 0.1f;
        for (int i = 0; i < NUM_CASCADES; ++i) {
            cascadeVP[i] = fit_cascade(eye, fwd, right, up, fovy, aspect, zn, SPLITS[i], lightDir);
            zn = SPLITS[i];
        }

        // ---- Passes 1..3: depth into each cascade ----
        for (int c = 0; c < NUM_CASCADES; ++c) {
            SDL_GPUDepthStencilTargetInfo sd{}; sd.texture=st->shadow[c]; sd.clear_depth=1.0f;
            sd.load_op=SDL_GPU_LOADOP_CLEAR; sd.store_op=SDL_GPU_STOREOP_STORE;
            SDL_GPURenderPass *ps = SDL_BeginGPURenderPass(cmd, nullptr, 0, &sd);
            SDL_BindGPUGraphicsPipeline(ps, st->shadowPipe);
            struct SUBO { Mat4 lightVP, model; } su; su.lightVP = cascadeVP[c];
            draw_scene(cmd, ps, st, su, [](SUBO &u, const Mat4 &m){ u.model = m; });
            SDL_EndGPURenderPass(ps);
        }

        // ---- Pass 4: lit + cascaded shadows ----
        MainFUBO fu{};
        for (int i = 0; i < 3; ++i) fu.lightVP[i] = cascadeVP[i];
        fu.splits[0]=SPLITS[0]; fu.splits[1]=SPLITS[1]; fu.splits[2]=SPLITS[2];
        fu.lightDir[0]=lightDir.x; fu.lightDir[1]=lightDir.y; fu.lightDir[2]=lightDir.z;
        fu.baseColor[0]=0.72f; fu.baseColor[1]=0.74f; fu.baseColor[2]=0.78f; fu.baseColor[3]=1;
        fu.debug = st->debug ? 1.0f : 0.0f;

        SDL_GPUColorTargetInfo c{}; c.texture=swap; c.clear_color=SDL_FColor{0.20f,0.28f,0.40f,1};
        c.load_op=SDL_GPU_LOADOP_CLEAR; c.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo d{}; d.texture=st->depth; d.clear_depth=1.0f;
        d.load_op=SDL_GPU_LOADOP_CLEAR; d.store_op=SDL_GPU_STOREOP_DONT_CARE;
        SDL_GPURenderPass *pm = SDL_BeginGPURenderPass(cmd, &c, 1, &d);
        SDL_BindGPUGraphicsPipeline(pm, st->mainPipe);
        SDL_GPUTextureSamplerBinding sb[3];
        for (int i = 0; i < 3; ++i) { sb[i].texture=st->shadow[i]; sb[i].sampler=st->sampler; }
        SDL_BindGPUFragmentSamplers(pm, 0, sb, 3);

        MainVUBO mu{}; mu.view = view;
        for (int i = 0; i < NUM_PILLARS; ++i) {
            Mat4 model = pillar_model(i);
            mu.mvp = mat4_mul(proj, mat4_mul(view, model)); mu.model = model;
            SDL_GPUBufferBinding cvb{}; cvb.buffer=st->cv; SDL_GPUBufferBinding cib{}; cib.buffer=st->ci;
            SDL_BindGPUVertexBuffers(pm,0,&cvb,1); SDL_BindGPUIndexBuffer(pm,&cib,SDL_GPU_INDEXELEMENTSIZE_16BIT);
            SDL_PushGPUVertexUniformData(cmd,0,&mu,sizeof(mu));
            SDL_PushGPUFragmentUniformData(cmd,0,&fu,sizeof(fu));
            SDL_DrawGPUIndexedPrimitives(pm,36,1,0,0,0);
        }
        Mat4 gm = mat4_identity();
        mu.mvp = mat4_mul(proj, mat4_mul(view, gm)); mu.model = gm;
        SDL_GPUBufferBinding gvb{}; gvb.buffer=st->gv; SDL_GPUBufferBinding gib{}; gib.buffer=st->gi;
        SDL_BindGPUVertexBuffers(pm,0,&gvb,1); SDL_BindGPUIndexBuffer(pm,&gib,SDL_GPU_INDEXELEMENTSIZE_16BIT);
        SDL_PushGPUVertexUniformData(cmd,0,&mu,sizeof(mu));
        SDL_PushGPUFragmentUniformData(cmd,0,&fu,sizeof(fu));
        SDL_DrawGPUIndexedPrimitives(pm,6,1,0,0,0);
        SDL_EndGPURenderPass(pm);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->sampler) SDL_ReleaseGPUSampler(st->device, st->sampler);
        for (int i = 0; i < NUM_CASCADES; ++i) if (st->shadow[i]) SDL_ReleaseGPUTexture(st->device, st->shadow[i]);
        if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
        if (st->gi) SDL_ReleaseGPUBuffer(st->device, st->gi);
        if (st->gv) SDL_ReleaseGPUBuffer(st->device, st->gv);
        if (st->ci) SDL_ReleaseGPUBuffer(st->device, st->ci);
        if (st->cv) SDL_ReleaseGPUBuffer(st->device, st->cv);
        if (st->mainPipe)   SDL_ReleaseGPUGraphicsPipeline(st->device, st->mainPipe);
        if (st->shadowPipe) SDL_ReleaseGPUGraphicsPipeline(st->device, st->shadowPipe);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}
Cascades are backend-sensitive, like recipe 16. The texel snap above keeps the shadows stable frame-to-frame, but the bias per cascade, the split distances and the ortho depth range still interact with your projection's depth convention. If shadows detach or acne appears in one band, tune that cascade's bias first; the depth-compare sign is the same one recipe 16 flagged as tunable.

Try it yourself

  1. Soften the edges with PCF: sample each cascade at a 3×3 grid of offsets and average the lit/shadowed results — combined with the texel snap, you get shadows that are both stable and soft.
  2. Blend the seams: near a split boundary, sample both cascades and lerp by distance so the transition isn't a hard line (visible with the debug tint on).
  3. Use a logarithmic split scheme (lerp of uniform and log splits) instead of the hand-picked distances and compare resolution distribution.
  4. Pack the three maps into one D32 texture array and index the layer, dropping from three samplers to one — the production layout.
