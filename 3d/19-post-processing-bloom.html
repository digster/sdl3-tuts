Recipe 19 — Post-Processing & Bloom

Make bright things glow. Render the scene offscreen, isolate the bright pixels, blur them with a cheap separable Gaussian, and add the result back over the scene. A four-pass pipeline built entirely on render-to-texture.

What you'll learn

  • Chaining several offscreen colour targets and ping-ponging between them.
  • A bright-pass (threshold) that keeps only the pixels worth glowing.
  • Why a separable Gaussian (horizontal then vertical) is so much cheaper than a 2D one.
  • An additive composite that adds the blurred bloom back onto the scene.

Prerequisites

Recipe 12 — Render-to-Texture. Everything here is that two-pass pattern repeated: each post step is a fullscreen-triangle draw that samples one target and writes another. The fullscreen-triangle vertex shader is reused verbatim.

Walkthrough

Bloom in four passes

  1. Scene → target A. Draw a bright emissive cube on a dark background into an offscreen colour target.
  2. Bright-pass A → B. A fullscreen triangle keeps pixels above a luminance threshold and zeroes the rest.
  3. Blur B → C → B. A separable Gaussian: horizontal pass B→C, then vertical pass C→B. A direction uniform picks the axis.
  4. Composite → swapchain. Sample the original scene (A) plus the blurred bloom (B), add them, present.

The targets

Three sampleable colour targets, all created with the recipe-12 create_color_target helper. The scene target A is full resolution; the bright/blur targets B and C are half resolution — the blur is the most expensive part and a wide glow doesn't need full detail. Half-res also doubles the effective blur radius for free. 

st->sceneA  = create_color_target(dev, w,   h,   fmt);   // full-res scene
st->brightB = create_color_target(dev, w/2, h/2, fmt);  // half-res bright + final blur
st->blurC   = create_color_target(dev, w/2, h/2, fmt);  // half-res scratch
st->sceneDepth = create_depth(dev, w, h);               // only the scene pass needs depth

The fullscreen triangle (reused)

Identical to recipe 12: three vertices generated from [[vertex_id]], UVs computed in the shader, no vertex buffer. Every post pass reuses it. 

static const char *kPostVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
vertex VSOut postVS(uint vid [[vertex_id]]) {
    const float2 P[3] = { float2(-1,-1), float2(3,-1), float2(-1,3) };
    VSOut o; o.position = float4(P[vid], 0, 1);
    o.uv = P[vid] * 0.5 + 0.5; o.uv.y = 1.0 - o.uv.y;
    return o;
}
)msl";

Pass 2 — bright-pass

Compute a luminance and keep the pixel only if it clears the threshold; otherwise output black. After this pass, target B holds just the glowing bits. 

static const char *kBrightFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
struct Bright { float threshold; float pad0, pad1, pad2; };
fragment float4 brightFS(VSOut in [[stage_in]],
                         texture2d<float> scene [[texture(0)]],
                         sampler smp [[sampler(0)]],
                         constant Bright &u [[buffer(0)]]) {
    float3 c = scene.sample(smp, in.uv).rgb;
    float lum = dot(c, float3(0.2126, 0.7152, 0.0722));
    return float4(lum > u.threshold ? c : float3(0.0), 1.0);
}
)msl";

Pass 3 — separable Gaussian blur

A full 2D Gaussian over an N×N window costs N² taps per pixel. A separable Gaussian splits it into two 1D passes — N taps horizontally, then N taps vertically — which is mathematically identical but costs 2N taps. The direction uniform is (texelW, 0) for the horizontal pass and (0, texelH) for the vertical one, so the same shader does both. 

static const char *kBlurFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
struct Blur { float2 direction; float2 pad; };   // texel-sized step along one axis
fragment float4 blurFS(VSOut in [[stage_in]],
                       texture2d<float> src [[texture(0)]],
                       sampler smp [[sampler(0)]],
                       constant Blur &u [[buffer(0)]]) {
    // 9-tap Gaussian (normalised weights).
    const float w[5] = { 0.227027, 0.194594, 0.121622, 0.054054, 0.016216 };
    float3 sum = src.sample(smp, in.uv).rgb * w[0];
    for (int i = 1; i < 5; ++i) {
        float2 off = u.direction * float(i);
        sum += src.sample(smp, in.uv + off).rgb * w[i];
        sum += src.sample(smp, in.uv - off).rgb * w[i];
    }
    return float4(sum, 1.0);
}
)msl";

Pass 4 — additive composite

Sample the untouched scene (A) and the blurred bloom (B), and add the bloom scaled by an intensity. Because the scene and bloom are two different textures, this pass binds two fragment samplers. 

static const char *kCompositeFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
struct Comp { float intensity; float pad0, pad1, pad2; };
fragment float4 compositeFS(VSOut in [[stage_in]],
                            texture2d<float> scene [[texture(0)]],
                            sampler        smpS  [[sampler(0)]],
                            texture2d<float> bloom [[texture(1)]],
                            sampler        smpB  [[sampler(1)]],
                            constant Comp  &u    [[buffer(0)]]) {
    float3 c = scene.sample(smpS, in.uv).rgb;
    float3 b = bloom.sample(smpB, in.uv).rgb;
    return float4(c + b * u.intensity, 1.0);   // additive
}
)msl";

Driving the four passes

One command buffer, four render passes. The first draws the cube; the next three are each a single fullscreen-triangle draw with the right input bound. Note the blur runs twice with different direction uniforms and swapped source/target. 

// Pass 3a: horizontal blur, B -> C
SDL_GPURenderPass *p3 = SDL_BeginGPURenderPass(cmd, &to_C, 1, nullptr);
SDL_BindGPUGraphicsPipeline(p3, st->blur_pipeline);
SDL_GPUTextureSamplerBinding sb{}; sb.texture=st->brightB; sb.sampler=st->sampler;
SDL_BindGPUFragmentSamplers(p3, 0, &sb, 1);
struct { float dir[2], pad[2]; } hb{ { 1.0f/(st->fb_w*0.5f), 0.0f }, {0,0} };
SDL_PushGPUFragmentUniformData(cmd, 0, &hb, sizeof(hb));
SDL_DrawGPUPrimitives(p3, 3, 1, 0, 0);
SDL_EndGPURenderPass(p3);
// Pass 3b: vertical blur, C -> B  (same pipeline, direction = (0, texelH))
Why this matters. Bloom is the canonical multi-pass post-process: threshold, blur, composite. Swap the bright-pass for a luminance histogram and you have auto-exposure; swap the blur for a depth-weighted one and you have depth-of-field. The plumbing — chain targets, ping-pong, composite — is what generalises.

Complete listing

A bright emissive cube on a near-black background, glowing through a half-resolution separable-Gaussian bloom that is added back over the scene before presentation.

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e,
                                  Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s;
    i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d, &i);
}
static bool upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev);
    SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb;
    SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false);
    SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb); return true;
}
static SDL_GPUTexture *create_color_target(SDL_GPUDevice *dev, Uint32 w, Uint32 h, SDL_GPUTextureFormat fmt){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D; ti.format=fmt;
    ti.usage = SDL_GPU_TEXTUREUSAGE_COLOR_TARGET | SDL_GPU_TEXTUREUSAGE_SAMPLER;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}

// Build a single fullscreen-post pipeline given its fragment shader + target format.
static SDL_GPUGraphicsPipeline *make_post_pipeline(SDL_GPUDevice *dev, const char *fs_src, const char *fs_entry,
                                                   Uint32 num_samplers, Uint32 num_ubo, SDL_GPUTextureFormat fmt){
    SDL_GPUShader *vs = make_shader(dev, kPostVS, SDL_GPU_SHADERSTAGE_VERTEX, "postVS", 0, 0);
    SDL_GPUShader *fs = make_shader(dev, fs_src,  SDL_GPU_SHADERSTAGE_FRAGMENT, fs_entry, num_ubo, num_samplers);
    SDL_GPUColorTargetDescription ct{}; ct.format = fmt;
    SDL_GPUGraphicsPipelineCreateInfo pci{};
    pci.vertex_shader=vs; pci.fragment_shader=fs;
    pci.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    pci.target_info.color_target_descriptions=&ct;
    pci.target_info.num_color_targets=1;
    SDL_GPUGraphicsPipeline *p = SDL_CreateGPUGraphicsPipeline(dev, &pci);
    SDL_ReleaseGPUShader(dev, vs); SDL_ReleaseGPUShader(dev, fs);
    return p;
}

static void resize_targets(AppState *st, Uint32 w, Uint32 h)
{
    if (st->sceneA)     SDL_ReleaseGPUTexture(st->device, st->sceneA);
    if (st->brightB)    SDL_ReleaseGPUTexture(st->device, st->brightB);
    if (st->blurC)      SDL_ReleaseGPUTexture(st->device, st->blurC);
    if (st->sceneDepth) SDL_ReleaseGPUTexture(st->device, st->sceneDepth);
    st->sceneA     = create_color_target(st->device, w,   h,   kHDR);
    st->brightB    = create_color_target(st->device, w/2, h/2, kHDR);
    st->blurC      = create_color_target(st->device, w/2, h/2, kHDR);
    st->sceneDepth = create_depth       (st->device, w,   h);
    st->fb_w = w; st->fb_h = h;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Post-Processing & Bloom", "1.0", "com.example.sdl3.bloom");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Post-Processing & Bloom", 800, 600, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    SDL_GPUBufferCreateInfo vbi{}; vbi.usage=SDL_GPU_BUFFERUSAGE_VERTEX; vbi.size=sizeof(kCube);
    st->vbuf=SDL_CreateGPUBuffer(st->device,&vbi);
    SDL_GPUBufferCreateInfo ibi{}; ibi.usage=SDL_GPU_BUFFERUSAGE_INDEX;  ibi.size=sizeof(kIdx);
    st->ibuf=SDL_CreateGPUBuffer(st->device,&ibi);
    upload_buffer(st->device, st->vbuf, kCube, sizeof(kCube));
    upload_buffer(st->device, st->ibuf, kIdx,  sizeof(kIdx));

    SDL_GPUSamplerCreateInfo si{}; si.min_filter=SDL_GPU_FILTER_LINEAR; si.mag_filter=SDL_GPU_FILTER_LINEAR;
    si.address_mode_u=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE;
    si.address_mode_v=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE;
    st->sampler = SDL_CreateGPUSampler(st->device, &si);

    // --- scene pipeline (offscreen, HDR target, depth tested) ---
    SDL_GPUShader *svs = make_shader(st->device, kSceneVS, SDL_GPU_SHADERSTAGE_VERTEX,   "sceneVS", 1, 0);
    SDL_GPUShader *sfs = make_shader(st->device, kSceneFS, SDL_GPU_SHADERSTAGE_FRAGMENT, "sceneFS", 0, 0);
    SDL_GPUVertexBufferDescription svb{}; svb.slot=0; svb.pitch=sizeof(Vertex); svb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute sattrs[2]{};
    sattrs[0].location=0; sattrs[0].buffer_slot=0; sattrs[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; sattrs[0].offset=offsetof(Vertex,x);
    sattrs[1].location=1; sattrs[1].buffer_slot=0; sattrs[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; sattrs[1].offset=offsetof(Vertex,r);
    SDL_GPUVertexInputState svis{}; svis.vertex_buffer_descriptions=&svb; svis.num_vertex_buffers=1; svis.vertex_attributes=sattrs; svis.num_vertex_attributes=2;
    SDL_GPUColorTargetDescription sct{}; sct.format=kHDR;
    SDL_GPUGraphicsPipelineCreateInfo spci{};
    spci.vertex_shader=svs; spci.fragment_shader=sfs;
    spci.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    spci.vertex_input_state=svis;
    spci.target_info.color_target_descriptions=&sct;
    spci.target_info.num_color_targets=1;
    spci.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    spci.target_info.has_depth_stencil_target=true;
    spci.depth_stencil_state.enable_depth_test=true;
    spci.depth_stencil_state.enable_depth_write=true;
    spci.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;
    st->scene_pipeline = SDL_CreateGPUGraphicsPipeline(st->device, &spci);
    SDL_ReleaseGPUShader(st->device, svs); SDL_ReleaseGPUShader(st->device, sfs);
    if (!st->scene_pipeline) return fail("scene pipeline");

    // --- post pipelines ---
    SDL_GPUTextureFormat swap_fmt = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    st->bright_pipeline    = make_post_pipeline(st->device, kBrightFS,    "brightFS",    1, 1, kHDR);
    st->blur_pipeline      = make_post_pipeline(st->device, kBlurFS,      "blurFS",      1, 1, kHDR);
    st->composite_pipeline = make_post_pipeline(st->device, kCompositeFS, "compositeFS", 2, 1, swap_fmt);
    if (!st->bright_pipeline || !st->blur_pipeline || !st->composite_pipeline) return fail("post pipelines");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->fb_w || sh != st->fb_h) resize_targets(st, sw, sh);
        float aspect = sh > 0 ? (float)sw / (float)sh : 1.0f;
        Mat4 model = mat4_mul(mat4_rotate_y(t * 0.8f), mat4_rotate_x(t * 0.5f));
        Mat4 view  = mat4_translate(0, 0, -3.0f);
        Mat4 proj  = mat4_perspective(60.0f * SDL_PI_F / 180.0f, aspect, 0.1f, 100.0f);
        Mat4 mvp   = mat4_mul(proj, mat4_mul(view, model));

        float texW = 1.0f / (st->fb_w * 0.5f);   // half-res texel size
        float texH = 1.0f / (st->fb_h * 0.5f);

        // ---- Pass 1: scene into sceneA ----
        SDL_GPUColorTargetInfo a{};
        a.texture=st->sceneA; a.clear_color=SDL_FColor{0.01f,0.01f,0.02f,1};
        a.load_op=SDL_GPU_LOADOP_CLEAR; a.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo da{};
        da.texture=st->sceneDepth; da.clear_depth=1.0f;
        da.load_op=SDL_GPU_LOADOP_CLEAR; da.store_op=SDL_GPU_STOREOP_DONT_CARE;
        SDL_GPURenderPass *p1 = SDL_BeginGPURenderPass(cmd, &a, 1, &da);
        SDL_BindGPUGraphicsPipeline(p1, st->scene_pipeline);
        SDL_GPUBufferBinding vbind{}; vbind.buffer=st->vbuf; SDL_BindGPUVertexBuffers(p1,0,&vbind,1);
        SDL_GPUBufferBinding ibind{}; ibind.buffer=st->ibuf; SDL_BindGPUIndexBuffer(p1,&ibind, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        SDL_PushGPUVertexUniformData(cmd, 0, &mvp, sizeof(mvp));
        SDL_DrawGPUIndexedPrimitives(p1, 36, 1, 0, 0, 0);
        SDL_EndGPURenderPass(p1);

        // ---- Pass 2: bright-pass sceneA -> brightB (half-res) ----
        SDL_GPUColorTargetInfo b{}; b.texture=st->brightB; b.clear_color=SDL_FColor{0,0,0,1};
        b.load_op=SDL_GPU_LOADOP_CLEAR; b.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p2 = SDL_BeginGPURenderPass(cmd, &b, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p2, st->bright_pipeline);
        SDL_GPUTextureSamplerBinding s2{}; s2.texture=st->sceneA; s2.sampler=st->sampler;
        SDL_BindGPUFragmentSamplers(p2, 0, &s2, 1);
        struct { float threshold; float pad[3]; } bp{ 1.0f, {0,0,0} };
        SDL_PushGPUFragmentUniformData(cmd, 0, &bp, sizeof(bp));
        SDL_DrawGPUPrimitives(p2, 3, 1, 0, 0);
        SDL_EndGPURenderPass(p2);

        // ---- Pass 3a: horizontal blur brightB -> blurC ----
        SDL_GPUColorTargetInfo c{}; c.texture=st->blurC; c.clear_color=SDL_FColor{0,0,0,1};
        c.load_op=SDL_GPU_LOADOP_CLEAR; c.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p3 = SDL_BeginGPURenderPass(cmd, &c, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p3, st->blur_pipeline);
        SDL_GPUTextureSamplerBinding s3{}; s3.texture=st->brightB; s3.sampler=st->sampler;
        SDL_BindGPUFragmentSamplers(p3, 0, &s3, 1);
        struct { float dir[2]; float pad[2]; } hb{ { texW, 0.0f }, {0,0} };
        SDL_PushGPUFragmentUniformData(cmd, 0, &hb, sizeof(hb));
        SDL_DrawGPUPrimitives(p3, 3, 1, 0, 0);
        SDL_EndGPURenderPass(p3);

        // ---- Pass 3b: vertical blur blurC -> brightB ----
        SDL_GPUColorTargetInfo d{}; d.texture=st->brightB; d.clear_color=SDL_FColor{0,0,0,1};
        d.load_op=SDL_GPU_LOADOP_CLEAR; d.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p4 = SDL_BeginGPURenderPass(cmd, &d, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p4, st->blur_pipeline);
        SDL_GPUTextureSamplerBinding s4{}; s4.texture=st->blurC; s4.sampler=st->sampler;
        SDL_BindGPUFragmentSamplers(p4, 0, &s4, 1);
        struct { float dir[2]; float pad[2]; } vb2{ { 0.0f, texH }, {0,0} };
        SDL_PushGPUFragmentUniformData(cmd, 0, &vb2, sizeof(vb2));
        SDL_DrawGPUPrimitives(p4, 3, 1, 0, 0);
        SDL_EndGPURenderPass(p4);

        // ---- Pass 4: composite scene + bloom into the swapchain ----
        SDL_GPUColorTargetInfo e{}; e.texture=swap; e.clear_color=SDL_FColor{0,0,0,1};
        e.load_op=SDL_GPU_LOADOP_CLEAR; e.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p5 = SDL_BeginGPURenderPass(cmd, &e, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p5, st->composite_pipeline);
        SDL_GPUTextureSamplerBinding cs[2]{};
        cs[0].texture=st->sceneA;  cs[0].sampler=st->sampler;   // sampler(0): scene
        cs[1].texture=st->brightB; cs[1].sampler=st->sampler;   // sampler(1): bloom
        SDL_BindGPUFragmentSamplers(p5, 0, cs, 2);
        struct { float intensity; float pad[3]; } cp{ 1.2f, {0,0,0} };
        SDL_PushGPUFragmentUniformData(cmd, 0, &cp, sizeof(cp));
        SDL_DrawGPUPrimitives(p5, 3, 1, 0, 0);
        SDL_EndGPURenderPass(p5);
    }

    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->sampler)    SDL_ReleaseGPUSampler(st->device, st->sampler);
        if (st->sceneA)     SDL_ReleaseGPUTexture(st->device, st->sceneA);
        if (st->brightB)    SDL_ReleaseGPUTexture(st->device, st->brightB);
        if (st->blurC)      SDL_ReleaseGPUTexture(st->device, st->blurC);
        if (st->sceneDepth) SDL_ReleaseGPUTexture(st->device, st->sceneDepth);
        if (st->ibuf)       SDL_ReleaseGPUBuffer(st->device, st->ibuf);
        if (st->vbuf)       SDL_ReleaseGPUBuffer(st->device, st->vbuf);
        if (st->composite_pipeline) SDL_ReleaseGPUGraphicsPipeline(st->device, st->composite_pipeline);
        if (st->blur_pipeline)      SDL_ReleaseGPUGraphicsPipeline(st->device, st->blur_pipeline);
        if (st->bright_pipeline)    SDL_ReleaseGPUGraphicsPipeline(st->device, st->bright_pipeline);
        if (st->scene_pipeline)     SDL_ReleaseGPUGraphicsPipeline(st->device, st->scene_pipeline);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. You already push threshold and intensity as uniforms — bind them to keys and sweep the values live to feel how each shapes the glow.
  2. Widen the blur: run the H/V blur pair two or three times in a row (ping-ponging B↔C), or grow the tap count and weights, for a softer, larger halo.
  3. Downsample further — make the bright/blur targets quarter resolution (w/4, h/4). Cheaper still, and the glow gets even wider.
  4. Tint the bloom warm: in compositeFS multiply b by float3(1.1, 0.9, 0.7) before adding, for a sunlit, filmic feel.
