Recipe 23 — Tone Mapping & Gamma

Render in HDR, then map it down for the display. An exposure control, a choice of tone-mapping curve (clamp vs Reinhard vs ACES) and a final gamma correction turn unbounded light into a picture a monitor can actually show.

What you'll learn

  • Why colours above 1.0 must be tone-mapped, not just clamped.
  • An exposure multiply as the simplest brightness control.
  • Two operators — Reinhard and the filmic ACES approximation — and how they differ.
  • The final gamma step (pow(c, 1/2.2)) that makes mid-tones read correctly.

Prerequisites

Recipe 19 — Bloom for the HDR colour target (R16G16B16A16_FLOAT) and the fullscreen-triangle post pass. Tone mapping is the pass every HDR pipeline — bloom included — should end with.

Walkthrough

Render to an HDR target

The swapchain stores 8-bit colour clamped to [0,1]. To keep bright highlights intact, the scene is drawn into a floating-point target where values can sail past 1.0, exactly as the bloom recipe did. The tone-map pass then reads that target. 

static const SDL_GPUTextureFormat kHDR = SDL_GPU_TEXTUREFORMAT_R16G16B16A16_FLOAT;
st->sceneHDR = create_color_target(dev, w, h, kHDR);   // unbounded colour

Clamping is not tone mapping

The naive way to fit HDR into [0,1] is to clamp — but that flattens every bright region to solid white and destroys detail in the highlights. A tone-mapping curve instead compresses the high end smoothly, preserving the sense that something is bright without blowing it out. 

float3 reinhard(float3 c) { return c / (1.0 + c); }      // simple, slightly flat

float3 aces(float3 x) {                                  // filmic, punchy contrast
    const float a = 2.51, b = 0.03, c = 2.43, d = 0.59, e = 0.14;
    return clamp((x * (a*x + b)) / (x * (c*x + d) + e), 0.0, 1.0);
}

Exposure, then curve, then gamma

The pass does three things in order. Exposure scales the HDR colour (your "shutter"). The curve compresses it into [0,1]. Finally gamma encodes it for the display — without pow(c, 1/2.2) the mid-tones come out too dark, because monitors are non-linear. 

fragment float4 toneFS(VSOut in [[stage_in]],
                       texture2d<float> hdr [[texture(0)]], sampler smp [[sampler(0)]],
                       constant Tone &u [[buffer(0)]]) {
    float3 c = hdr.sample(smp, in.uv).rgb * u.exposure;     // 1. exposure
    float3 mapped = u.mode < 0.5 ? clamp(c, 0.0, 1.0)       // 2. curve
                  : u.mode < 1.5 ? reinhard(c)
                                 : aces(c);
    mapped = pow(mapped, float3(1.0 / 2.2));                // 3. gamma
    return float4(mapped, 1.0);
}
Order matters. Do all lighting and blending in linear HDR space; tone-map and gamma-encode last, once, just before the pixel hits the screen. Gamma-correcting earlier (or twice) is the classic washed-out / crushed-black bug.

Complete listing

A cube with deliberately over-bright vertex colours is drawn into an HDR target, then tone-mapped to the window. Press Space to cycle clamp → Reinhard → ACES, and ↑/↓ to change exposure — clamp blows out, the curves hold detail. 

/*
 * 23-tone-mapping-and-gamma.cpp — HDR scene target tone-mapped (clamp/Reinhard/ACES)
 * with exposure and gamma, on the post-pass pattern from recipe 19.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <cstring>
#include <cstddef>

struct Vertex { float x, y, z, r, g, b, a; };
// Over-bright cube: several channels well above 1.0 so tone mapping has work to do.
static const Vertex kCube[24] = {
    {  0.5f,-0.5f,-0.5f, 4.0f,1.0f,0.4f,1 },{  0.5f, 0.5f,-0.5f, 4.0f,1.0f,0.4f,1 },{  0.5f, 0.5f, 0.5f, 4.0f,1.0f,0.4f,1 },{  0.5f,-0.5f, 0.5f, 4.0f,1.0f,0.4f,1 },
    { -0.5f,-0.5f, 0.5f, 0.3f,2.5f,3.5f,1 },{ -0.5f, 0.5f, 0.5f, 0.3f,2.5f,3.5f,1 },{ -0.5f, 0.5f,-0.5f, 0.3f,2.5f,3.5f,1 },{ -0.5f,-0.5f,-0.5f, 0.3f,2.5f,3.5f,1 },
    { -0.5f, 0.5f,-0.5f, 3.0f,3.0f,0.6f,1 },{ -0.5f, 0.5f, 0.5f, 3.0f,3.0f,0.6f,1 },{  0.5f, 0.5f, 0.5f, 3.0f,3.0f,0.6f,1 },{  0.5f, 0.5f,-0.5f, 3.0f,3.0f,0.6f,1 },
    { -0.5f,-0.5f, 0.5f, 0.2f,0.4f,0.5f,1 },{ -0.5f,-0.5f,-0.5f, 0.2f,0.4f,0.5f,1 },{  0.5f,-0.5f,-0.5f, 0.2f,0.4f,0.5f,1 },{  0.5f,-0.5f, 0.5f, 0.2f,0.4f,0.5f,1 },
    { -0.5f,-0.5f, 0.5f, 0.4f,0.8f,4.0f,1 },{  0.5f,-0.5f, 0.5f, 0.4f,0.8f,4.0f,1 },{  0.5f, 0.5f, 0.5f, 0.4f,0.8f,4.0f,1 },{ -0.5f, 0.5f, 0.5f, 0.4f,0.8f,4.0f,1 },
    {  0.5f,-0.5f,-0.5f, 3.5f,0.5f,0.5f,1 },{ -0.5f,-0.5f,-0.5f, 3.5f,0.5f,0.5f,1 },{ -0.5f, 0.5f,-0.5f, 3.5f,0.5f,0.5f,1 },{  0.5f, 0.5f,-0.5f, 3.5f,0.5f,0.5f,1 },
};
static const Uint16 kIdx[36] = {
    0,1,2, 0,2,3, 4,5,6, 4,6,7, 8,9,10, 8,10,11,
    12,13,14, 12,14,15, 16,17,18, 16,18,19, 20,21,22, 20,22,23,
};

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_translate(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[12]=x;r.m[13]=y;r.m[14]=z; return r;}
static Mat4 mat4_rotate_y(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[0]=c;r.m[2]=-s;r.m[8]=s;r.m[10]=c; return r;}
static Mat4 mat4_rotate_x(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[5]=c;r.m[6]=s;r.m[9]=-s;r.m[10]=c; return r;}
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}

static const char *kSceneVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos [[attribute(0)]]; float4 color [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float4 color; };
struct UBO   { float4x4 mvp; };
vertex VSOut sceneVS(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o; o.position = u.mvp * float4(in.pos, 1.0); o.color = in.color; return o;
}
)msl";
static const char *kSceneFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float4 color; };
fragment float4 sceneFS(VSOut in [[stage_in]]) { return in.color; }   // raw HDR colour
)msl";

static const char *kPostVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
vertex VSOut postVS(uint vid [[vertex_id]]) {
    const float2 P[3] = { float2(-1,-1), float2(3,-1), float2(-1,3) };
    VSOut o; o.position = float4(P[vid], 0, 1);
    o.uv = P[vid] * 0.5 + 0.5; o.uv.y = 1.0 - o.uv.y;
    return o;
}
)msl";
static const char *kToneFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
struct Tone  { float exposure; float mode; float pad0, pad1; };
static float3 reinhard(float3 c) { return c / (1.0 + c); }
static float3 aces(float3 x) {
    const float a = 2.51, b = 0.03, c = 2.43, d = 0.59, e = 0.14;
    return clamp((x * (a*x + b)) / (x * (c*x + d) + e), 0.0, 1.0);
}
fragment float4 toneFS(VSOut in [[stage_in]],
                       texture2d<float> hdr [[texture(0)]], sampler smp [[sampler(0)]],
                       constant Tone &u [[buffer(0)]]) {
    float3 c = hdr.sample(smp, in.uv).rgb * u.exposure;
    float3 mapped = u.mode < 0.5 ? clamp(c, 0.0, 1.0)
                  : u.mode < 1.5 ? reinhard(c)
                                 : aces(c);
    mapped = pow(mapped, float3(1.0 / 2.2));
    return float4(mapped, 1.0);
}
)msl";

static const SDL_GPUTextureFormat kHDR = SDL_GPU_TEXTUREFORMAT_R16G16B16A16_FLOAT;

struct ToneUBO { float exposure, mode, pad0, pad1; };

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUGraphicsPipeline *scene_pipeline=nullptr, *tone_pipeline=nullptr;
    SDL_GPUBuffer *vbuf=nullptr, *ibuf=nullptr;
    SDL_GPUTexture *sceneHDR=nullptr, *depth=nullptr;
    SDL_GPUSampler *sampler=nullptr;
    Uint32 fb_w=0, fb_h=0; Uint64 start_ns=0;
    float exposure=1.0f; int mode=2;          // start on ACES
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e, Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s; i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d,&i);
}
static void upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev); SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb; SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false); SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb);
}
static SDL_GPUTexture *create_color_target(SDL_GPUDevice *dev, Uint32 w, Uint32 h, SDL_GPUTextureFormat fmt){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D; ti.format=fmt;
    ti.usage=SDL_GPU_TEXTUREUSAGE_COLOR_TARGET | SDL_GPU_TEXTUREUSAGE_SAMPLER;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}
static void resize_targets(AppState *st, Uint32 w, Uint32 h){
    if (st->sceneHDR) SDL_ReleaseGPUTexture(st->device, st->sceneHDR);
    if (st->depth)    SDL_ReleaseGPUTexture(st->device, st->depth);
    st->sceneHDR = create_color_target(st->device, w, h, kHDR);
    st->depth    = create_depth(st->device, w, h);
    st->fb_w=w; st->fb_h=h;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Tone Mapping and Gamma", "1.0", "com.example.sdl3.tonemap");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Tone Mapping and Gamma", 800, 600, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    SDL_GPUBufferCreateInfo vbi{}; vbi.usage=SDL_GPU_BUFFERUSAGE_VERTEX; vbi.size=sizeof(kCube); st->vbuf=SDL_CreateGPUBuffer(st->device,&vbi);
    SDL_GPUBufferCreateInfo ibi{}; ibi.usage=SDL_GPU_BUFFERUSAGE_INDEX;  ibi.size=sizeof(kIdx);  st->ibuf=SDL_CreateGPUBuffer(st->device,&ibi);
    upload_buffer(st->device, st->vbuf, kCube, sizeof(kCube));
    upload_buffer(st->device, st->ibuf, kIdx,  sizeof(kIdx));

    SDL_GPUSamplerCreateInfo si{}; si.min_filter=SDL_GPU_FILTER_LINEAR; si.mag_filter=SDL_GPU_FILTER_LINEAR;
    si.address_mode_u=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE; si.address_mode_v=SDL_GPU_SAMPLERADDRESSMODE_CLAMP_TO_EDGE;
    st->sampler = SDL_CreateGPUSampler(st->device, &si);

    // --- scene pipeline (HDR target, depth tested) ---
    SDL_GPUShader *svs=make_shader(st->device,kSceneVS,SDL_GPU_SHADERSTAGE_VERTEX,"sceneVS",1,0);
    SDL_GPUShader *sfs=make_shader(st->device,kSceneFS,SDL_GPU_SHADERSTAGE_FRAGMENT,"sceneFS",0,0);
    SDL_GPUVertexBufferDescription svb{}; svb.slot=0; svb.pitch=sizeof(Vertex); svb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute sa[2]{};
    sa[0].location=0; sa[0].buffer_slot=0; sa[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; sa[0].offset=offsetof(Vertex,x);
    sa[1].location=1; sa[1].buffer_slot=0; sa[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; sa[1].offset=offsetof(Vertex,r);
    SDL_GPUVertexInputState sv{}; sv.vertex_buffer_descriptions=&svb; sv.num_vertex_buffers=1; sv.vertex_attributes=sa; sv.num_vertex_attributes=2;
    SDL_GPUColorTargetDescription sct{}; sct.format=kHDR;
    SDL_GPUGraphicsPipelineCreateInfo sp{};
    sp.vertex_shader=svs; sp.fragment_shader=sfs; sp.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST; sp.vertex_input_state=sv;
    sp.target_info.color_target_descriptions=&sct; sp.target_info.num_color_targets=1;
    sp.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; sp.target_info.has_depth_stencil_target=true;
    sp.depth_stencil_state.enable_depth_test=true; sp.depth_stencil_state.enable_depth_write=true; sp.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;
    st->scene_pipeline=SDL_CreateGPUGraphicsPipeline(st->device,&sp);
    SDL_ReleaseGPUShader(st->device,svs); SDL_ReleaseGPUShader(st->device,sfs);
    if(!st->scene_pipeline) return fail("scene pipeline");

    // --- tone-map pipeline (fullscreen triangle -> swapchain) ---
    SDL_GPUTextureFormat swap = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    SDL_GPUShader *pvs=make_shader(st->device,kPostVS,SDL_GPU_SHADERSTAGE_VERTEX,"postVS",0,0);
    SDL_GPUShader *pfs=make_shader(st->device,kToneFS,SDL_GPU_SHADERSTAGE_FRAGMENT,"toneFS",1,1);
    SDL_GPUColorTargetDescription tct{}; tct.format=swap;
    SDL_GPUGraphicsPipelineCreateInfo tp{};
    tp.vertex_shader=pvs; tp.fragment_shader=pfs; tp.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    tp.target_info.color_target_descriptions=&tct; tp.target_info.num_color_targets=1;
    st->tone_pipeline=SDL_CreateGPUGraphicsPipeline(st->device,&tp);
    SDL_ReleaseGPUShader(st->device,pvs); SDL_ReleaseGPUShader(st->device,pfs);
    if(!st->tone_pipeline) return fail("tone pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN) {
        if (e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
        if (e->key.scancode == SDL_SCANCODE_SPACE) st->mode = (st->mode + 1) % 3;
        if (e->key.scancode == SDL_SCANCODE_UP)   st->exposure = SDL_min(8.0f, st->exposure * 1.25f);
        if (e->key.scancode == SDL_SCANCODE_DOWN) st->exposure = SDL_max(0.05f, st->exposure / 1.25f);
    }
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->fb_w || sh != st->fb_h) resize_targets(st, sw, sh);
        float aspect = sh > 0 ? (float)sw/(float)sh : 1.0f;
        Mat4 mvp = mat4_mul(mat4_perspective(60.0f*SDL_PI_F/180.0f, aspect, 0.1f, 100.0f),
                            mat4_mul(mat4_translate(0,0,-3.0f),
                                     mat4_mul(mat4_rotate_y(t*0.6f), mat4_rotate_x(t*0.4f))));

        // ---- Pass 1: scene into the HDR target ----
        SDL_GPUColorTargetInfo a{}; a.texture=st->sceneHDR; a.clear_color=SDL_FColor{0.0f,0.0f,0.01f,1};
        a.load_op=SDL_GPU_LOADOP_CLEAR; a.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo da{}; da.texture=st->depth; da.clear_depth=1.0f;
        da.load_op=SDL_GPU_LOADOP_CLEAR; da.store_op=SDL_GPU_STOREOP_DONT_CARE;
        SDL_GPURenderPass *p1 = SDL_BeginGPURenderPass(cmd, &a, 1, &da);
        SDL_BindGPUGraphicsPipeline(p1, st->scene_pipeline);
        SDL_GPUBufferBinding vb{}; vb.buffer=st->vbuf; SDL_BindGPUVertexBuffers(p1,0,&vb,1);
        SDL_GPUBufferBinding ib{}; ib.buffer=st->ibuf; SDL_BindGPUIndexBuffer(p1,&ib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        SDL_PushGPUVertexUniformData(cmd, 0, &mvp, sizeof(mvp));
        SDL_DrawGPUIndexedPrimitives(p1, 36, 1, 0, 0, 0);
        SDL_EndGPURenderPass(p1);

        // ---- Pass 2: tone-map the HDR target to the swapchain ----
        SDL_GPUColorTargetInfo b{}; b.texture=swap; b.clear_color=SDL_FColor{0,0,0,1};
        b.load_op=SDL_GPU_LOADOP_CLEAR; b.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p2 = SDL_BeginGPURenderPass(cmd, &b, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p2, st->tone_pipeline);
        SDL_GPUTextureSamplerBinding sb{}; sb.texture=st->sceneHDR; sb.sampler=st->sampler;
        SDL_BindGPUFragmentSamplers(p2, 0, &sb, 1);
        ToneUBO tu{ st->exposure, (float)st->mode, 0, 0 };
        SDL_PushGPUFragmentUniformData(cmd, 0, &tu, sizeof(tu));
        SDL_DrawGPUPrimitives(p2, 3, 1, 0, 0);
        SDL_EndGPURenderPass(p2);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->sampler)  SDL_ReleaseGPUSampler(st->device, st->sampler);
        if (st->sceneHDR) SDL_ReleaseGPUTexture(st->device, st->sceneHDR);
        if (st->depth)    SDL_ReleaseGPUTexture(st->device, st->depth);
        if (st->ibuf)     SDL_ReleaseGPUBuffer(st->device, st->ibuf);
        if (st->vbuf)     SDL_ReleaseGPUBuffer(st->device, st->vbuf);
        if (st->tone_pipeline)  SDL_ReleaseGPUGraphicsPipeline(st->device, st->tone_pipeline);
        if (st->scene_pipeline) SDL_ReleaseGPUGraphicsPipeline(st->device, st->scene_pipeline);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Add the Uncharted-2 (Hable) operator as a fourth mode and compare its shoulder/toe against ACES.
  2. Auto-exposure: read back an average luminance (or just fake it with a slow drift) and adapt exposure toward a target over time.
  3. Remove the gamma line and watch the whole image turn muddy — proof that the 1/2.2 encode is doing real work.
  4. Chain this after recipe 19's bloom: composite scene + bloom into the HDR target, then tone-map once at the very end.
