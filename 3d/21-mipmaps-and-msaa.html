Recipe 21 — Mipmaps & MSAA

Two anti-aliasing tools, side by side. Mipmaps kill the shimmer on a receding textured ground plane; 4× MSAA smooths the jagged edges of the cubes standing on it. The polished finish for the 3D track.

What you'll learn

  • Creating a texture with a full mip chain and generating it with SDL_GenerateMipmapsForGPUTexture.
  • A trilinear sampler — mipmap_mode = LINEAR plus a generous max_lod — and optional anisotropy.
  • An MSAA colour target and a matching multisample_state.sample_count on the pipeline.
  • Resolving a multisampled target into the swapchain with store_op = RESOLVE and resolve_texture.

Prerequisites

Recipe 08 — Textures & Samplers for texture upload and sampler creation; the camera math from recipe 11 is handy but not required. These are the most recent SDL_GPU features in the track — the note below flags exactly what was checked against the headers.

Walkthrough

Two different aliasing problems

Aliasing shows up in two places. On a textured surface receding into the distance, many texels fall inside one pixel; sampling just one of them makes the texture sparkle and crawl as the camera moves — that's minification aliasing, and mipmaps fix it. On a geometric edge, the triangle either covers a pixel or doesn't, producing a hard staircase — that's edge aliasing, and MSAA fixes it. This recipe uses both at once.

Mipmaps — a pyramid of pre-shrunk copies

A mipmapped texture stores the full image plus a chain of half-size copies down to 1×1. When a surface is far away the GPU reads from a smaller, pre-averaged level instead of point-sampling the full image, so distant texels stop shimmering. The level count is floor(log2(max(w,h))) + 1. You upload level 0 and let SDL build the rest. 

Uint32 mip_levels = 1;
for (Uint32 s = (W > H ? W : H); s > 1; s >>= 1) ++mip_levels;   // floor(log2(max))+1

SDL_GPUTextureCreateInfo ti{};
ti.type   = SDL_GPU_TEXTURETYPE_2D;
ti.format = SDL_GPU_TEXTUREFORMAT_R8G8B8A8_UNORM;
// COLOR_TARGET is required: SDL_GenerateMipmapsForGPUTexture renders the lower levels.
ti.usage  = SDL_GPU_TEXTUREUSAGE_SAMPLER | SDL_GPU_TEXTUREUSAGE_COLOR_TARGET;
ti.width  = W; ti.height = H;
ti.layer_count_or_depth = 1;
ti.num_levels   = mip_levels;
ti.sample_count = SDL_GPU_SAMPLECOUNT_1;
st->ground_tex = SDL_CreateGPUTexture(st->device, &ti);

After uploading level 0 with the usual transfer-buffer copy, generate the rest. SDL_GenerateMipmapsForGPUTexture takes a command buffer (not a copy pass) and must be called outside any pass: 

SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(dev);
// ... upload level 0 inside a copy pass, end it ...
SDL_GenerateMipmapsForGPUTexture(cmd, st->ground_tex);   // fills levels 1..N-1
SDL_SubmitGPUCommandBuffer(cmd);

A trilinear sampler

Linear within a level (bilinear) plus linear between levels (mipmap_mode = LINEAR) gives trilinear filtering — smooth blending as the surface recedes. max_lod must be high enough to reach the smallest level. Optional anisotropy sharpens textures viewed at a grazing angle, like a ground plane. 

SDL_GPUSamplerCreateInfo si{};
si.min_filter     = SDL_GPU_FILTER_LINEAR;
si.mag_filter     = SDL_GPU_FILTER_LINEAR;
si.mipmap_mode    = SDL_GPU_SAMPLERMIPMAPMODE_LINEAR;     // trilinear
si.address_mode_u = SDL_GPU_SAMPLERADDRESSMODE_REPEAT;
si.address_mode_v = SDL_GPU_SAMPLERADDRESSMODE_REPEAT;
si.min_lod        = 0.0f;
si.max_lod        = 1000.0f;                              // allow the whole chain
si.enable_anisotropy = true;                             // optional, big win at grazing angles
si.max_anisotropy    = 8.0f;
st->sampler = SDL_CreateGPUSampler(st->device, &si);

MSAA — sample the edge several times

With a 4× multisampled colour target the rasteriser tests coverage at four sub-pixel positions per pixel and averages them, so edges fade smoothly instead of stepping. Two things must agree: the colour target's sample_count and the pipeline's multisample_state.sample_count. 

// Multisampled colour target (rendered into, never sampled directly).
SDL_GPUTextureCreateInfo mi{};
mi.type=SDL_GPU_TEXTURETYPE_2D; mi.format=swap_fmt;
mi.usage=SDL_GPU_TEXTUREUSAGE_COLOR_TARGET;
mi.width=w; mi.height=h; mi.layer_count_or_depth=1; mi.num_levels=1;
mi.sample_count=SDL_GPU_SAMPLECOUNT_4;
st->msaa_color = SDL_CreateGPUTexture(st->device, &mi);

// Pipeline must match the target's sample count.
pci.multisample_state.sample_count = SDL_GPU_SAMPLECOUNT_4;

The depth target used with an MSAA pass must also be 4× — create it with sample_count = SDL_GPU_SAMPLECOUNT_4.

Resolving into the swapchain

A multisampled texture can't be presented directly; its samples have to be resolved down to one sample per pixel. SDL does this as part of ending the pass: bind the MSAA texture as texture, the single-sample swapchain as resolve_texture, and set store_op = SDL_GPU_STOREOP_RESOLVE. 

SDL_GPUColorTargetInfo cti{};
cti.texture         = st->msaa_color;                 // 4× target we render into
cti.resolve_texture = swap;                           // 1× swapchain receives the resolve
cti.clear_color     = SDL_FColor{0.05f,0.06f,0.09f,1};
cti.load_op         = SDL_GPU_LOADOP_CLEAR;
cti.store_op        = SDL_GPU_STOREOP_RESOLVE;        // resolve at end of pass
// (Use SDL_GPU_STOREOP_RESOLVE_AND_STORE if you also need the MSAA contents kept.)
API verification. Every name used here was checked against the current SDL3 GPU wiki: SDL_GenerateMipmapsForGPUTexture(command_buffer, texture) (takes a command buffer, called outside any pass); SDL_GPU_SAMPLERMIPMAPMODE_LINEAR; the sampler's enable_anisotropy / max_anisotropy / min_lod / max_lod fields; SDL_GPUMultisampleState::sample_count; SDL_GPU_STOREOP_RESOLVE and SDL_GPU_STOREOP_RESOLVE_AND_STORE; and the resolve_texture / resolve_mip_level / resolve_layer fields of SDL_GPUColorTargetInfo. Note that SDL_GenerateMipmapsForGPUTexture requires the texture to carry the COLOR_TARGET usage flag, since it renders the smaller levels.

Complete listing

A large textured ground plane stretches to the horizon — mipmaps keep its distant texels calm — with a row of cubes whose edges 4× MSAA softens. The scene renders into a multisampled target and resolves into the swapchain on present. 

/*
 * 21-mipmaps-and-msaa.cpp — mipmapped ground plane (trilinear + anisotropic) and
 * a 4x MSAA colour target resolved into the swapchain. Final 3D-track recipe.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>

#include <cstring>
#include <cstddef>
#include <vector>

static const SDL_GPUSampleCount kSamples = SDL_GPU_SAMPLECOUNT_4;

struct Vertex { float x, y, z, u, v; };

// A big ground quad on the XZ plane, UVs tiled many times so minification bites.
static const Vertex kGround[4] = {
    { -40.0f, -1.0f, -40.0f,  0.0f,  0.0f },
    { -40.0f, -1.0f,  40.0f,  0.0f, 40.0f },
    {  40.0f, -1.0f,  40.0f, 40.0f, 40.0f },
    {  40.0f, -1.0f, -40.0f, 40.0f,  0.0f },
};
static const Uint16 kGroundIdx[6] = { 0,1,2, 0,2,3 };

// A textured cube (same UV-per-face layout as recipe 08).
static const Vertex kCube[24] = {
    {  0.5f,-0.5f, 0.5f, 0,0 },{  0.5f, 0.5f, 0.5f, 0,1 },{  0.5f, 0.5f,-0.5f, 1,1 },{  0.5f,-0.5f,-0.5f, 1,0 },
    { -0.5f,-0.5f,-0.5f, 0,0 },{ -0.5f, 0.5f,-0.5f, 0,1 },{ -0.5f, 0.5f, 0.5f, 1,1 },{ -0.5f,-0.5f, 0.5f, 1,0 },
    { -0.5f, 0.5f, 0.5f, 0,0 },{ -0.5f, 0.5f,-0.5f, 0,1 },{  0.5f, 0.5f,-0.5f, 1,1 },{  0.5f, 0.5f, 0.5f, 1,0 },
    { -0.5f,-0.5f,-0.5f, 0,0 },{ -0.5f,-0.5f, 0.5f, 0,1 },{  0.5f,-0.5f, 0.5f, 1,1 },{  0.5f,-0.5f,-0.5f, 1,0 },
    { -0.5f,-0.5f, 0.5f, 0,0 },{ -0.5f, 0.5f, 0.5f, 0,1 },{  0.5f, 0.5f, 0.5f, 1,1 },{  0.5f,-0.5f, 0.5f, 1,0 },
    {  0.5f,-0.5f,-0.5f, 0,0 },{  0.5f, 0.5f,-0.5f, 0,1 },{ -0.5f, 0.5f,-0.5f, 1,1 },{ -0.5f,-0.5f,-0.5f, 1,0 },
};
static const Uint16 kCubeIdx[36] = {
    0,1,2, 4,5,6, 8,9,10, 12,13,14, 16,17,18, 20,21,22,
    0,2,3, 4,6,7, 8,10,11, 12,14,15, 16,18,19, 20,22,23,
};

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_translate(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[12]=x;r.m[13]=y;r.m[14]=z; return r;}
static Mat4 mat4_rotate_y(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[0]=c;r.m[2]=-s;r.m[8]=s;r.m[10]=c; return r;}
static Mat4 mat4_rotate_x(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[5]=c;r.m[6]=s;r.m[9]=-s;r.m[10]=c; return r;}
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos [[attribute(0)]]; float2 uv [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float2 uv; };
struct UBO   { float4x4 mvp; };
vertex VSOut vertexMain(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o; o.position = u.mvp * float4(in.pos, 1.0); o.uv = in.uv; return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float2 uv; };
fragment float4 fragmentMain(VSOut in [[stage_in]],
                             texture2d<float> tex [[texture(0)]],
                             sampler smp [[sampler(0)]]) {
    return tex.sample(smp, in.uv);
}
)msl";

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUGraphicsPipeline *pipeline=nullptr;
    SDL_GPUBuffer *ground_vb=nullptr, *ground_ib=nullptr, *cube_vb=nullptr, *cube_ib=nullptr;
    SDL_GPUTexture *tex=nullptr;
    SDL_GPUTexture *msaa_color=nullptr, *msaa_depth=nullptr;
    SDL_GPUSampler *sampler=nullptr;
    SDL_GPUTextureFormat swap_fmt=SDL_GPU_TEXTUREFORMAT_INVALID;
    Uint32 fb_w=0, fb_h=0;
    Uint64 start_ns=0;
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e,
                                  Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s;
    i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d, &i);
}
static bool upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev);
    SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb;
    SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false);
    SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb); return true;
}

// Upload level 0, then generate the rest of the mip chain in the same command buffer.
static void upload_mipmapped_texture(SDL_GPUDevice *dev, SDL_GPUTexture *dst,
                                     const void *src, Uint32 w, Uint32 h){
    Uint32 size = w * h * 4;
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);

    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev);
    SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTextureTransferInfo s{}; s.transfer_buffer=tb; s.pixels_per_row=w; s.rows_per_layer=h;
    SDL_GPUTextureRegion r{}; r.texture=dst; r.w=w; r.h=h; r.d=1; r.mip_level=0;   // level 0 only
    SDL_UploadToGPUTexture(cp,&s,&r,false);
    SDL_EndGPUCopyPass(cp);
    SDL_GenerateMipmapsForGPUTexture(cmd, dst);   // outside any pass; fills levels 1..N-1
    SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb);
}

static void resize_msaa(AppState *st, Uint32 w, Uint32 h){
    if (st->msaa_color) SDL_ReleaseGPUTexture(st->device, st->msaa_color);
    if (st->msaa_depth) SDL_ReleaseGPUTexture(st->device, st->msaa_depth);

    SDL_GPUTextureCreateInfo ci{}; ci.type=SDL_GPU_TEXTURETYPE_2D; ci.format=st->swap_fmt;
    ci.usage=SDL_GPU_TEXTUREUSAGE_COLOR_TARGET;
    ci.width=w; ci.height=h; ci.layer_count_or_depth=1; ci.num_levels=1; ci.sample_count=kSamples;
    st->msaa_color = SDL_CreateGPUTexture(st->device, &ci);

    SDL_GPUTextureCreateInfo di{}; di.type=SDL_GPU_TEXTURETYPE_2D; di.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    di.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    di.width=w; di.height=h; di.layer_count_or_depth=1; di.num_levels=1; di.sample_count=kSamples;
    st->msaa_depth = SDL_CreateGPUTexture(st->device, &di);

    st->fb_w=w; st->fb_h=h;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Mipmaps & MSAA", "1.0", "com.example.sdl3.aa");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Mipmaps & MSAA", 800, 600, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);
    st->swap_fmt = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);

    // --- geometry ---
    SDL_GPUBufferCreateInfo gvb{}; gvb.usage=SDL_GPU_BUFFERUSAGE_VERTEX; gvb.size=sizeof(kGround);
    st->ground_vb=SDL_CreateGPUBuffer(st->device,&gvb);
    SDL_GPUBufferCreateInfo gib{}; gib.usage=SDL_GPU_BUFFERUSAGE_INDEX;  gib.size=sizeof(kGroundIdx);
    st->ground_ib=SDL_CreateGPUBuffer(st->device,&gib);
    SDL_GPUBufferCreateInfo cvb{}; cvb.usage=SDL_GPU_BUFFERUSAGE_VERTEX; cvb.size=sizeof(kCube);
    st->cube_vb=SDL_CreateGPUBuffer(st->device,&cvb);
    SDL_GPUBufferCreateInfo cib{}; cib.usage=SDL_GPU_BUFFERUSAGE_INDEX;  cib.size=sizeof(kCubeIdx);
    st->cube_ib=SDL_CreateGPUBuffer(st->device,&cib);
    upload_buffer(st->device, st->ground_vb, kGround,    sizeof(kGround));
    upload_buffer(st->device, st->ground_ib, kGroundIdx, sizeof(kGroundIdx));
    upload_buffer(st->device, st->cube_vb,   kCube,      sizeof(kCube));
    upload_buffer(st->device, st->cube_ib,   kCubeIdx,   sizeof(kCubeIdx));

    // --- mipmapped checker texture ---
    const Uint32 W = 256, H = 256;
    std::vector<Uint32> pixels(W * H);
    for (Uint32 y = 0; y < H; ++y)
        for (Uint32 x = 0; x < W; ++x) {
            bool on = ((x / 16) + (y / 16)) % 2 == 0;
            pixels[y * W + x] = on ? 0xFFE0E0E0u : 0xFF303030u;   // ABGR-LE grey checker
        }
    Uint32 mip_levels = 1;
    for (Uint32 s = (W > H ? W : H); s > 1; s >>= 1) ++mip_levels;   // floor(log2(max))+1

    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_R8G8B8A8_UNORM;
    ti.usage = SDL_GPU_TEXTUREUSAGE_SAMPLER | SDL_GPU_TEXTUREUSAGE_COLOR_TARGET;   // COLOR_TARGET for mip gen
    ti.width=W; ti.height=H; ti.layer_count_or_depth=1; ti.num_levels=mip_levels; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    st->tex = SDL_CreateGPUTexture(st->device, &ti);
    upload_mipmapped_texture(st->device, st->tex, pixels.data(), W, H);

    // --- trilinear + anisotropic sampler ---
    SDL_GPUSamplerCreateInfo si{};
    si.min_filter=SDL_GPU_FILTER_LINEAR; si.mag_filter=SDL_GPU_FILTER_LINEAR;
    si.mipmap_mode=SDL_GPU_SAMPLERMIPMAPMODE_LINEAR;
    si.address_mode_u=SDL_GPU_SAMPLERADDRESSMODE_REPEAT;
    si.address_mode_v=SDL_GPU_SAMPLERADDRESSMODE_REPEAT;
    si.min_lod=0.0f; si.max_lod=1000.0f;
    si.enable_anisotropy=true; si.max_anisotropy=8.0f;
    st->sampler = SDL_CreateGPUSampler(st->device, &si);

    // --- pipeline: MSAA sample count must match the colour target ---
    SDL_GPUShader *vs = make_shader(st->device, kVS, SDL_GPU_SHADERSTAGE_VERTEX,   "vertexMain",   1, 0);
    SDL_GPUShader *fs = make_shader(st->device, kFS, SDL_GPU_SHADERSTAGE_FRAGMENT, "fragmentMain", 0, 1);

    SDL_GPUVertexBufferDescription vb{}; vb.slot=0; vb.pitch=sizeof(Vertex); vb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute attrs[2]{};
    attrs[0].location=0; attrs[0].buffer_slot=0; attrs[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[0].offset=offsetof(Vertex,x);
    attrs[1].location=1; attrs[1].buffer_slot=0; attrs[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT2; attrs[1].offset=offsetof(Vertex,u);
    SDL_GPUVertexInputState vis{}; vis.vertex_buffer_descriptions=&vb; vis.num_vertex_buffers=1; vis.vertex_attributes=attrs; vis.num_vertex_attributes=2;

    SDL_GPUColorTargetDescription ct{}; ct.format=st->swap_fmt;
    SDL_GPUGraphicsPipelineCreateInfo pci{};
    pci.vertex_shader=vs; pci.fragment_shader=fs;
    pci.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    pci.vertex_input_state=vis;
    pci.multisample_state.sample_count=kSamples;        // match the MSAA target
    pci.target_info.color_target_descriptions=&ct;
    pci.target_info.num_color_targets=1;
    pci.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    pci.target_info.has_depth_stencil_target=true;
    pci.depth_stencil_state.enable_depth_test=true;
    pci.depth_stencil_state.enable_depth_write=true;
    pci.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;
    st->pipeline = SDL_CreateGPUGraphicsPipeline(st->device, &pci);
    SDL_ReleaseGPUShader(st->device, vs); SDL_ReleaseGPUShader(st->device, fs);
    if (!st->pipeline) return fail("pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *, SDL_Event *e)
{
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->fb_w || sh != st->fb_h) resize_msaa(st, sw, sh);
        float aspect = sh > 0 ? (float)sw / (float)sh : 1.0f;

        // Camera looking down the plane toward the horizon (grazing the ground).
        Mat4 view = mat4_mul(mat4_translate(0, -0.5f, -6.0f), mat4_rotate_x(0.35f));
        Mat4 proj = mat4_perspective(60.0f * SDL_PI_F / 180.0f, aspect, 0.1f, 200.0f);
        Mat4 vp   = mat4_mul(proj, view);

        // Render into the multisampled target; resolve into the swapchain on store.
        SDL_GPUColorTargetInfo cti{};
        cti.texture         = st->msaa_color;
        cti.resolve_texture = swap;
        cti.clear_color     = SDL_FColor{0.05f,0.06f,0.09f,1};
        cti.load_op         = SDL_GPU_LOADOP_CLEAR;
        cti.store_op        = SDL_GPU_STOREOP_RESOLVE;
        SDL_GPUDepthStencilTargetInfo dti{};
        dti.texture=st->msaa_depth; dti.clear_depth=1.0f;
        dti.load_op=SDL_GPU_LOADOP_CLEAR; dti.store_op=SDL_GPU_STOREOP_DONT_CARE;

        SDL_GPURenderPass *pass = SDL_BeginGPURenderPass(cmd, &cti, 1, &dti);
        SDL_BindGPUGraphicsPipeline(pass, st->pipeline);
        SDL_GPUTextureSamplerBinding tsb{}; tsb.texture=st->tex; tsb.sampler=st->sampler;
        SDL_BindGPUFragmentSamplers(pass, 0, &tsb, 1);

        // Ground plane (mipmaps tame the distant shimmer).
        SDL_GPUBufferBinding gvb{}; gvb.buffer=st->ground_vb; SDL_BindGPUVertexBuffers(pass,0,&gvb,1);
        SDL_GPUBufferBinding gib{}; gib.buffer=st->ground_ib; SDL_BindGPUIndexBuffer(pass,&gib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        Mat4 ground_mvp = vp;   // ground is already in world space
        SDL_PushGPUVertexUniformData(cmd, 0, &ground_mvp, sizeof(ground_mvp));
        SDL_DrawGPUIndexedPrimitives(pass, 6, 1, 0, 0, 0);

        // A row of cubes (MSAA smooths their edges).
        SDL_GPUBufferBinding cvb{}; cvb.buffer=st->cube_vb; SDL_BindGPUVertexBuffers(pass,0,&cvb,1);
        SDL_GPUBufferBinding cib{}; cib.buffer=st->cube_ib; SDL_BindGPUIndexBuffer(pass,&cib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        for (int i = -2; i <= 2; ++i) {
            Mat4 model = mat4_mul(mat4_translate((float)i * 2.2f, -0.5f, -2.0f - (float)(i*i)),
                                  mat4_rotate_y(t * 0.6f + (float)i));
            Mat4 mvp = mat4_mul(vp, model);
            SDL_PushGPUVertexUniformData(cmd, 0, &mvp, sizeof(mvp));
            SDL_DrawGPUIndexedPrimitives(pass, 36, 1, 0, 0, 0);
        }
        SDL_EndGPURenderPass(pass);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->sampler)    SDL_ReleaseGPUSampler(st->device, st->sampler);
        if (st->tex)        SDL_ReleaseGPUTexture(st->device, st->tex);
        if (st->msaa_color) SDL_ReleaseGPUTexture(st->device, st->msaa_color);
        if (st->msaa_depth) SDL_ReleaseGPUTexture(st->device, st->msaa_depth);
        if (st->cube_ib)    SDL_ReleaseGPUBuffer(st->device, st->cube_ib);
        if (st->cube_vb)    SDL_ReleaseGPUBuffer(st->device, st->cube_vb);
        if (st->ground_ib)  SDL_ReleaseGPUBuffer(st->device, st->ground_ib);
        if (st->ground_vb)  SDL_ReleaseGPUBuffer(st->device, st->ground_vb);
        SDL_ReleaseGPUGraphicsPipeline(st->device, st->pipeline);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Toggle the sample count between SDL_GPU_SAMPLECOUNT_1, _2, _4 and _8 (change kSamples; both the targets and the pipeline pick it up). Watch the cube edges go from a staircase to glass-smooth — and the cost climb.
  2. Compare SDL_GPU_SAMPLERMIPMAPMODE_NEAREST against LINEAR on the ground plane. Nearest snaps abruptly between mip levels (a visible "mip line"); linear blends them seamlessly.
  3. Turn anisotropy off (enable_anisotropy = false) and look at the ground at a grazing angle — it blurs into mush in the distance. Turn it back on and the texture stays crisp far away.
  4. Tint each mip level a different colour at generation time (or in a custom mip-gen pass) to see exactly which level the GPU samples where — distant pixels light up as higher levels.

And that completes the 3D track. You started with a single triangle and a bare SDL_GPU pipeline, grew it into a lit and textured cube, learned to fly around it with an FPS camera, then rendered the world into offscreen targets and dressed it with skyboxes, normal maps and cast shadows. From there you put the GPU to work on its own simulations, drew whole fields in one instanced draw, made bright things glow, layered transparency correctly, and finally smoothed the whole image with mipmaps and MSAA. That is a complete real-time renderer's toolkit — every technique here is a building block you'll recognise in any modern engine.
