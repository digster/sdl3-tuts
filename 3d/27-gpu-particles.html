Recipe 27 — GPU Particles

Grow the compute fountain into a 3D system. A flow field swirls tens of thousands of particles under a perspective camera, the mouse becomes an attractor, and additive blending turns dense regions into glow — all simulated and drawn without the data ever leaving the GPU.

What you'll learn

  • Taking the recipe-17 compute particle buffer into 3D world space under an MVP camera.
  • Advecting particles through a procedural flow field instead of plain gravity.
  • An interactive attractor fed from the mouse into the compute kernel.
  • Additive point billboards coloured by speed and life.

Prerequisites

Recipe 17 — Compute Shaders built the flat 2D fountain and the dispatch-then-draw plumbing; this recipe keeps that machinery and lifts it into 3D. Recipe 20 supplies the blend state. It's the SDL_GPU twin of bgfx recipe 22.

Walkthrough

3D particles, same buffer trick

The particles still live in one buffer flagged VERTEX | COMPUTE_STORAGE_READ | COMPUTE_STORAGE_WRITE — the compute pass simulates it, the render pass draws it, SDL inserts the barrier. The only change from recipe 17 is the data: each particle is now a float4 position+life and a float4 velocity, in world space. 

struct Particle { float pos[4]; float vel[4]; };   // pos.xyz + life, vel.xyz

A flow field plus a mouse attractor

Recipe 17 pushed every particle with the same gravity. Here a cheap sine-based field gives a different velocity at every point in space, and a linear pull toward an attractor (no normalize, so no singularity) lets the mouse stir the swarm. 

# cs_particles (excerpt) — params.p0 = (dt, time, count, attractStrength)
float3 flow = float3(sin(p.y*1.3 + p.z*0.7),
                     sin(p.z*1.1 + p.x*0.9),
                     sin(p.x*1.2 + p.y*0.8)) * 1.2;
flow += (u.attractor.xyz - p.xyz) * u.p0.w;        // pull toward the mouse
v.xyz = v.xyz * 0.96 + flow * u.p0.x;              // damping
p.xyz += v.xyz * u.p0.x;
p.w   -= u.p0.x;                                    // age; respawn when life runs out

Additive billboards under the camera

The render pipeline draws the buffer as a POINTLIST with the MVP applied in the vertex shader and point_size set for visible billboards. The colour target enables additive blending so overlapping particles sum to white in dense regions — the cheapest glow there is. 

SDL_GPUColorTargetBlendState bs{};
bs.enable_blend = true;
bs.src_color_blendfactor = SDL_GPU_BLENDFACTOR_ONE;   // additive
bs.dst_color_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
bs.color_blend_op        = SDL_GPU_BLENDOP_ADD;
bs.src_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
bs.dst_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
bs.alpha_blend_op        = SDL_GPU_BLENDOP_ADD;
ct.blend_state = bs;
The CPU barely works. As in recipe 17, the CPU only ticks the clock, feeds the mouse, and counts workgroups; born, simulated and drawn entirely on the GPU, this scales to hundreds of thousands of particles. The bgfx track tells the same story with bgfx::Encoder and a dynamic buffer in recipe 22.

Complete listing

65,536 particles advected through a flow field under an orbiting camera, glowing additively, hot where they move fast. Hold the left mouse button and move to drag an attractor through the swarm. 

/*
 * 27-gpu-particles.cpp — 3D compute particle system: flow field + mouse attractor,
 * additive point billboards. Compute machinery from recipe 17, blend from recipe 20.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>
#include <cstring>
#include <cstddef>
#include <vector>

static const int N = 65536;

struct Particle { float pos[4]; float vel[4]; };   // pos.xyz + life, vel.xyz

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}
static Mat4 mat4_look_at(float ex,float ey,float ez, float cx,float cy,float cz, float ux,float uy,float uz){
    float fx=cx-ex, fy=cy-ey, fz=cz-ez; float fl=1.0f/SDL_sqrtf(fx*fx+fy*fy+fz*fz); fx*=fl; fy*=fl; fz*=fl;
    float sx=fy*uz-fz*uy, sy=fz*ux-fx*uz, sz=fx*uy-fy*ux; float sl=1.0f/SDL_sqrtf(sx*sx+sy*sy+sz*sz); sx*=sl; sy*=sl; sz*=sl;
    float vx=sy*fz-sz*fy, vy=sz*fx-sx*fz, vz=sx*fy-sy*fx;
    Mat4 r=mat4_identity();
    r.m[0]=sx; r.m[4]=sy; r.m[8]=sz;
    r.m[1]=vx; r.m[5]=vy; r.m[9]=vz;
    r.m[2]=-fx; r.m[6]=-fy; r.m[10]=-fz;
    r.m[12]=-(sx*ex+sy*ey+sz*ez); r.m[13]=-(vx*ex+vy*ey+vz*ez); r.m[14]=(fx*ex+fy*ey+fz*ez);
    return r;
}

static const char *kCompute = R"msl(
#include <metal_stdlib>
using namespace metal;
struct Particle { float4 pos; float4 vel; };
struct Params   { float4 p0; float4 attractor; };   // p0 = (dt, time, count, attract)
static float hash(float n) { return fract(sin(n) * 43758.5453); }
kernel void cs(constant Params &u [[buffer(0)]], device Particle *pt [[buffer(1)]],
               uint id [[thread_position_in_grid]]) {
    if (float(id) >= u.p0.z) return;
    float4 p = pt[id].pos;
    float4 v = pt[id].vel;
    float3 flow = float3(sin(p.y*1.3 + p.z*0.7),
                         sin(p.z*1.1 + p.x*0.9),
                         sin(p.x*1.2 + p.y*0.8)) * 1.2;
    flow += (u.attractor.xyz - p.xyz) * u.p0.w;       // linear pull, no singularity
    v.xyz = v.xyz * 0.96 + flow * u.p0.x;
    p.xyz += v.xyz * u.p0.x;
    p.w   -= u.p0.x;
    if (p.w <= 0.0) {                                  // respawn in the seed volume
        float r  = hash(float(id) * 12.9898 + u.p0.y);
        float r2 = hash(float(id) * 78.233  + u.p0.y);
        float r3 = hash(float(id) * 37.719  + u.p0.y);
        p = float4((r-0.5)*6.0, (r2-0.5)*4.0, (r3-0.5)*6.0, 1.5 + 2.0*r);
        v = float4(0.0);
    }
    pt[id].pos = p; pt[id].vel = v;
}
)msl";

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float4 pos [[attribute(0)]]; float4 vel [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float point_size [[point_size]]; float4 color; };
struct VUBO  { float4x4 mvp; };
vertex VSOut vs(VSIn in [[stage_in]], constant VUBO &u [[buffer(0)]]) {
    VSOut o;
    o.position   = u.mvp * float4(in.pos.xyz, 1.0);
    o.point_size = 3.0;
    float life = clamp(in.pos.w, 0.0, 1.0);
    float spd  = length(in.vel.xyz);
    float3 cold = float3(0.10, 0.30, 0.90), hot = float3(1.0, 0.6, 0.2);
    o.color = float4(mix(cold, hot, clamp(spd*0.4, 0.0, 1.0)) * (0.25 + 0.75*life), 1.0);
    return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float point_size [[point_size]]; float4 color; };
fragment float4 fs(VSOut in [[stage_in]]) { return in.color; }
)msl";

struct VUBO   { Mat4 mvp; };
struct Params { float p0[4]; float attractor[4]; };

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUComputePipeline *compute=nullptr;
    SDL_GPUGraphicsPipeline *draw=nullptr;
    SDL_GPUBuffer *particles=nullptr;
    float mouseX=0, mouseY=0; bool attracting=false;
    int win_w=900, win_h=600;
    Uint64 start_ns=0, last_ns=0;
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e, Uint32 ubo){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s; i.num_uniform_buffers=ubo;
    return SDL_CreateGPUShader(d,&i);
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("GPU Particles", "1.0", "com.example.sdl3.gpuparticles");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("GPU Particles", st->win_w, st->win_h, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    // Particle buffer: drawn as vertices AND simulated as compute storage.
    SDL_GPUBufferCreateInfo bi{};
    bi.usage = SDL_GPU_BUFFERUSAGE_VERTEX | SDL_GPU_BUFFERUSAGE_COMPUTE_STORAGE_READ | SDL_GPU_BUFFERUSAGE_COMPUTE_STORAGE_WRITE;
    bi.size  = sizeof(Particle) * N;
    st->particles = SDL_CreateGPUBuffer(st->device, &bi);

    std::vector<Particle> init(N);
    for (int i = 0; i < N; ++i)
        init[i] = { { (SDL_randf()-0.5f)*6, (SDL_randf()-0.5f)*4, (SDL_randf()-0.5f)*6, SDL_randf()*2.0f },
                    { 0, 0, 0, 0 } };
    {   // upload the seed state
        SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=(Uint32)bi.size;
        SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(st->device,&tbi);
        void *m=SDL_MapGPUTransferBuffer(st->device,tb,false); std::memcpy(m,init.data(),bi.size); SDL_UnmapGPUTransferBuffer(st->device,tb);
        SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(st->device); SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
        SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb; SDL_GPUBufferRegion r{}; r.buffer=st->particles; r.size=(Uint32)bi.size;
        SDL_UploadToGPUBuffer(cp,&s,&r,false); SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
        SDL_ReleaseGPUTransferBuffer(st->device,tb);
    }

    SDL_GPUComputePipelineCreateInfo ci{};
    ci.code=(const Uint8*)kCompute; ci.code_size=std::strlen(kCompute);
    ci.entrypoint="cs"; ci.format=SDL_GPU_SHADERFORMAT_MSL;
    ci.num_uniform_buffers=1; ci.num_readwrite_storage_buffers=1;
    ci.threadcount_x=64; ci.threadcount_y=1; ci.threadcount_z=1;
    st->compute = SDL_CreateGPUComputePipeline(st->device, &ci);
    if (!st->compute) return fail("compute pipeline");

    SDL_GPUShader *vs=make_shader(st->device,kVS,SDL_GPU_SHADERSTAGE_VERTEX,"vs",1);
    SDL_GPUShader *fs=make_shader(st->device,kFS,SDL_GPU_SHADERSTAGE_FRAGMENT,"fs",0);
    SDL_GPUVertexBufferDescription vb{}; vb.slot=0; vb.pitch=sizeof(Particle); vb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute a[2]{};
    a[0].location=0; a[0].buffer_slot=0; a[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; a[0].offset=offsetof(Particle,pos);
    a[1].location=1; a[1].buffer_slot=0; a[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; a[1].offset=offsetof(Particle,vel);
    SDL_GPUVertexInputState vi{}; vi.vertex_buffer_descriptions=&vb; vi.num_vertex_buffers=1; vi.vertex_attributes=a; vi.num_vertex_attributes=2;

    SDL_GPUColorTargetBlendState bs{};
    bs.enable_blend = true;
    bs.src_color_blendfactor = SDL_GPU_BLENDFACTOR_ONE;      // additive
    bs.dst_color_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
    bs.color_blend_op        = SDL_GPU_BLENDOP_ADD;
    bs.src_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
    bs.dst_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
    bs.alpha_blend_op        = SDL_GPU_BLENDOP_ADD;
    SDL_GPUColorTargetDescription ct{}; ct.format=SDL_GetGPUSwapchainTextureFormat(st->device, st->window); ct.blend_state=bs;

    SDL_GPUGraphicsPipelineCreateInfo pc{};
    pc.vertex_shader=vs; pc.fragment_shader=fs; pc.primitive_type=SDL_GPU_PRIMITIVETYPE_POINTLIST; pc.vertex_input_state=vi;
    pc.target_info.color_target_descriptions=&ct; pc.target_info.num_color_targets=1;
    st->draw=SDL_CreateGPUGraphicsPipeline(st->device,&pc);
    SDL_ReleaseGPUShader(st->device,vs); SDL_ReleaseGPUShader(st->device,fs);
    if(!st->draw) return fail("draw pipeline");

    st->start_ns = st->last_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *appstate, SDL_Event *e)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_MOUSE_MOTION) { st->mouseX = e->motion.x; st->mouseY = e->motion.y; }
    if (e->type == SDL_EVENT_MOUSE_BUTTON_DOWN && e->button.button == SDL_BUTTON_LEFT) st->attracting = true;
    if (e->type == SDL_EVENT_MOUSE_BUTTON_UP   && e->button.button == SDL_BUTTON_LEFT) st->attracting = false;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    Uint64 now = SDL_GetTicksNS();
    float dt = (now - st->last_ns) / 1.0e9f; if (dt > 0.05f) dt = 0.05f;
    st->last_ns = now;
    float time = (now - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);

    // Map the mouse to a point on the z = 0 plane, roughly framing the swarm
    // (win_w/win_h hold the size from the previous frame, refreshed after acquire).
    float ax = ((float)st->mouseX / st->win_w * 2.0f - 1.0f) * 6.0f;
    float ay = -((float)st->mouseY / st->win_h * 2.0f - 1.0f) * 4.0f;
    Params params{};
    params.p0[0]=dt; params.p0[1]=time; params.p0[2]=(float)N; params.p0[3]=st->attracting ? 3.0f : 0.0f;
    params.attractor[0]=ax; params.attractor[1]=ay; params.attractor[2]=0; params.attractor[3]=0;

    // ---- compute pass: advance the simulation ----
    SDL_GPUStorageBufferReadWriteBinding rw{}; rw.buffer = st->particles;
    SDL_GPUComputePass *cp = SDL_BeginGPUComputePass(cmd, nullptr, 0, &rw, 1);
    SDL_BindGPUComputePipeline(cp, st->compute);
    SDL_PushGPUComputeUniformData(cmd, 0, &params, sizeof(params));
    SDL_DispatchGPUCompute(cp, (N + 63) / 64, 1, 1);
    SDL_EndGPUComputePass(cp);

    // ---- render pass: draw the same buffer additively under the camera ----
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);
    if (swap) {
        st->win_w = (int)sw; st->win_h = (int)sh;
        float aspect = sh > 0 ? (float)sw/(float)sh : 1.0f;
        float ang = time * 0.2f, dist = 11.0f;
        Mat4 view = mat4_look_at(SDL_sinf(ang)*dist, 1.0f, SDL_cosf(ang)*dist, 0,0,0, 0,1,0);
        VUBO vub{}; vub.mvp = mat4_mul(mat4_perspective(60.0f*SDL_PI_F/180.0f, aspect, 0.1f, 100.0f), view);

        SDL_GPUColorTargetInfo c{}; c.texture=swap; c.clear_color=SDL_FColor{0.01f,0.01f,0.03f,1};
        c.load_op=SDL_GPU_LOADOP_CLEAR; c.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass *p = SDL_BeginGPURenderPass(cmd, &c, 1, nullptr);
        SDL_BindGPUGraphicsPipeline(p, st->draw);
        SDL_GPUBufferBinding vb{}; vb.buffer=st->particles; SDL_BindGPUVertexBuffers(p,0,&vb,1);
        SDL_PushGPUVertexUniformData(cmd, 0, &vub, sizeof(vub));
        SDL_DrawGPUPrimitives(p, N, 1, 0, 0);
        SDL_EndGPURenderPass(p);
    }

    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->particles) SDL_ReleaseGPUBuffer(st->device, st->particles);
        if (st->draw)      SDL_ReleaseGPUGraphicsPipeline(st->device, st->draw);
        if (st->compute)   SDL_ReleaseGPUComputePipeline(st->device, st->compute);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Bump N to 500,000 — only the dispatch count changes, and the GPU shrugs.
  2. Add a repulsor on the right mouse button (negate the attract strength) to blow particles apart.
  3. Soft round sprites: expand each point into a camera-facing quad (recipe 18 instancing) and fade by radius for blobs instead of squares.
  4. Swap the sine field for true curl noise so the flow is divergence-free and never bunches up.

And that completes the 3D track. From a single triangle you built a lit, textured, shadowed world, authored cross-platform shaders, and finished with many-light forward and deferred shading, tone mapping, reflections, screen-space ambient occlusion, and a GPU particle system — the toolkit of a modern real-time engine. The bgfx Track rebuilds this same arc on a graphics-API-agnostic renderer: SDL3 still owns the window and input, while bgfx drives the backend — right down to its own compute particle system.
