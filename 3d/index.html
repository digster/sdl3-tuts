3D Track

Twenty-one recipes that take you from the "hello triangle" to a textured, lit cube you can fly around with an FPS camera, then on through cross-platform shaders, skyboxes, normal and shadow mapping, GPU compute, and finally the techniques that polish a real renderer: instanced rendering, post-processing bloom, alpha blending and transparency, and anti-aliasing with mipmaps and MSAA. All in C++ using SDL3's SDL_GPU API (Metal / Vulkan / D3D12 under one abstraction).

How to run the code

For recipes 01–12 and 14–21, every Complete listing is a drop-in replacement for examples/cpp-gpu/triangle.cpp. Replace that file's contents, then build with make run-gpu from the repo root. That covers the original recipes through GPU compute as well as the later instancing, bloom, transparency and anti-aliasing listings (18–21).

Recipe 13 lives in the sibling folder examples/cpp-gpu-shadercross/ because it has one extra dependency (SDL_shadercross), and is built with make run-shadercross.

Shaders in recipes 01–12 and 14–21 are written in Metal Shading Language (MSL) and embedded as raw string literals. On macOS that compiles at runtime and needs no extra tooling. On other platforms see recipe 02 for the SPIR-V / DXIL story, then jump to recipe 13 for the real cross-platform solution.
