Recipe 20 — Alpha Blending & Transparency

See-through surfaces. The blend-state struct that mixes a fragment's colour with what's already on screen — plus the two rules that keep translucency from going wrong: depth-write off, and draw back-to-front.

What you'll learn

  • The SDL_GPUColorTargetBlendState fields that turn on alpha blending.
  • Why transparent geometry uses depth test on but depth write off.
  • The "opaque first, then sorted transparent back-to-front" draw order.
  • The visual artifact you get when you skip either rule.

Prerequisites

Recipe 07 — Depth Testing (the depth buffer is central here) and recipe 08 for the sampler/pipeline shape. We'll add a second pipeline whose only difference is its blend and depth state.

Walkthrough

What blending actually does

Without blending, a fragment that survives the depth test simply overwrites the pixel. Blending instead combines the incoming fragment (the source) with the colour already in the target (the destination) using a weighted formula. Standard "over" alpha compositing is: 

// result = src.rgb * src.a  +  dst.rgb * (1 - src.a)

which is exactly the blend factors SRC_ALPHA and ONE_MINUS_SRC_ALPHA combined with the ADD operation.

The blend-state struct

Blending is pipeline state. Fill an SDL_GPUColorTargetBlendState and hang it off the colour target description: 

SDL_GPUColorTargetBlendState bs{};
bs.enable_blend           = true;
bs.src_color_blendfactor  = SDL_GPU_BLENDFACTOR_SRC_ALPHA;
bs.dst_color_blendfactor  = SDL_GPU_BLENDFACTOR_ONE_MINUS_SRC_ALPHA;
bs.color_blend_op         = SDL_GPU_BLENDOP_ADD;
bs.src_alpha_blendfactor  = SDL_GPU_BLENDFACTOR_ONE;
bs.dst_alpha_blendfactor  = SDL_GPU_BLENDFACTOR_ONE_MINUS_SRC_ALPHA;
bs.alpha_blend_op         = SDL_GPU_BLENDOP_ADD;

SDL_GPUColorTargetDescription ct{};
ct.format      = SDL_GetGPUSwapchainTextureFormat(device, window);
ct.blend_state = bs;                       // attach it to the target

The opaque pipeline leaves enable_blend = false (the default); only the transparent pipeline sets the struct above.

Depth test on, depth write off

Here's the subtlety. Transparent surfaces must still be occluded by opaque geometry in front of them — so depth testing stays on. But they must not write their own depth, because a near-transparent pane writing depth would stop farther transparent panes (and anything behind it) from blending through. 

// Transparent pipeline depth state:
tpci.depth_stencil_state.enable_depth_test  = true;    // still get occluded by opaque
tpci.depth_stencil_state.enable_depth_write = false;   // but don't block what's behind
tpci.depth_stencil_state.compare_op         = SDL_GPU_COMPAREOP_LESS;

Draw order: opaque first, then sorted back-to-front

Blending is not commutative — "red over blue" looks different from "blue over red". The destination must already hold everything behind the fragment, so the only correct order is:

  1. Draw all opaque geometry (any order; depth sorts it).
  2. Sort the transparent surfaces by view-space depth, farthest first.
  3. Draw them back-to-front, each blending over the ones already there.
// View-space Z of each pane's centre; more negative = farther from the camera.
std::sort(panes.begin(), panes.end(), [&](const Pane &a, const Pane &b){
    return view_z(a) < view_z(b);          // farthest (smallest z) drawn first
});
The artifact. Leave depth-write on, or skip the sort, and you get the classic transparency bug: panes vanish or punch rectangular holes where a nearer one wrote depth before a farther one tried to blend. Order-independent transparency (depth peeling, weighted blended OIT) exists to avoid the sort — but for a handful of panes, sorting is the simple, correct answer.

Complete listing

One opaque spinning cube in the middle, with three translucent coloured panes floating at different depths. The panes are sorted back-to-front every frame and blended over the scene; depth-write is off so they layer correctly. 

/*
 * 20-alpha-blending.cpp — opaque cube plus sorted translucent panes.
 * Two pipelines: opaque (blend off, depth-write on) and transparent
 * (blend on, depth-test on, depth-write off). Panes sorted back-to-front.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>

#include <cstring>
#include <cstddef>
#include <algorithm>

struct Vertex { float x, y, z, r, g, b, a; };

// Opaque cube (solid colours, alpha 1).
static const Vertex kCube[24] = {
    {  0.5f,-0.5f,-0.5f, 0.8f,0.8f,0.8f,1 },{  0.5f, 0.5f,-0.5f, 0.8f,0.8f,0.8f,1 },{  0.5f, 0.5f, 0.5f, 0.8f,0.8f,0.8f,1 },{  0.5f,-0.5f, 0.5f, 0.8f,0.8f,0.8f,1 },
    { -0.5f,-0.5f, 0.5f, 0.6f,0.6f,0.6f,1 },{ -0.5f, 0.5f, 0.5f, 0.6f,0.6f,0.6f,1 },{ -0.5f, 0.5f,-0.5f, 0.6f,0.6f,0.6f,1 },{ -0.5f,-0.5f,-0.5f, 0.6f,0.6f,0.6f,1 },
    { -0.5f, 0.5f,-0.5f, 0.9f,0.9f,0.9f,1 },{ -0.5f, 0.5f, 0.5f, 0.9f,0.9f,0.9f,1 },{  0.5f, 0.5f, 0.5f, 0.9f,0.9f,0.9f,1 },{  0.5f, 0.5f,-0.5f, 0.9f,0.9f,0.9f,1 },
    { -0.5f,-0.5f, 0.5f, 0.5f,0.5f,0.5f,1 },{ -0.5f,-0.5f,-0.5f, 0.5f,0.5f,0.5f,1 },{  0.5f,-0.5f,-0.5f, 0.5f,0.5f,0.5f,1 },{  0.5f,-0.5f, 0.5f, 0.5f,0.5f,0.5f,1 },
    { -0.5f,-0.5f, 0.5f, 0.7f,0.7f,0.7f,1 },{  0.5f,-0.5f, 0.5f, 0.7f,0.7f,0.7f,1 },{  0.5f, 0.5f, 0.5f, 0.7f,0.7f,0.7f,1 },{ -0.5f, 0.5f, 0.5f, 0.7f,0.7f,0.7f,1 },
    {  0.5f,-0.5f,-0.5f, 0.7f,0.7f,0.7f,1 },{ -0.5f,-0.5f,-0.5f, 0.7f,0.7f,0.7f,1 },{ -0.5f, 0.5f,-0.5f, 0.7f,0.7f,0.7f,1 },{  0.5f, 0.5f,-0.5f, 0.7f,0.7f,0.7f,1 },
};
static const Uint16 kIdx[36] = {
    0,1,2, 4,5,6, 8,9,10, 12,13,14, 16,17,18, 20,21,22,
    0,2,3, 4,6,7, 8,10,11, 12,14,15, 16,18,19, 20,22,23,
};

// A single translucent quad in its own local space; coloured + positioned per draw.
static const Vertex kQuad[4] = {
    { -0.9f,-0.9f, 0.0f, 1,1,1,1 },{ -0.9f, 0.9f, 0.0f, 1,1,1,1 },
    {  0.9f, 0.9f, 0.0f, 1,1,1,1 },{  0.9f,-0.9f, 0.0f, 1,1,1,1 },
};
static const Uint16 kQuadIdx[6] = { 0,1,2, 0,2,3 };

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_translate(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[12]=x;r.m[13]=y;r.m[14]=z; return r;}
static Mat4 mat4_rotate_y(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[0]=c;r.m[2]=-s;r.m[8]=s;r.m[10]=c; return r;}
static Mat4 mat4_rotate_x(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[5]=c;r.m[6]=s;r.m[9]=-s;r.m[10]=c; return r;}
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos [[attribute(0)]]; float4 color [[attribute(1)]]; };
struct VSOut { float4 position [[position]]; float4 color; };
struct UBO   { float4x4 mvp; float4 tint; };   // tint.a carries the pane's alpha
vertex VSOut vertexMain(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o; o.position = u.mvp * float4(in.pos, 1.0);
    o.color = in.color * u.tint;
    return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float4 color; };
fragment float4 fragmentMain(VSOut in [[stage_in]]) { return in.color; }
)msl";

struct UBO { Mat4 mvp; float tint[4]; };

// A transparent pane: where it sits, what colour, how see-through.
struct Pane { float px, py, pz; float r, g, b, a; };

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUGraphicsPipeline *opaque=nullptr, *transparent=nullptr;
    SDL_GPUBuffer *cube_vb=nullptr, *cube_ib=nullptr, *quad_vb=nullptr, *quad_ib=nullptr;
    SDL_GPUTexture *depth=nullptr;
    Uint32 depth_w=0, depth_h=0;
    Uint64 start_ns=0;
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e, Uint32 ubo){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s; i.num_uniform_buffers=ubo;
    return SDL_CreateGPUShader(d, &i);
}
static bool upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev);
    SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb;
    SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false);
    SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb); return true;
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}

// Both pipelines share shaders + vertex layout; only blend/depth state differs.
static SDL_GPUGraphicsPipeline *make_pipeline(AppState *st, bool blend){
    SDL_GPUShader *vs = make_shader(st->device, kVS, SDL_GPU_SHADERSTAGE_VERTEX,   "vertexMain",   1);
    SDL_GPUShader *fs = make_shader(st->device, kFS, SDL_GPU_SHADERSTAGE_FRAGMENT, "fragmentMain", 0);

    SDL_GPUVertexBufferDescription vb{}; vb.slot=0; vb.pitch=sizeof(Vertex); vb.input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    SDL_GPUVertexAttribute attrs[2]{};
    attrs[0].location=0; attrs[0].buffer_slot=0; attrs[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[0].offset=offsetof(Vertex,x);
    attrs[1].location=1; attrs[1].buffer_slot=0; attrs[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; attrs[1].offset=offsetof(Vertex,r);
    SDL_GPUVertexInputState vis{}; vis.vertex_buffer_descriptions=&vb; vis.num_vertex_buffers=1; vis.vertex_attributes=attrs; vis.num_vertex_attributes=2;

    SDL_GPUColorTargetDescription ct{}; ct.format = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    if (blend) {
        SDL_GPUColorTargetBlendState bs{};
        bs.enable_blend          = true;
        bs.src_color_blendfactor = SDL_GPU_BLENDFACTOR_SRC_ALPHA;
        bs.dst_color_blendfactor = SDL_GPU_BLENDFACTOR_ONE_MINUS_SRC_ALPHA;
        bs.color_blend_op        = SDL_GPU_BLENDOP_ADD;
        bs.src_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE;
        bs.dst_alpha_blendfactor = SDL_GPU_BLENDFACTOR_ONE_MINUS_SRC_ALPHA;
        bs.alpha_blend_op        = SDL_GPU_BLENDOP_ADD;
        ct.blend_state = bs;
    }

    SDL_GPUGraphicsPipelineCreateInfo pci{};
    pci.vertex_shader=vs; pci.fragment_shader=fs;
    pci.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    pci.vertex_input_state=vis;
    pci.target_info.color_target_descriptions=&ct;
    pci.target_info.num_color_targets=1;
    pci.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    pci.target_info.has_depth_stencil_target=true;
    pci.depth_stencil_state.enable_depth_test  = true;
    pci.depth_stencil_state.enable_depth_write = blend ? false : true;   // the key line
    pci.depth_stencil_state.compare_op         = SDL_GPU_COMPAREOP_LESS;

    SDL_GPUGraphicsPipeline *p = SDL_CreateGPUGraphicsPipeline(st->device, &pci);
    SDL_ReleaseGPUShader(st->device, vs); SDL_ReleaseGPUShader(st->device, fs);
    return p;
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Alpha Blending", "1.0", "com.example.sdl3.blend");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Alpha Blending", 800, 600, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    SDL_GPUBufferCreateInfo cvbi{}; cvbi.usage=SDL_GPU_BUFFERUSAGE_VERTEX; cvbi.size=sizeof(kCube);
    st->cube_vb=SDL_CreateGPUBuffer(st->device,&cvbi);
    SDL_GPUBufferCreateInfo cibi{}; cibi.usage=SDL_GPU_BUFFERUSAGE_INDEX;  cibi.size=sizeof(kIdx);
    st->cube_ib=SDL_CreateGPUBuffer(st->device,&cibi);
    SDL_GPUBufferCreateInfo qvbi{}; qvbi.usage=SDL_GPU_BUFFERUSAGE_VERTEX; qvbi.size=sizeof(kQuad);
    st->quad_vb=SDL_CreateGPUBuffer(st->device,&qvbi);
    SDL_GPUBufferCreateInfo qibi{}; qibi.usage=SDL_GPU_BUFFERUSAGE_INDEX;  qibi.size=sizeof(kQuadIdx);
    st->quad_ib=SDL_CreateGPUBuffer(st->device,&qibi);
    upload_buffer(st->device, st->cube_vb, kCube,    sizeof(kCube));
    upload_buffer(st->device, st->cube_ib, kIdx,     sizeof(kIdx));
    upload_buffer(st->device, st->quad_vb, kQuad,    sizeof(kQuad));
    upload_buffer(st->device, st->quad_ib, kQuadIdx, sizeof(kQuadIdx));

    st->opaque      = make_pipeline(st, false);
    st->transparent = make_pipeline(st, true);
    if (!st->opaque || !st->transparent) return fail("pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *, SDL_Event *e)
{
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->depth_w || sh != st->depth_h) {
            if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
            st->depth = create_depth(st->device, sw, sh);
            st->depth_w = sw; st->depth_h = sh;
        }
        float aspect = sh > 0 ? (float)sw / (float)sh : 1.0f;
        Mat4 view = mat4_translate(0, 0, -4.5f);
        Mat4 proj = mat4_perspective(60.0f * SDL_PI_F / 180.0f, aspect, 0.1f, 100.0f);

        // Three translucent panes at different depths along Z.
        Pane panes[3] = {
            { 0, 0, -1.2f, 1.0f, 0.3f, 0.3f, 0.5f },   // red, farthest
            { 0, 0,  0.0f, 0.3f, 1.0f, 0.3f, 0.5f },   // green, middle
            { 0, 0,  1.2f, 0.3f, 0.3f, 1.0f, 0.5f },   // blue, nearest
        };
        // Sort back-to-front in view space: more-negative view Z is farther.
        std::sort(panes, panes + 3, [&](const Pane &a, const Pane &b){
            float za = (mat4_mul(view, mat4_translate(a.px, a.py, a.pz))).m[14];
            float zb = (mat4_mul(view, mat4_translate(b.px, b.py, b.pz))).m[14];
            return za < zb;                  // farthest (smallest z) first
        });

        SDL_GPUColorTargetInfo cti{};
        cti.texture=swap; cti.clear_color=SDL_FColor{0.05f,0.06f,0.09f,1};
        cti.load_op=SDL_GPU_LOADOP_CLEAR; cti.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo dti{};
        dti.texture=st->depth; dti.clear_depth=1.0f;
        dti.load_op=SDL_GPU_LOADOP_CLEAR; dti.store_op=SDL_GPU_STOREOP_DONT_CARE;

        SDL_GPURenderPass *pass = SDL_BeginGPURenderPass(cmd, &cti, 1, &dti);

        // ---- 1. opaque cube (blend off, depth-write on) ----
        SDL_BindGPUGraphicsPipeline(pass, st->opaque);
        SDL_GPUBufferBinding cvb{}; cvb.buffer=st->cube_vb; SDL_BindGPUVertexBuffers(pass,0,&cvb,1);
        SDL_GPUBufferBinding cib{}; cib.buffer=st->cube_ib; SDL_BindGPUIndexBuffer(pass,&cib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        UBO cube_ubo{};
        Mat4 cube_model = mat4_mul(mat4_rotate_y(t * 0.8f), mat4_rotate_x(t * 0.5f));
        cube_ubo.mvp = mat4_mul(proj, mat4_mul(view, cube_model));
        cube_ubo.tint[0]=cube_ubo.tint[1]=cube_ubo.tint[2]=cube_ubo.tint[3]=1.0f;
        SDL_PushGPUVertexUniformData(cmd, 0, &cube_ubo, sizeof(cube_ubo));
        SDL_DrawGPUIndexedPrimitives(pass, 36, 1, 0, 0, 0);

        // ---- 2. transparent panes, back-to-front (blend on, depth-write off) ----
        SDL_BindGPUGraphicsPipeline(pass, st->transparent);
        SDL_GPUBufferBinding qvb{}; qvb.buffer=st->quad_vb; SDL_BindGPUVertexBuffers(pass,0,&qvb,1);
        SDL_GPUBufferBinding qib{}; qib.buffer=st->quad_ib; SDL_BindGPUIndexBuffer(pass,&qib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        for (const Pane &p : panes) {
            UBO u{};
            Mat4 model = mat4_translate(p.px, p.py, p.pz);
            u.mvp = mat4_mul(proj, mat4_mul(view, model));
            // Premultiply nothing here — straight alpha. tint carries colour + alpha.
            u.tint[0]=p.r; u.tint[1]=p.g; u.tint[2]=p.b; u.tint[3]=p.a;
            SDL_PushGPUVertexUniformData(cmd, 0, &u, sizeof(u));
            SDL_DrawGPUIndexedPrimitives(pass, 6, 1, 0, 0, 0);
        }

        SDL_EndGPURenderPass(pass);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->depth)   SDL_ReleaseGPUTexture(st->device, st->depth);
        if (st->quad_ib) SDL_ReleaseGPUBuffer(st->device, st->quad_ib);
        if (st->quad_vb) SDL_ReleaseGPUBuffer(st->device, st->quad_vb);
        if (st->cube_ib) SDL_ReleaseGPUBuffer(st->device, st->cube_ib);
        if (st->cube_vb) SDL_ReleaseGPUBuffer(st->device, st->cube_vb);
        if (st->transparent) SDL_ReleaseGPUGraphicsPipeline(st->device, st->transparent);
        if (st->opaque)      SDL_ReleaseGPUGraphicsPipeline(st->device, st->opaque);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Switch to additive blending — src = SRC_ALPHA, dst = ONE — for glowing glass, fire or magic. Additive is order-independent, so you can even drop the sort.
  2. Reproduce the artifact: set the transparent pipeline's enable_depth_write = true, or remove the std::sort, and watch panes punch holes through each other.
  3. Use premultiplied alpha: multiply the colour by alpha in the shader and switch src_color_blendfactor to SDL_GPU_BLENDFACTOR_ONE. It composites more cleanly through mip levels and filtering.
  4. Animate each pane's alpha over time (p.a = 0.5f + 0.5f * SDL_sinf(t + phase)) to fade them in and out.
