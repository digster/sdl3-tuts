Recipe 18 — Instanced Rendering

Draw a whole field of cubes — hundreds or thousands — in a single draw call. Per-instance data lives in its own vertex buffer that the GPU advances once per object instead of once per vertex.

What you'll learn

  • Why one instanced draw beats thousands of draw calls and uniform pushes.
  • A second vertex buffer bound at slot 1 with SDL_GPU_VERTEXINPUTRATE_INSTANCE.
  • Mixing per-vertex attributes (slot 0) and per-instance attributes (slot 1) in one pipeline.
  • The single instanced draw via SDL_DrawGPUIndexedPrimitives with a non-1 instance count.

Prerequisites

Recipe 06 — The 3D Cube for the geometry, recipe 07 for depth, and recipe 10 — which drew a grid the slow way, one SDL_DrawGPUIndexedPrimitives per cube. This recipe collapses that loop into a single call.

Walkthrough

The problem with one-draw-per-object

In recipe 10 a grid of cubes was drawn by looping on the CPU: push a fresh model matrix, issue a draw, repeat. That's fine for a dozen cubes and miserable for a thousand — every iteration is a uniform upload and a draw call, and the CPU spends all its time feeding the GPU instead of the GPU spending its time drawing. Instancing inverts that: the geometry is uploaded once, the per-object data is uploaded once as a flat array, and a single draw call stamps out every copy.

Two buffers, two input rates

The cube vertices live in slot 0 exactly as before, advanced once per vertex (SDL_GPU_VERTEXINPUTRATE_VERTEX). The new idea is a second buffer in slot 1 holding one record per instance — here a world-space offset and a colour — advanced once per instance (SDL_GPU_VERTEXINPUTRATE_INSTANCE). The GPU keeps the slot-1 pointer fixed across all 36 vertices of a cube, then steps it forward for the next cube. 

struct Vertex   { float x, y, z; };                 // slot 0, per vertex
struct Instance { float ox, oy, oz; float r, g, b, a; };  // slot 1, per instance

SDL_GPUVertexBufferDescription vbufs[2]{};
vbufs[0].slot=0; vbufs[0].pitch=sizeof(Vertex);   vbufs[0].input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
vbufs[1].slot=1; vbufs[1].pitch=sizeof(Instance); vbufs[1].input_rate=SDL_GPU_VERTEXINPUTRATE_INSTANCE;

That single field — input_rate — is the whole trick. Both buffers feed the same vertex shader; they just advance at different rates.

Attribute locations across slots

Attribute locations are global to the pipeline, but each attribute names which buffer_slot it reads from. Position is location 0 from slot 0; the per-instance offset and colour are locations 2 and 3 from slot 1. (Location 1 is left free here so the cube's own per-vertex slots line up with the lit/textured recipes — feel free to renumber.) 

SDL_GPUVertexAttribute attrs[3]{};
// per-vertex (slot 0)
attrs[0].location=0; attrs[0].buffer_slot=0; attrs[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[0].offset=offsetof(Vertex,x);
// per-instance (slot 1)
attrs[1].location=2; attrs[1].buffer_slot=1; attrs[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[1].offset=offsetof(Instance,ox);
attrs[2].location=3; attrs[2].buffer_slot=1; attrs[2].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; attrs[2].offset=offsetof(Instance,r);

SDL_GPUVertexInputState vis{};
vis.vertex_buffer_descriptions=vbufs; vis.num_vertex_buffers=2;
vis.vertex_attributes=attrs;          vis.num_vertex_attributes=3;

Generating the instance array

Build the per-instance data once on the CPU and upload it like any other vertex buffer. Here a 12×12 grid laid out on the XZ plane, each cube tinted by a hue that sweeps across the field. 

const int GRID = 12;
const int NUM_INSTANCES = GRID * GRID;
std::vector<Instance> inst(NUM_INSTANCES);
for (int z = 0; z < GRID; ++z)
    for (int x = 0; x < GRID; ++x) {
        Instance &it = inst[z * GRID + x];
        it.ox = (x - GRID * 0.5f) * 1.6f;
        it.oy = 0.0f;
        it.oz = (z - GRID * 0.5f) * 1.6f;
        float h = (float)(x + z) / (float)(2 * GRID);   // 0..1 hue sweep
        it.r = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 0.0f);
        it.g = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 2.094f);
        it.b = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 4.188f);
        it.a = 1.0f;
    }

The vertex shader sees both streams

Per-vertex pos arrives at attribute(0); the per-instance ioffset and icolor arrive at attribute(2) and attribute(3). The model transform is just a translation by the offset, so the world position is pos + ioffset. A single shared viewProj uniform (buffer 0) projects everything. 

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos     [[attribute(0)]];
               float3 ioffset [[attribute(2)]];
               float4 icolor  [[attribute(3)]]; };
struct VSOut { float4 position [[position]]; float4 color; };
struct UBO   { float4x4 viewProj; };
vertex VSOut vs(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o;
    float3 world = in.pos + in.ioffset;        // model = translate(ioffset)
    o.position = u.viewProj * float4(world, 1.0);
    o.color    = in.icolor;
    return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float4 color; };
fragment float4 fs(VSOut in [[stage_in]]) { return in.color; }
)msl";

One draw, every cube

Bind both vertex buffers (slot 0 = cube, slot 1 = instances), bind the index buffer, push the one viewProj uniform, and issue a single indexed draw whose instance count is NUM_INSTANCES. The GPU runs the 36-index cube once per instance, swapping in the next slot-1 record each time. 

SDL_GPUBufferBinding vb[2]{};
vb[0].buffer = st->vbuf; vb[1].buffer = st->ibuf_inst;   // slots 0 and 1
SDL_BindGPUVertexBuffers(pass, 0, vb, 2);
SDL_GPUBufferBinding ib{}; ib.buffer = st->ibuf;
SDL_BindGPUIndexBuffer(pass, &ib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
SDL_PushGPUVertexUniformData(cmd, 0, &viewProj, sizeof(viewProj));
SDL_DrawGPUIndexedPrimitives(pass, /*num_indices=*/36, /*num_instances=*/NUM_INSTANCES, 0, 0, 0);
Why this matters. The signature SDL_DrawGPUIndexedPrimitives(pass, num_indices, num_instances, first_index, vertex_offset, first_instance) has always had that second argument; every earlier recipe just passed 1. Pass NUM_INSTANCES and the cost of "more objects" becomes a bigger buffer, not more CPU work. Grass, asteroid fields, particle quads, crowd characters — all instancing.

Complete listing

A 12×12 field of 144 hued cubes drawn in one call, gently rotating as a whole. Push GRID up and watch the draw count stay at one. 

/*
 * 18-instanced-rendering.cpp — a field of cubes drawn in a single instanced
 * draw call. Per-instance offset + colour live in a slot-1 vertex buffer with
 * input_rate = INSTANCE.
 */
#define SDL_MAIN_USE_CALLBACKS 1
#include <SDL3/SDL.h>
#include <SDL3/SDL_main.h>

#include <cstring>
#include <cstddef>
#include <vector>

static const int GRID = 12;
static const int NUM_INSTANCES = GRID * GRID;

struct Vertex   { float x, y, z; };
struct Instance { float ox, oy, oz; float r, g, b, a; };

// Cube corners only — colour now comes from the per-instance stream.
static const Vertex kCube[24] = {
    {  0.5f,-0.5f,-0.5f },{  0.5f, 0.5f,-0.5f },{  0.5f, 0.5f, 0.5f },{  0.5f,-0.5f, 0.5f },
    { -0.5f,-0.5f, 0.5f },{ -0.5f, 0.5f, 0.5f },{ -0.5f, 0.5f,-0.5f },{ -0.5f,-0.5f,-0.5f },
    { -0.5f, 0.5f,-0.5f },{ -0.5f, 0.5f, 0.5f },{  0.5f, 0.5f, 0.5f },{  0.5f, 0.5f,-0.5f },
    { -0.5f,-0.5f, 0.5f },{ -0.5f,-0.5f,-0.5f },{  0.5f,-0.5f,-0.5f },{  0.5f,-0.5f, 0.5f },
    { -0.5f,-0.5f, 0.5f },{  0.5f,-0.5f, 0.5f },{  0.5f, 0.5f, 0.5f },{ -0.5f, 0.5f, 0.5f },
    {  0.5f,-0.5f,-0.5f },{ -0.5f,-0.5f,-0.5f },{ -0.5f, 0.5f,-0.5f },{  0.5f, 0.5f,-0.5f },
};
static const Uint16 kIdx[36] = {
    0,1,2, 4,5,6, 8,9,10, 12,13,14, 16,17,18, 20,21,22,
    0,2,3, 4,6,7, 8,10,11, 12,14,15, 16,18,19, 20,22,23,
};

struct Mat4 { float m[16]; };
static Mat4 mat4_identity(){ Mat4 r{}; r.m[0]=r.m[5]=r.m[10]=r.m[15]=1; return r; }
static Mat4 mat4_translate(float x,float y,float z){ Mat4 r=mat4_identity(); r.m[12]=x;r.m[13]=y;r.m[14]=z; return r;}
static Mat4 mat4_rotate_y(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[0]=c;r.m[2]=-s;r.m[8]=s;r.m[10]=c; return r;}
static Mat4 mat4_rotate_x(float a){ float c=SDL_cosf(a),s=SDL_sinf(a); Mat4 r=mat4_identity(); r.m[5]=c;r.m[6]=s;r.m[9]=-s;r.m[10]=c; return r;}
static Mat4 mat4_perspective(float fovy,float aspect,float n,float f){ float t=1/SDL_tanf(fovy*0.5f); Mat4 r{}; r.m[0]=t/aspect; r.m[5]=t; r.m[10]=f/(n-f); r.m[11]=-1; r.m[14]=(n*f)/(n-f); return r;}
static Mat4 mat4_mul(const Mat4 &a,const Mat4 &b){ Mat4 r{}; for(int c=0;c<4;++c) for(int row=0;row<4;++row){ float s=0; for(int k=0;k<4;++k) s+=a.m[k*4+row]*b.m[c*4+k]; r.m[c*4+row]=s; } return r;}

static const char *kVS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSIn  { float3 pos     [[attribute(0)]];
               float3 ioffset [[attribute(2)]];
               float4 icolor  [[attribute(3)]]; };
struct VSOut { float4 position [[position]]; float4 color; };
struct UBO   { float4x4 viewProj; };
vertex VSOut vs(VSIn in [[stage_in]], constant UBO &u [[buffer(0)]]) {
    VSOut o;
    float3 world = in.pos + in.ioffset;
    o.position = u.viewProj * float4(world, 1.0);
    o.color    = in.icolor;
    return o;
}
)msl";
static const char *kFS = R"msl(
#include <metal_stdlib>
using namespace metal;
struct VSOut { float4 position [[position]]; float4 color; };
fragment float4 fs(VSOut in [[stage_in]]) { return in.color; }
)msl";

struct AppState {
    SDL_Window *window=nullptr; SDL_GPUDevice *device=nullptr;
    SDL_GPUGraphicsPipeline *pipeline=nullptr;
    SDL_GPUBuffer *vbuf=nullptr, *ibuf=nullptr, *ibuf_inst=nullptr;
    SDL_GPUTexture *depth=nullptr;
    Uint32 depth_w=0, depth_h=0;
    Uint64 start_ns=0;
};

static SDL_AppResult fail(const char *w){ SDL_Log("%s: %s", w, SDL_GetError()); return SDL_APP_FAILURE; }
static SDL_GPUShader *make_shader(SDL_GPUDevice *d, const char *src, SDL_GPUShaderStage s, const char *e,
                                  Uint32 ubo, Uint32 samplers){
    SDL_GPUShaderCreateInfo i{}; i.code=(const Uint8*)src; i.code_size=std::strlen(src);
    i.entrypoint=e; i.format=SDL_GPU_SHADERFORMAT_MSL; i.stage=s;
    i.num_uniform_buffers=ubo; i.num_samplers=samplers;
    return SDL_CreateGPUShader(d, &i);
}
static bool upload_buffer(SDL_GPUDevice *dev, SDL_GPUBuffer *dst, const void *src, Uint32 size){
    SDL_GPUTransferBufferCreateInfo tbi{}; tbi.usage=SDL_GPU_TRANSFERBUFFERUSAGE_UPLOAD; tbi.size=size;
    SDL_GPUTransferBuffer *tb=SDL_CreateGPUTransferBuffer(dev,&tbi);
    void *m=SDL_MapGPUTransferBuffer(dev,tb,false); std::memcpy(m,src,size); SDL_UnmapGPUTransferBuffer(dev,tb);
    SDL_GPUCommandBuffer *cmd=SDL_AcquireGPUCommandBuffer(dev);
    SDL_GPUCopyPass *cp=SDL_BeginGPUCopyPass(cmd);
    SDL_GPUTransferBufferLocation s{}; s.transfer_buffer=tb;
    SDL_GPUBufferRegion r{}; r.buffer=dst; r.size=size;
    SDL_UploadToGPUBuffer(cp,&s,&r,false);
    SDL_EndGPUCopyPass(cp); SDL_SubmitGPUCommandBuffer(cmd);
    SDL_ReleaseGPUTransferBuffer(dev,tb); return true;
}
static SDL_GPUTexture *create_depth(SDL_GPUDevice *dev, Uint32 w, Uint32 h){
    SDL_GPUTextureCreateInfo ti{}; ti.type=SDL_GPU_TEXTURETYPE_2D;
    ti.format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT; ti.usage=SDL_GPU_TEXTUREUSAGE_DEPTH_STENCIL_TARGET;
    ti.width=w; ti.height=h; ti.layer_count_or_depth=1; ti.num_levels=1; ti.sample_count=SDL_GPU_SAMPLECOUNT_1;
    return SDL_CreateGPUTexture(dev,&ti);
}

SDL_AppResult SDL_AppInit(void **appstate, int, char *[])
{
    SDL_SetAppMetadata("Instanced Rendering", "1.0", "com.example.sdl3.instancing");
    if (!SDL_Init(SDL_INIT_VIDEO)) return fail("init");
    AppState *st = new AppState(); *appstate = st;
    st->device = SDL_CreateGPUDevice(SDL_GPU_SHADERFORMAT_MSL, true, nullptr);
    st->window = SDL_CreateWindow("Instanced Rendering", 800, 600, SDL_WINDOW_RESIZABLE);
    SDL_ClaimWindowForGPUDevice(st->device, st->window);

    // --- cube geometry (slot 0) + indices ---
    SDL_GPUBufferCreateInfo vbi{}; vbi.usage=SDL_GPU_BUFFERUSAGE_VERTEX; vbi.size=sizeof(kCube);
    st->vbuf=SDL_CreateGPUBuffer(st->device,&vbi);
    SDL_GPUBufferCreateInfo ibi{}; ibi.usage=SDL_GPU_BUFFERUSAGE_INDEX;  ibi.size=sizeof(kIdx);
    st->ibuf=SDL_CreateGPUBuffer(st->device,&ibi);
    upload_buffer(st->device, st->vbuf, kCube, sizeof(kCube));
    upload_buffer(st->device, st->ibuf, kIdx,  sizeof(kIdx));

    // --- per-instance data (slot 1) ---
    std::vector<Instance> inst(NUM_INSTANCES);
    for (int z = 0; z < GRID; ++z)
        for (int x = 0; x < GRID; ++x) {
            Instance &it = inst[z * GRID + x];
            it.ox = (x - GRID * 0.5f) * 1.6f;
            it.oy = 0.0f;
            it.oz = (z - GRID * 0.5f) * 1.6f;
            float h = (float)(x + z) / (float)(2 * GRID);
            it.r = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 0.0f);
            it.g = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 2.094f);
            it.b = 0.5f + 0.5f * SDL_sinf(h * 6.283f + 4.188f);
            it.a = 1.0f;
        }
    SDL_GPUBufferCreateInfo ibi2{}; ibi2.usage=SDL_GPU_BUFFERUSAGE_VERTEX; ibi2.size=(Uint32)(sizeof(Instance)*NUM_INSTANCES);
    st->ibuf_inst=SDL_CreateGPUBuffer(st->device,&ibi2);
    upload_buffer(st->device, st->ibuf_inst, inst.data(), ibi2.size);

    // --- pipeline: two vertex buffers, one per-vertex, one per-instance ---
    SDL_GPUShader *vs = make_shader(st->device, kVS, SDL_GPU_SHADERSTAGE_VERTEX,   "vs", 1, 0);
    SDL_GPUShader *fs = make_shader(st->device, kFS, SDL_GPU_SHADERSTAGE_FRAGMENT, "fs", 0, 0);

    SDL_GPUVertexBufferDescription vbufs[2]{};
    vbufs[0].slot=0; vbufs[0].pitch=sizeof(Vertex);   vbufs[0].input_rate=SDL_GPU_VERTEXINPUTRATE_VERTEX;
    vbufs[1].slot=1; vbufs[1].pitch=sizeof(Instance); vbufs[1].input_rate=SDL_GPU_VERTEXINPUTRATE_INSTANCE;

    SDL_GPUVertexAttribute attrs[3]{};
    attrs[0].location=0; attrs[0].buffer_slot=0; attrs[0].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[0].offset=offsetof(Vertex,x);
    attrs[1].location=2; attrs[1].buffer_slot=1; attrs[1].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT3; attrs[1].offset=offsetof(Instance,ox);
    attrs[2].location=3; attrs[2].buffer_slot=1; attrs[2].format=SDL_GPU_VERTEXELEMENTFORMAT_FLOAT4; attrs[2].offset=offsetof(Instance,r);

    SDL_GPUVertexInputState vis{};
    vis.vertex_buffer_descriptions=vbufs; vis.num_vertex_buffers=2;
    vis.vertex_attributes=attrs;          vis.num_vertex_attributes=3;

    SDL_GPUColorTargetDescription ct{}; ct.format = SDL_GetGPUSwapchainTextureFormat(st->device, st->window);
    SDL_GPUGraphicsPipelineCreateInfo pci{};
    pci.vertex_shader=vs; pci.fragment_shader=fs;
    pci.primitive_type=SDL_GPU_PRIMITIVETYPE_TRIANGLELIST;
    pci.vertex_input_state=vis;
    pci.target_info.color_target_descriptions=&ct;
    pci.target_info.num_color_targets=1;
    pci.target_info.depth_stencil_format=SDL_GPU_TEXTUREFORMAT_D32_FLOAT;
    pci.target_info.has_depth_stencil_target=true;
    pci.depth_stencil_state.enable_depth_test=true;
    pci.depth_stencil_state.enable_depth_write=true;
    pci.depth_stencil_state.compare_op=SDL_GPU_COMPAREOP_LESS;

    st->pipeline = SDL_CreateGPUGraphicsPipeline(st->device, &pci);
    SDL_ReleaseGPUShader(st->device, vs);
    SDL_ReleaseGPUShader(st->device, fs);
    if (!st->pipeline) return fail("pipeline");

    st->start_ns = SDL_GetTicksNS();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void *, SDL_Event *e)
{
    if (e->type == SDL_EVENT_QUIT) return SDL_APP_SUCCESS;
    if (e->type == SDL_EVENT_KEY_DOWN && e->key.scancode == SDL_SCANCODE_ESCAPE) return SDL_APP_SUCCESS;
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void *appstate)
{
    AppState *st = static_cast<AppState *>(appstate);
    float t = (SDL_GetTicksNS() - st->start_ns) / 1.0e9f;

    SDL_GPUCommandBuffer *cmd = SDL_AcquireGPUCommandBuffer(st->device);
    SDL_GPUTexture *swap=nullptr; Uint32 sw=0, sh=0;
    SDL_WaitAndAcquireGPUSwapchainTexture(cmd, st->window, &swap, &sw, &sh);

    if (swap) {
        if (sw != st->depth_w || sh != st->depth_h) {
            if (st->depth) SDL_ReleaseGPUTexture(st->device, st->depth);
            st->depth = create_depth(st->device, sw, sh);
            st->depth_w = sw; st->depth_h = sh;
        }
        float aspect = sh > 0 ? (float)sw / (float)sh : 1.0f;

        // One view/projection for the whole field; slowly orbit the camera.
        Mat4 spin = mat4_rotate_y(t * 0.2f);
        Mat4 view = mat4_mul(mat4_translate(0, -2.0f, -22.0f), mat4_mul(mat4_rotate_x(0.5f), spin));
        Mat4 proj = mat4_perspective(60.0f * SDL_PI_F / 180.0f, aspect, 0.1f, 200.0f);
        Mat4 viewProj = mat4_mul(proj, view);

        SDL_GPUColorTargetInfo cti{};
        cti.texture=swap; cti.clear_color=SDL_FColor{0.04f,0.05f,0.08f,1};
        cti.load_op=SDL_GPU_LOADOP_CLEAR; cti.store_op=SDL_GPU_STOREOP_STORE;
        SDL_GPUDepthStencilTargetInfo dti{};
        dti.texture=st->depth; dti.clear_depth=1.0f;
        dti.load_op=SDL_GPU_LOADOP_CLEAR; dti.store_op=SDL_GPU_STOREOP_DONT_CARE;

        SDL_GPURenderPass *pass = SDL_BeginGPURenderPass(cmd, &cti, 1, &dti);
        SDL_BindGPUGraphicsPipeline(pass, st->pipeline);
        SDL_GPUBufferBinding vb[2]{};
        vb[0].buffer = st->vbuf; vb[1].buffer = st->ibuf_inst;
        SDL_BindGPUVertexBuffers(pass, 0, vb, 2);
        SDL_GPUBufferBinding ib{}; ib.buffer = st->ibuf;
        SDL_BindGPUIndexBuffer(pass, &ib, SDL_GPU_INDEXELEMENTSIZE_16BIT);
        SDL_PushGPUVertexUniformData(cmd, 0, &viewProj, sizeof(viewProj));
        SDL_DrawGPUIndexedPrimitives(pass, 36, NUM_INSTANCES, 0, 0, 0);
        SDL_EndGPURenderPass(pass);
    }
    SDL_SubmitGPUCommandBuffer(cmd);
    return SDL_APP_CONTINUE;
}

void SDL_AppQuit(void *appstate, SDL_AppResult)
{
    AppState *st = static_cast<AppState *>(appstate);
    if (!st) return;
    if (st->device) {
        if (st->depth)     SDL_ReleaseGPUTexture(st->device, st->depth);
        if (st->ibuf_inst) SDL_ReleaseGPUBuffer(st->device, st->ibuf_inst);
        if (st->ibuf)      SDL_ReleaseGPUBuffer(st->device, st->ibuf);
        if (st->vbuf)      SDL_ReleaseGPUBuffer(st->device, st->vbuf);
        SDL_ReleaseGPUGraphicsPipeline(st->device, st->pipeline);
        if (st->window) SDL_ReleaseWindowFromGPUDevice(st->device, st->window);
        SDL_DestroyGPUDevice(st->device);
    }
    SDL_DestroyWindow(st->window);
    delete st;
}

Try it yourself

  1. Animate the offsets in the vertex shader: pass time as a uniform and add sin(time + float(instance_id) * 0.3) to world.y. Receive the instance index with uint iid [[instance_id]] — the field becomes a rippling wave.
  2. Push GRID to ~316 (≈100 000 cubes). The only thing that grows is the instance buffer; the draw call count stays at exactly one.
  3. Add a per-instance scale (and a rotation angle) to the Instance struct, build a full model matrix in the shader, and give every cube its own size and spin.
  4. Jitter the colours: perturb each instance's hue with SDL_randf() at build time, or recompute colour from the animated height in the fragment shader.
